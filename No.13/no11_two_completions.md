# No.11 のエピ商を保つ二種類の完備化

2026-11-19。λ を非可算正則基数とし、λ 以上に可測基数がないと仮定する。原著の例 A.19 の整礎な ZC モデルを、各 L_{λ,λ} 式 φ の真理を関係 Rφ で記録した集合署名 Σ で扱う。否定された式も含め、文には必要ならダミー変数を付ける。非空のモデルを C₊、形式的始対象を空構造 0 とする。射はこの署名の全準同型とする。[原著 A.19](https://doi.org/10.1017/CBO9780511600579.010)・[前回の構成](lower_bound_trials.md)

調べたのは、(i) 積と誘導部分構造で閉じた K と、(ii) 0 と C₊ を小極限だけで閉じた L である。いずれでも 0 → Vη が真クラス個のエピ商を与える。以下の二つの論証は、ともに**どの集合署名の理論のモデル圏とも同値でない**という結論を与える。今回の導出であり、独立検証・形式化・初出の確認は未実施である。

同日の続稿で、§3 の図式の内部余極限を全ての中間の充満部分圏で計算し、内部完備な中間圏を一括して排除する証明案と、No.13 一般を肯定する証明案を得た。[内部余極限と被約積を用いた続稿](no13_reduced_products_proof_draft.md)

## 1. 大きいほうの完備化 K と署名の変更

**補題。** Σ は集合サイズの多ソート関係署名とする。Str(Σ) の充満・同型閉な部分圏 K が反射的で、ある集合署名 Γ の無限一階理論 T について K ≃ ModΓ(T) ならば、K の対象類は元の Σ における集合サイズの無限一階理論で公理化できる。

以下では Γ の関数記号はグラフ関係に置き換え、全域性・一意性を公理に加える。これで準同型も保たれる。モデル表示を E:K ≃ ModΓ(T) とする。

### 1.1 元と関係を検出する対象

Σ の各ソートについて一元だけの無関係構造 Dₛ を取り、各関係記号 R について、その項の各位置に別々の形式元を取り、その一組だけに R を課した構造 Dᵣ を取る。準同型 Dᵣ → X は R が成り立つ順序付きの組に対応し、形式元の像の重複も許す。零項関係には台が空の対応する構造を用いる。位置を取り出す射 Dₛ → Dᵣ も固定する。これら集合個の構造 D について、反射射 uᴅ:D → Pᴅ を取る。K の各対象 B では uᴅ による前合成が全単射となる。実際に必要なのは、この集合個の反射だけである。

### 1.2 第二の表示を、元の表示の小さい図式で読む

一つの無限基数 ν を Γ、T の論理の幅、全ての EPᴅ のサイズ以上に選び、μ=2^ν とする。必要な量化の幅を ν 以下に取れば μ^ν=μ なので、任意の T-モデルの高々 μ 個の元を含むサイズ ≤μ の初等部分モデルを、T に十分な固定断片で取れる。Γ の全関係の項数もこの選択で抑える。K の対象 A のうち EA がサイズ ≤μ であるものの同型代表を集合 B₀ に取り、すべての Pᴅ も加える。B₀ は小さい充満部分圏とみなす。[原著、下方 Löwenheim–Skolem 定理 5.41](https://doi.org/10.1017/CBO9780511600579.008)

任意の Σ-構造 X で、Γ のソート t の元の候補を (A,a,f) によって表す。A∈B₀、a∈(EA)ₜ、f:A→X は Σ-準同型である。タグ (A,a) は集合個であり、固定した A からの準同型は、A の全元を並べた変数組と A の正の原子図式で記述する。

- 二つの候補 (A,a,f),(A′,a′,f′) の等号の条件は、C∈B₀ と p:A→C, p′:A′→C, h:C→X があって、hp=f, hp′=f′ および Ep(a)=Ep′(a′) となること。
- Γ の関係 S が候補の組 (Aᵢ,aᵢ,fᵢ) で成り立つ条件は、C∈B₀ と pᵢ:Aᵢ→C, h:C→X があり、hpᵢ=fᵢ かつ EC で S((Epᵢ(aᵢ))ᵢ) が成り立つこと。

これらは Σ の無限一階式で書ける。例えば C,pᵢ の選択は固定した集合にわたる選言であり、h は C の全元に対応する変数の存在量化である。EC 内の等号・関係の真偽はタグを選ぶときの固定データである。

X∈K のとき (A,a,f) を Ef(a) に送ると、以上の等号と関係が EX のものに一致する。全射性には一つの元を含む小さい初等部分モデルを使う。等号または関係の反映には、関係する全ての Efᵢ の**像全体**を同時に含む小さい初等部分モデル EC ↪ EX を使う。像は ≤μ 個の元からなり、E の充満忠実性で因子化を K に戻せる。逆方向は準同型による関係の保存から従う。これが、全ての X を一つのタグ集合 B₀ で扱える理由である。

### 1.3 外側の構造が誤って合格しないこと

Σ の公理として、上の等号条件が同値関係であること、関係条件が代表の変更で不変であること、およびその商 Yₓ が T を満たすことを書く。形式的には Γ の式を上の候補に翻訳する。量化された各元についてタグを動かし、そのタグの変数組を量化する。T、タグ、各組の長さは全て集合サイズなので、翻訳後の全式が一つの L_{χ,χ} に入るよう正則 χ を選べる。

さらに各 D について次を公理にする。

1. uᴅ による写像 HomΣ(Pᴅ,X) → HomΣ(D,X) が全単射である。
2. f:Pᴅ→X に b ↦ [Pᴅ,b,f] を対応させると、HomΣ(Pᴅ,X) から HomΓ(EPᴅ,Yₓ) への全単射になる。

2 では候補の写像が全ての Γ-関係を保つことも要求する。全射性で変化する準同型の始域 EPᴅ は**固定した集合サイズ**であり、その各元の値を上の候補で並べ、正の原子図式で準同型性を表せる。一意性も同じ変数組で書ける。位置射 Dₛ→Dᵣ の反射 Pₛ→Pᵣ とこれらの全単射との可換性も集合個の式として課せる。X∈K では 1 は反射、2 は E の充満忠実性と 1.2 から成立し、可換性も関手性から成立する。

逆にこれらの公理を満たす X を取る。Yₓ は T のモデルなので、B∈K と Yₓ≅EB を選べる。1、2、E の充満忠実性、B の反射の性質を順に使うと、全ての D で HomΣ(D,X)≅HomΣ(D,B) が得られ、位置射と可換である。Dₛ では各ソートの全単射であり、Dᵣ ではその全単射が関係を保存し反映することを与える。従って X≅B であり X∈K。これで補題が示された。単に X の拡大が存在すると述べるだけでは最後の復元を保証できない。

**No.11 への適用。** 前稿 §1 の K は反射的である。一方、元の Σ で K が公理化できるなら、非モデルの小さい誘導部分構造に一様なサイズ上界がある。誘導部分構造で閉じる K は、これによりある正則基数で有向余極限に閉じ、解集合条件と合わせてアクセス可能になる。完備なので局所可呈示となり、0 → Vη に矛盾する。従って補題の対偶から、**K の別署名での公理化も不可能**である。同じ補題は、前稿 §2 の M-集合の例にも作用のグラフ・全域性を用いて適用できる。具体的には M-Set 内の自由一元 M-集合と作用のグラフのテストを使い、1.3 の公理に M-作用の公理を含めればよい。[前稿 §1–2 の反射と非公理化の証明](lower_bound_trials.md)

## 2. 誘導部分構造を加えず、小極限だけで閉じる試み

以下は §1 の反射性を仮定しない別証明である。実際に L の対象と射を計算する。

### 2.1 各射がどの座標を見るか

C₊ の対象の誘導部分構造のうち、集合論の 0=∅, 1={∅} を含むものを考える。この二元は異なり、それぞれパラメータなしの式で定義されている。部分構造の Rφ は親モデルでの φ の真理を記録しているので、ここで部分構造自身が ZC を満たす必要はない。二つのそのような対象の間の準同型は、R≠ と各 R¬φ も保つため、単射で全関係を反映し、0,1 を保つ。

非空族 (Aᵢ) の積から一つのそのような B への準同型 h を取る。各部分集合 S⊆I について、S 上で 1、補集合上で 0 の元 bₛ を用意する。h(bₛ) は 0 または 1 である。補元と二元の論理積のグラフを表す Rφ から、U={S:h(bₛ)=1} は超フィルターになる。任意の ν<λ 個のビットについて「出力が 1 ⇔ 全入力が 1」を表す関係記号もあるので、U は λ-完備である。非主的ならば、U に属さない集合への最小分割に押し出して λ 以上の可測基数を得る。仮定に反するので U は一つの座標 i に集中する。

uᵢ=vᵢ のとき、ビット b_{ {i} } が 1 なら u、それ以外なら v を選ぶ関数のグラフを使う。積での出力は v であり、B ではビットが 1 なので h(u)=h(v) となる。従って h=kπᵢ と集合写像として因子化する。**k が準同型となる箇所には注意がいる。** Aᵢ で Rφ(ā) が真でも他の座標で φ を実現できるとは限らない。そこで ā を任意に積に持ち上げて、「ビットが 1 なら φ」という式 ψ の関係 Rψ を使う。この関係は全座標で成立し、B ではビットが 1 なので Rφ(k ā) が従う。座標は U により一意、k は πᵢ の全射性により一意である。空積から B への射はない。空積では恒偽式に対応する一変数関係が一点上で成立するが、B では空だからである。

### 2.2 小極限閉包の形

C₊ を Str(Σ) の非空連結小図式の極限の下で閉じて得る充満・同型閉部分圏を B とする。B の対象はすべて 2.1 の条件を満たす。実際、その条件を満たす対象間では射が誘導部分構造の埋め込みである。連結図式の極限のどの射影も埋め込みである。一つの座標での元の一致は射の単射性と連結性によって全座標に伝わる。同様に一つの座標での関係の成立は全座標に伝わる。0,1 の族は整合するので極限にも二つの元が残る。

L の対象は、空構造と、B の対象の任意の小積で尽くされる。逆包含を確かめるには、積を値に取る小図式を考える。2.1 により各矢印は、終域の各座標について、始域の一座標とそこからの B の射を指定する。全ての座標を頂点とし、指定された射を辺として並べる。元の図式の極限は、この座標図式の各連結成分の極限を取った後の積である。実際、どちらの元も全辺で整合する族で、各関係は全座標で判定される。連結成分は集合個で、その極限は B に属する。図式に空構造が現れれば極限も空構造、座標が一つもなければ空積である。これで小極限閉性が分かる。逆に B とその積は定義により L に含まれる。

従って空構造以外の部分は形式的小積の圏 Prod(B) と同値である。ここで Prod(B) の対象は集合添字族で、射 (Aᵢ)→(Bⱼ) は各 j について i と Aᵢ→Bⱼ を一つずつ選ぶ。空積もこの記述に含まれる。非空な Q∈B を一つ固定する。Q から空構造に射はないので、Q の下の圏は

    (Q ↓ L) ≃ Prod(Q ↓ B)

となる。Q ↓ B の始対象 1_Q は厳密である。実際、f:Q→B′ から 1_Q への射 r は rf=1_Q を満たし、B の射 r はモノなので同型になる。

### 2.3 厳密な始対象を持つ圏の形式的小積

**補題。** 厳密な始対象 O を持つ局所小圏 D に対して、Prod(D) は抽象的に公理化可能でない。

公理化可能なら小さい稠密部分圏があり、従って同型を検出する対象の集合 G がある。G に現れる族の全成分のうち、O と同型でないものの集合を H とする。各 X≇O にはある H∈H から射がある。さもなければ、一成分の族の射 (O)→(X) に対して、全ての G=(Gⱼ) からの Hom は全単射になる。実際その Hom は、始対象成分一つにつき一元を持ち、それ以外の成分からは O にも X にも射がない。すると同型検出性から O≅X となってしまう。[公理化可能性と小さい稠密部分圏、p.412](https://cmuc.karlin.mff.cuni.cz/pdf/cmuc9602/adamek.pdf)

各 H∈H に対する射 (O,H)→(O) を、O 成分への射影とする。Y=(Yⱼ) がこの射に右直交する条件は、∏ⱼ(1 ⊔ D(H,Yⱼ)) が一点になることである。従って全ての射に右直交する対象は各成分が O と同型の族に尽きる。この充満部分圏は Set^op と同値である。

公理化可能な圏内で集合個の固定射への右直交性を課した充満部分圏は、公理化可能である。固定された始域・終域の全元を変数として量化し、準同型の正の原子図式と延長の存在・一意性を書くことで確かめられる。しかし Set^op は抽象的に公理化可能でない。前稿 §4 の濃度の証明では、どの仮想表示 E にも、ある強極限 μ で |E(X)|=μ となる対象が存在しないことが |Set(X,2)|=2^{|X|} から従う。一方、同じ μ で下方 Löwenheim–Skolem はサイズちょうど μ のモデルを与える。これで矛盾となる。[前稿 §4 の基数の選択と証明](lower_bound_trials.md)

最後に、抽象的に公理化可能な圏の Q の下の圏は、EQ の全元を定数で名付け、その正の原子図式を加えて公理化できる。Q の下の射は一般の準同型なので、異なる定数の値が一致することは許す。従って L が公理化可能なら Prod(Q↓B) も公理化可能となるが、補題に反する。

## 3. 完備フィルターの被約積を加えると、どのエピが壊れるか

局所的な条件で対象を加える別の試みとして、ある正則 κ≥λ を固定し、C₊ の対象の κ-完備フィルターによる被約積も許すことを考える。このとき、十分大きい各 Vη に対し、被約積 Y と **Vη → Y という相異なる二射**を実際に作れる。従ってこれらの対象と全 Σ-準同型を含むどの完備化でも、もとのエピ商族は真クラスのまま残らない。

Vη の元 a について、a を含むサイズ <κ の誘導部分構造 S が存在し、任意の C∈C₊ と任意の二射 u,v:S→C で u(a)=v(a) なら、(S,a) は a の像を決める。この性質を持つ点付き構造の各同型類は、Vη で高々一つの元の像しかこの意味で決められない。同じ型が二つの異なる元 a,a′ に対応すれば、同型と二つの包含を用いて、共通の S から Vη 自身への射で a の値が異なるからである。サイズ <κ の点付き Σ-構造の同型類の数を τ とすると、|Vη|>τ では、どの小さい部分構造でも像を決められない a がある。

I を Vη のサイズ <κ の部分集合全体とし、各 s∈I について s∪{a} の誘導構造から同じ Cₛ∈C₊ に入る二射 fₛ,gₛ で fₛ(a)≠gₛ(a) となるものを選ぶ。I は集合なので収集と選択で足りる。F を I 上の錐フィルター、すなわちある t∈I に対して {s:t⊆s} を含む部分集合の全体とする。κ の正則性から F は固有な κ-完備フィルターである。各 fₛ,gₛ をその定義域の外で任意の値によって集合写像に延長し、Y=∏ₛ Cₛ/F と置く。各関係は、それが成立する座標の集合が F に属するときに被約積で成立すると定める。この定義は関係の項数が <λ≤κ なので代表の変更で不変である。

二つの写像 x↦[s↦fₛ(x)] と x↦[s↦gₛ(x)] はともに準同型である。実際、Vη で真な一つの原子関係に現れる組は <κ 個の元からなり、それを含む s の錐上では関係が保存される。a での両者の値は全座標で相異なる。よって 0→Vη は Y によってエピでなくなる。この計算は κ をいくら大きく固定しても適用できる。F は一般のフィルターであり、任意の無限一階理論のモデル類がこの被約積で閉じるという主張は使っていない。

**この Y は、小極限閉包にすでにある積と射影だけの有向図式から作れる。** t∈I ごとに Pₜ=∏_{s∈I, t⊆s} Cₛ を取り、t⊆t′ に対して射影 Pₜ→Pₜ′ を使う。I は κ-有向である。Str(Σ) におけるこの図式の余極限は Y になる。各錐上の族は外側を任意の値で埋められ、二つの族が同じ元を表すのは、さらに小さい錐上で一致するときである。原子関係の成立も、ある錐上の全座標で成立することに一致する。従って、A.19 の全対象とその積を含み、真クラス個の 0→Vη をエピに保つ充満部分圏では、どの κ≥λ に対しても、母圏の κ-有向余極限で閉じないことをこの形の図式一つで検出できる。内部余極限が存在する場合には、包含がその余極限を保存しない。

## 4. どこまで排除したか

K と L は、同じ A.19 の射をエピに保ったまま完備にする二つの方法である。K は反射と小さい準同型の符号化で、L は座標超フィルターの主性と Q の下の圏で排除された。§3 の方法では、大きい Vη から出る二射が現れる場所を特定できる。両端 K,L を排除したことから中間の全ての充満部分圏については結論できない。一般の完備な公理化可能圏が通常のエピ商に関して co-wellpowered であるかも、これらの証明では決まらない。
