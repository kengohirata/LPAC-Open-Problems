# No.13　完備かつ公理化可能な圏は局所可呈示か

Adámek–Rosický の No.13 は、すべての小極限を持つ圏について、ある多ソート署名 Σ と、ある無限論理 \(L_{\lambda,\lambda}\) の集合個の公理からなる理論 \(T\) により \(\mathcal K\simeq\operatorname{Mod}(T)\) と表示できれば、局所可呈示性が従うかを問う。射はすべての Σ-準同型である。完備なアクセス可能圏は局所可呈示なので、問われているのはアクセス可能性である。原著は Vopěnka 原理の下での肯定と、それより弱い「任意に大きい強コンパクト基数が存在する」という仮定の下での肯定を挙げている。[原問題 p.297](https://doi.org/10.1017/CBO9780511600579.011)・[原著第2章、系 2.47](https://doi.org/10.1017/CBO9780511600579.005)・[Rosický (1994)](https://doi.org/10.1007/BF00878503)

完備性はモデル圏の内部で判定する。例えば定数 \(a,b\) と、公理 \(a\ne b\)、\(\forall x\,(x=a\lor x=b)\) を取る。任意の二つのモデルの間にちょうど一つの準同型があるので、各モデルが内部の終対象であり、この圏は完備である。一方、同じ署名の全構造の圏の終対象は一点で、二定数が一致する。この違いが No.4・10 の極限閉性と比較するときに効く。

**2026-11-19 の研究草稿。** No.11 の例から作った射影図式は、小極限閉包と誘導部分構造まで含む閉包との間の全ての充満部分圏で終対象を内部余極限に持つ。この計算を出発点に、No.13 を ZFC で肯定する証明案を得た。制限米田表示で公理化を保ち、固定対象の被約冪を扱った後、量化ランクが有界な型でフィルターの完備度を一様化する。再点検では、証人組を移す双方向の帰納法、一様化の商ブール代数による別証、可呈示対象の直接構成を加えた。現在の評価は「多分正しい」。別の研究者による検証・形式化・初出の確認は未実施である。[証明草稿と検証箇所](no13_reduced_products_proof_draft.md)

## ZFC でどこまで進めるか

1. **公理化可能性から解集合が得られる。** 任意の Σ-構造 \(X\) と準同型 \(X\to M\models T\) を取る。下方 Löwenheim–Skolem により、像を含み、\(T\) の部分式からなる固定した断片について初等的な部分構造 \(N\subseteq M\) を選べる。\(N\models T\) で、その濃度には \(X,\Sigma,T\) だけに依存する上界がある。従って \(X\to N\) の同型類には集合個の代表で足り、すべての \(X\to M\) がその一つを通る。これは No.6 の cone-reflectivity そのものである。[No.3 の小さい部分モデルの構成、§5](../No.3/positive_definability_and_local_submodels_2026-11-17.md)・[No.6 の解集合条件](../No.6/README.md)
2. **内部完備性から内部余完備性が従う。** 小図式 \(D\) の任意の余錐について、その脚の像をすべて含む小さい部分モデルを同様に取る。上界は図式の全対象の台集合の非交和と固定理論だけで決まるので、余錐の圏には弱始集合がある。また、モデル圏が完備なら、余錐の圏は頂点で極限を取って完備になる。Freyd の始対象定理により始余錐が存在する。従って \(D\) はモデル圏内で余極限を持つ。この証明は包含による極限の保存を仮定しない。
3. **ある正則基数 \(\kappa\) で有向余極限の保存を示せれば足りる。** 包含 \(\operatorname{Mod}(T)\hookrightarrow\operatorname{Str}(\Sigma)\) が \(\kappa\)-有向余極限を保存すると、2 によりモデル類は母圏のその余極限で閉じる。1 の解集合条件と原著の定理 2.53 からアクセス可能性が従い、系 2.47 で局所可呈示性を得る。必要に応じて \(\kappa\) を上げて母圏の可呈示ランクに合わせられる。[原著第2章、定理 2.53 と系 2.47](https://doi.org/10.1017/CBO9780511600579.005)

**有限項一階理論では ZFC で肯定される。** 原著の定理 5.23 は、モデル圏に存在する有向余極限を包含が保存することを示す。2 がその存在を保証するので 3 が適用できる。一般の無限論理でも、\(T\) が basic theory による表示を持てば定理 5.35 が直接アクセス可能性を与える。[原著第5章、定理 5.23・5.35](https://doi.org/10.1017/CBO9780511600579.008)

## No.7・11 と共通するコンパクト性の上界

固定した \(L_{\lambda,\lambda}\) 理論について \(\alpha=\max(\lambda,\aleph_1)\) と置く。Bagaria–Brooke-Taylor の定理 10 によれば、ある \(\kappa\) が \(\alpha\)-strongly compact なら、モデル圏に存在する \(\kappa\)-有向余極限は全構造の圏で計算できる。ここでの基数条件は、任意の \(\kappa\)-完備フィルターが \(\alpha\)-完備超フィルターに拡張すること。\(\kappa\) は必要に応じて正則基数まで上げてよい。従って上の 1–3 により、固定した理論には、その論理に対応する完備度が一つあれば足りる。[Bagaria–Brooke-Taylor, 定義 8・定理 10](https://arxiv.org/pdf/1202.5215)

特に **almost strongly compact 基数が任意に大きく存在すれば No.13 は肯定される**。各 \(\lambda\) に対して \(\alpha\) より大きいそのような基数を選べばよい。No.7 と No.11(b) の研究ノートにも同じ上界が現れる。No.11(b) ではエピ射の終域の元を決める図式の長さを抑え、ここでは内部の余極限と構造の余極限を一致させる。公刊文献の調査では No.13 一般の ZFC での決着を確認していない。[No.7 の上界](../No.7/compactness_upper_bound_and_failure_of_wvp.md)・[No.11(b) の上界](../No.11/epimorphisms_and_almost_strong_compactness.md)

## 下界を求める試行

No.11 の例 A.19 について、可測基数が有界なら、積と誘導部分構造で閉じた圏 K にも、小極限だけで閉じた圏 L にも、始対象から真クラス個のエピ商が残る。今回の証明では、K と L はどちらも署名を変更しても公理化できない。K には反射を用いた署名間の公理の移送を、L には積から出る射の座標分解を用いる。さらに、固定した完備度のフィルターによる被約積を加えると、十分大きいすべての Vη について元のエピ性が壊れる。[No.11 の二つの完備化と被約積の計算](no11_two_completions.md)

No.1・2 の作用を使う構成では、完備圏の族の局所可呈示性が almost strongly compact 基数の真クラス存在と同値になる。上と同じ署名移送は、この族の非局所可呈示な例にも適用できる。No.1 の平行二射例そのものの双対は、点付き前層を使うスライスの議論により、署名を変えても公理化できない。[下界の試行と各構成の証明](lower_bound_trials.md)・[反射による署名の移送、§1](no11_two_completions.md)

## 過去の反例を移す際に必要なこと

- **No.3・11(a)。** No.3 の小さい初等部分モデルによる因子化を強エピ射に適用すると、部分モデルの包含は同型になる。従って任意の公理化可能な圏は強エピ商について co-wellpowered である。固定対象が真クラス個の強商を持つ構成は、その性質だけで No.13 の仮定から外れる。[No.3、§5.3](../No.3/positive_definability_and_local_submodels_2026-11-17.md)・[No.11(a)](../No.11/README.md)
- **No.4・5・8・9・10。** 母圏の小極限で閉じる構成からは内部完備性が得られる。No.13 の反例に使うには、その圏に集合個の公理によるモデル表示を与え、圏自身が非アクセス可能であることを示す必要がある。元の包含の非反射性だけからはいずれも従わない。[No.4 の定義可能性の検討](../No.4/positive_definability_hulls_and_cardinal_bounds_2026-11-17.md)・[No.10 の直交類と反射性](../No.10/README.md)
- **No.1・2。** 双対圏で固定した少数の射に直交するという表示から、集合サイズの一階無限論理によるモデル表示への移送が必要になる。テストの本数だけではこの移送を与えない。[No.1・2 の定式化](../No.2/p1_p2_measurable_wvp_almost_compact_2026-11-17.md)
- **No.12。** 等化子と pure 射が現れる文献上の接点がある。Adámek–Rosický (1996) は VP の下で、等化子を持つ圏の公理化可能性・アクセス可能性・小さい稠密部分圏の存在が同値になることを示す。No.13 の VP による肯定もここから従う。No.12 の反例圏は既にアクセス可能で、完備なら系 2.47 が適用される。[1996年論文、pp.412–413](https://dml.cz/handle/10338.dmlcz/118845)・[No.12 の反例](../No.12/README.md)
