# No.13 の巨大基数下界を試す

2026-11-19。以下の二つの構成は、対象を「拡大署名の理論のモデルの還元であり、射は元の署名の全準同型」とするところまで進む。この条件をここでは擬初等的と呼ぶ。No.13 は、ある理論のモデルと**その署名の全準同型**の圏への同値を要求する。以下はこの区別を保った研究上の導出であり、No.13 自体から可測基数の存在を導くところまで到達していない。

**同日の続稿。** §1 の K について本稿に残る別署名での公理化の可能性は、反射を利用して排除できる。続稿ではさらに小極限閉包を計算し、被約積を加えたときに元のエピ性を壊す二射を構成した。[No.11 の二つの完備化と被約積](no11_two_completions.md)

## 1. No.11 のエピ商を完備化しても残せる

ある非可算正則基数 λ 以上に可測基数がないとする。原著の例 A.19 は、推移的な ZC モデルと λ-初等埋め込みに形式的始対象を加えた圏である。極限基数 η に対して、任意の対象への Vη からの射が高々一本になることが、そこでの可測基数の使い方である。元の圏には終対象がない。いかなる集合サイズのモデルにも、それより大きい Vη からの埋め込みは存在しない。[原著、例 A.19](https://doi.org/10.1017/CBO9780511600579.010)

これを一つの**関係署名** Σ で表示する。対象は整礎・外延的な ZC モデルで、整礎性には可算降下列の不存在を使う。Mostowski 崩壊により推移的表示と同値である。Lλ,λ の各式にその真理を表す関係記号を加える。否定を含む全式を使うので、準同型はちょうど λ-初等埋め込みになる。式は変数の改名を除いて集合個で足りる。零項記号を避けるため文の真理は余分な一変数を持つ関係で符号化できる。空構造を別の場合として許すと、形式的始対象 I が実現される。この公理化可能なモデル類を C とする。

**構成。** K を、C の対象の任意の小積の誘導部分構造に同型な構造すべてと、全 Σ-準同型からなる圏とする。空積も含む。K は積と等化子で閉じ、完備である。I は引き続き始対象である。各 η について、二つの射 Vη → B があるとする。B を積の部分構造として表示し、各座標に射影すると、例 A.19 により二射は一致する。座標への射影が元を分離するので、元の二射も一致する。空積への二射の一致も成立する。よって I → Vη はすべて K 内のエピ射である。Σ-構造の同型が台集合の濃度を保存するので、固定した I が真クラス個の異なるエピ商を持つ。局所可呈示圏は co-wellpowered なので K は局所可呈示でない。さらに K は全構造の圏で反射的である。任意の X から C の対象への射は、下方 Löwenheim–Skolem により X だけから決まる上界以下の対象への射を経由する。その代表全部への評価写像の像に、積からの**誘導構造**を与えると反射が得られる。空の射族も空積で扱える。従ってこの例には余完備性もある。[局所可呈示圏の商、原著第1章](https://doi.org/10.1017/CBO9780511600579.004)

**モデル表示の検査。** K は擬初等的である。追加ソートに添字集合 J と J 上のファイバー Cⱼ を置き、各ファイバーに C の公理を相対化する。空ファイバーは別途許せる。評価写像 e(j,x)∈Cⱼ を置き、異なる x,y はある座標で分離され、各関係 R の各組について R(x̄) ⇔ ∀j Rⱼ(e(j,x̄)) と書く。J が空なら分離公理は台を高々一点に制限し、全関係が成り立つ。この還元がちょうど K である。

**元の署名での公理化を排除できる。** 一般に、誘導部分構造で閉じ、集合サイズの無限理論 T で公理化できる関係構造のクラスでは、非モデルはすべて、一様な基数以下の非モデルを誘導部分構造に持つ。非モデルで偽の公理を保つ小さい初等部分構造を取ればよい。十分大きい正則 κ に対して、このクラスは全構造の κ-有向余極限で閉じる。実際、余極限中の小さい非モデルの全元を段階に持ち上げ、そこで必要な正の原子関係を同時に成立させる。否定された原子関係や相異性は余極限への準同型から段階へ戻る。小構造と署名のサイズおよび関係の項数から、必要な原子の数にあらかじめ上界を取り、その上に κ を選べる。こうして非モデルが一段階に誘導部分構造として埋め込まれてしまう。下方 Löwenheim–Skolem からは解集合条件も出るので、原著の定理 2.53 によりこのクラスはアクセス可能である。従って上の完備な K にはこの署名での公理化は存在しない。別署名のモデル圏への**抽象的な同値**の可能性はこの論証に残る。[原著、定理 2.53](https://doi.org/10.1017/CBO9780511600579.005)・[同、定理 5.41](https://doi.org/10.1017/CBO9780511600579.008)

## 2. No.1・2 の reduced power を完備な圏に入れる

無限集合 Ω の濃度を ρ、M=End(Ω)、δ=ρ⁺ とする。Kρ は Ω の冪の部分 M-集合全体であり、射は M-同変写像とする。Ω への射が異なる元を分離することと同値で、空積の一点も含む。Kρ は積・等化子で閉じる。また、すべての M-集合 X について、全射 X → im(X → Ω^Hom(X,Ω)) が反射を与える。特に余極限は母圏で取ってから反射すればよい。

**判定。** ZFC で、次の条件は同値になる。

1. Kρ は抽象的な圏として局所可呈示。
2. ある κ ≥ δ が存在し、任意の固有な κ-完備フィルターは δ-完備超フィルターに延長される。

**1 ⇒ 2。** 左正則 M-集合 M は Ω^Ω そのものなので Kρ に属し、台集合関手を表現する。1 の下で M はある正則 κ について κ-可呈示である。κ は |M| を超えるまで大きくしてよい。従って Kρ の κ-有向余極限を台集合関手が保存し、母圏の M-集合としても同じ余極限を与える。

任意の固有な κ-完備フィルター F に対し L=Ω^I/F を取る。サイズ <κ の部分 M-集合 Y の全元に代表関数を選ぶと、すべての作用等式が同時に座標ごとに成立する添字の集合は F に属する。異なる二元の代表が一致する集合は F に属さないので、この作用等式の集合内に、二元が異なる座標がある。そこで評価すれば Y → Ω が得られ、その二元を分離する。従って Y は Kρ に属する。L はこれらの Y の κ-有向合併であり、1 の下では L 自身が Kρ に属する。相異なる二つの定数列を使えば L → Ω が存在する。No.2 の reduced power の計算により、その射は F を延長する δ-完備超フィルターを与える。[No.2、§1・3](../No.2/p1_lower_bound_reduced_powers_accessibility_boundary_2026-11-17.md)

**2 ⇒ 1。** κ を |M| より大きい正則基数に上げる。X のサイズ <κ の部分 M-集合がすべて Kρ に属するなら X も Kρ に属する。実際、x≠y を固定し、サイズ <κ で x,y を含む部分 M-集合の κ-有向集合上で、各後方集合を含む δ-完備超フィルターを 2 により選ぶ。各段階の x,y を分離する評価を取り、超フィルターに沿って値を取ると X → Ω が得られる。|Ω|<δ により各元の値が一意に定まり、各作用等式と x,y の相異性が保たれる。κ-有向図式の母圏での余極限において、サイズ <κ の部分 M-集合は一段階に埋め込める。各元の代表と |M|·|Y| 個の作用等式を同時に持ち上げ、余極限への合成が元の包含となることを使う。従って Kρ はその余極限で閉じている。各対象はサイズ <κ の部分 M-集合の κ-有向合併で、それらは κ-可呈示である。従ってアクセス可能であり、完備性から局所可呈示である。

すべての ρ に対する 2 は「almost strongly compact 基数が任意に大きく存在する」と同値である。特に可測基数が ρ より上に存在しない場合は、任意の大きい正則 κ で κ 上の余小フィルターが反例になる。δ-完備な延長は非主的であり、超フィルターに属さない集合による最小分割に押し出せば ρ より大きい可測基数が得られるからである。[Brooke-Taylor–Rosický、定義 2.3・命題 2.4](https://arxiv.org/pdf/1506.01986)・[No.2 の可測基数への移送](../No.2/p1_p2_measurable_wvp_almost_compact_2026-11-17.md)

**何を公理化できるか。** Kρ は、テストのソート W と評価 ev:W×X → Ω を加え、「各テストは同変」「異なる二元を分離するテストがある」と書けば還元のクラスとして定義できる。Ω は ρ 個の名前とその選言で固定する。しかし 2 が失敗する場合、元の M-作用の言語には公理化がない。どんな候補理論にも十分大きい κ と延長不能な F を取り、L の小さい初等部分構造を取ると、上の分離計算によりそれはモデルだが L は非モデルとなる。

**テストを持たせたまま射に共変な W 成分を付ける試みも失敗する。** この拡大モデルの圏には終対象がない。X が空で W が一点のモデルからの射を数えると、終対象の W は一点となるはずである。一方、X=M に Ω の各点での評価をすべて持たせたモデルを取る。これらのテストは関数を分離し、恒等関数上で異なる値を取る。終対象への射はそれらのテストをすべて同じテストに送り、同時に名前付きの評価値を保存するはずなので矛盾する。

## 3. 元の例のまま移せるか

- No.2 の Nρ={∅}∪{X : Hom(X,Ω)=∅} は coreflective なので完備で、2 が失敗すれば非アクセス可能になる。しかしこの場合には**どんな署名でも**公理化可能にならない。実際、公理化可能な圏は小さい稠密部分圏を持つ。その代表の元の M-集合としてのサイズを μ で抑える。稠密表示で非空な null act X に入る射には非空な代表を始域とするものが必要である。空対象だけの図式の余極限は空だからである。その像は非空なサイズ ≤μ の null subact になる。No.2 の §5 (B)⇒(C) によりこの条件はまさに 2 を含意する。旧ノートの (C)⇒(A) とアクセス可能圏の basic theory 表示を合わせると、Nρ では抽象的公理化可能性とアクセス可能性は同値である。[No.2 の証明](../No.2/p1_lower_bound_reduced_powers_accessibility_boundary_2026-11-17.md)・[公理化可能圏の boundedness、p.412](https://cmuc.karlin.mff.cuni.cz/pdf/cmuc9602/adamek.pdf)
- No.1 の順序数による非余反射的な左直交類 A の場合も、もとの向きでは小さい稠密部分圏を持てない。一般に、小さい稠密部分圏 G を持つ余完備圏 A からの余極限保存関手 F:A→D（D は局所小）は右随伴を持つ。制限米田埋め込み E:A→Psh(G) の左随伴 L を取り、FL の右随伴を R(d)(g)=D(Fg,d) と書く。R(d) は L が同型に送るすべての射に直交するので E の本質像に属し、F の右随伴を与える。No.1 の包含はすべての小余極限を保存するため、既存の非余反射性の証明を採用する限り A の抽象的公理化可能性は排除される。双対の圏は §4 の別の議論で排除する。[No.1・2 の反例](../No.2/p1_p2_measurable_wvp_almost_compact_2026-11-17.md)
- No.3 の真クラス個の**強**エピ商を持つ候補は、モデル圏の強商に対する下方 Löwenheim–Skolem 上界で排除できる。§1 の Vη が与えるのは通常のエピ商である。この違いにより、§1 の候補は同じ議論で排除されない。[No.3、§5](../No.3/positive_definability_and_local_submodels_2026-11-17.md)

以上から、「完備な擬初等的なクラスが、還元の間の全準同型に関して局所可呈示」という命題には、§1 から可測基数の真クラスが、§2 からさらに almost strongly compact 基数の真クラスが必要である。No.13 自体の下界には、ある理論 S のモデル圏への同値を満たす例が必要である。§1 の K ではそのような同値を排除できることを続稿 §1 で示した。[別署名による表示の検討](no11_two_completions.md)

## 4. No.1 の平行二射例の双対も、署名を変えて排除できる

ここではまず ZFC で使える濃度の判定を示す。具体圏 B の対象のサイズを b(X) とし、各サイズ上界以下には同型類が集合個しかなく、サイズは非有界とする。ある固定対象 Q があって、十分大きいすべての X で次を満たすと仮定する。

    |B(X,Q)| ≥ 2^{b(X)}.

このとき B の双対は、どの集合署名によっても公理化可能でない。実際、E:B^op ≃ Mod(T) があると仮定し、e(X) を E(X) の全ソートの濃度の和とする。言語・理論・項数・量化の幅・e(Q) を一つの無限基数 θ で抑える。十分大きい強極限基数 μ で、cf(μ)>θ かつ b(X)<μ ⇒ e(X)<μ となるものを取れる。具体的には長さ θ⁺ の狭義増大基数列を作り、各後続段を、前段の冪集合の濃度と、前段のサイズ以下の全代表の e(X) の上限より大きくする。その上限 μ は所要の性質を持ち、μ^θ=μ である。

b(X)≥μ なら E(Q)→E(X) という準同型の個数が少なくとも 2^μ なので、e(X)≤μ は不可能である。その場合、ソートごとの写像を全部数えても μ^θ=μ 個だからである。b(X)<μ なら e(X)<μ であり、結局 e(X)=μ の対象が存在しない。一方、モデルの濃度は非有界である。μ より大きいモデルで μ 個の元を取り、それを含む初等部分モデルを作ると、μ^θ=μ よりその濃度はちょうど μ になる。矛盾。これは選んだ具体表示での反例から、任意の仮定されたモデル表示 E を排除する議論である。例えば B=Set では Q=2 で足りる。

次に、小さい非空圏 D 上の前層圏 P と、指定した大域点を持つ前層の圏 B=(1↓P) を考える。b(X) を各ソートの濃度の和とする。各ソートの評価関手の右随伴を R_d とし、Q=∏_d R_d(2) に恒等的に色 0 を与える大域点を選ぶ。点を保つ X→Q は、全ソートの全元を二色で塗り、指定された元だけは各ソートで 0 とする方法にちょうど対応する。b(X)>|Mor D|+ℵ₀ ならその個数は 2^{b(X)}。従って (1↓P)^op は公理化可能でない。

一方、公理化可能な圏の任意のスライスは公理化可能である。固定対象 B への射を、その各ソートの各 b∈B に対応する色述語で符号化し、各元がちょうど一色を持ち、色の割当てが準同型であることを公理化する。色は集合個なので論理のランクを上げればよい。色を保つ全準同型がちょうどスライスの射になる。

No.1 の圏 A は有限支持条件を含む母圏 K_fs 内で H(p_Z) が全単射となる平行二射 Z の圏であった。終対象 1 は A に属する。1→Z があれば両成分に M-固定点がある。Ω には M-固定点がないため H(Z₀)=H(Z₁)=∅ となり、H(p_Z) の条件は自動的に成立する。従って (1↓A)=(1↓K_fs)。K_fs は小さい非空圏上の前層圏なので、直前の濃度の判定から

    A^op / 1 ≃ (1↓K_fs)^op は公理化可能でない。

スライスに関する結果の対偶から、A^op 自身も ZFC で公理化可能でない。同じ証明で Nρ^op も排除できる。こちらは 1 の下に入ると任意の点付き M-集合が null であり、(1↓Nρ)=(1↓M-Set) となるためである。[有限支持の母圏の前層表示、§1.2](../No.2/p1_p2_measurable_wvp_almost_compact_2026-11-17.md)・[原著、下方 Löwenheim–Skolem 定理](https://doi.org/10.1017/CBO9780511600579.008)

## 5. 弱 Vopěnka 原理は下界にできない

集合パラメータ付き定義可能クラスについてのスキーマとして考える。A を「almost strongly compact 基数が真クラス存在する」とする。ZFC+A の無矛盾性を仮定すると、No.13 が成立し WVP のあるインスタンスが失敗するモデルがある。No.7 で用いた分離をそのまま適用できる。実際、WVP があれば、Wilson の特徴づけにより、A の論理的複雑さに十分な n に対する閉非有界クラス {α : Vα ≺Σₙ V} に強到達不能基数 η を取れる。A も仮定すれば Vη は ZFC+A のモデルである。従って ZFC+A+WVP は Con(ZFC+A) を証明する。一方、第二不完全性定理により ZFC+A+¬Con(ZFC+A) は相対的に無矛盾であり、そのモデルでは WVP の当該有限個のインスタンスのいずれかが失敗する。A はこのモデルでも No.13 を含意する。従って No.5・10 のような WVP への逆含意は得られない。この分離は可測基数が真クラスあることの必要性を判定しない。[Wilson の特徴づけ](https://arxiv.org/abs/1907.00284)・[No.7 の反映と無矛盾性の議論](../No.7/compactness_upper_bound_and_failure_of_wvp.md)・[No.13 の上界](README.md)
