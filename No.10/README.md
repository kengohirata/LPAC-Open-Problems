# No.10　等化子で閉じる入射性類は直交類か

**2026-11-19 の進展。** No.5 の非反射的直交類を用い、No.10 の全称命題が弱 Vopěnka 原理と同値になる証明案を得た。逆向きには、空の族を入射性テスト一本で排除し、同じ空の族がすべての共通直交性テストを通る前層圏の例を構成した。No.7 の肯定は不要である。CompHaus の反例との関係も証明の §5 に記した。プロジェクト内での導出であり、独立検証前である。[証明全文](no10_wvp_from_nonreflective_orthogonality.md)

Adámek–Rosický, *Locally Presentable and Accessible Categories*, Open Problems, p.297。局所可呈示圏 \(\mathcal K\) の入射性類 \(\mathcal C=\operatorname{Inj}(H)\) が \(\mathcal K\) の等化子で閉じるとき、ある射のクラス \(S\) について \(\mathcal C=S^\perp\) と書けるか。\(H,S\) には真クラスを許す。等化子閉性は、\(C,D\in\mathcal C\) と平行射 \(C\rightrightarrows D\) に対する条件である。[原著 p.297](https://doi.org/10.1017/CBO9780511600579.011)

射 \(u:A\to B\) に対するテストは、前合成 \(\mathcal K(B,X)\to\mathcal K(A,X)\) である。入射性では全射性、直交性では全単射性を要求する。結論ではテストの取り替えができる。例えば Set で二点集合から一点集合への任意の写像の切断 \(1\to 2\) をテストに取ると、すべての集合が入射的になる。二点集合自身では延長が一意にならないが、この入射性類 Set は空のテスト族に対する直交類である。

## 肯定が分かる範囲

- **弱 Vopěnka 原理（WVP）の下。** 入射性類は空積を含む小積で閉じる。各成分で選んだ延長を積にまとめればよい。等化子閉性を加えるとすべての小極限で閉じ、原著の定理 6.22 により包含は反射的になる。反射射 \(Y\to RY\) 全体を \(S\) とすれば \(\mathcal C=S^\perp\) である。これは原著が No.10 に添えた肯定方向である。[原著第6章、定理 6.22](https://doi.org/10.1017/CBO9780511600579.009)
- **\(H\) が集合なら ZFC で肯定。** 全テストの始域・終域が一様に \(\lambda\)-可呈示になる十分大きい非可算正則基数 \(\lambda\) を取り、母圏も局所 \(\lambda\)-可呈示となるように選ぶ。すると \(\operatorname{Inj}(H)\) は \(\lambda\)-有向余極限で閉じる。実際、始域から余極限への射を一つの段階に通し、そこで延長できる。小極限閉性と合わせれば小直交類になる。従って一般の場合に残るのは、集合個のテストによる入射性表示を持たない場合である。[Hébert, §3.4(c)](https://www.kurims.kyoto-u.ac.jp/EMIS/journals/TAC/volumes/12/12/12-12.pdf)

## これまでの問題との関係

**No.7 が最も直接につながる。** 小極限で閉じる充満部分圏は積とレトラクトで閉じる。後者は冪等射と恒等射の等化子を取れば分かる。従って No.7 が成り立つと、そのような部分圏はすべて入射性類であり、No.10 を適用できる。逆に「局所可呈示圏の極限閉充満部分圏はすべて直交類」と仮定すれば、積・等化子による極限の表示から直ちに No.10 が従う。**従って No.7 の下では、No.10 はこの極限閉部分圏全般に関する主張と同値である。** 後者を直接扱った先行研究が Adámek–Rosický (1992) である。No.7 の既存の反例では部分圏が入射性類であるという出発条件が失敗する。[No.7 の記録](../No.7/README.md)・[Adámek–Rosický (1992)](https://www.muni.cz/en/research/publications/196741)

## 一般の場合の判定

\(S_{\mathcal C}\) を、\(\mathcal C\) の全対象への前合成が全単射になる射のクラスとする。\(S_{\mathcal C}^{\perp}\) は \(\mathcal C\) を含む最小の直交類である。従って反例を構成するには、等化子で閉じる入射性類 \(\mathcal C\) と、\(X\in S_{\mathcal C}^{\perp}\setminus\mathcal C\) を同時に与える必要がある。特に \(X\) は、\(\mathcal C\) の全対象が満たすある入射性テストには失敗するが、共通の直交性テストはすべて通る。この違いが No.8 の証人を移す際の障害となる。

もう一つの判定は、\(\mathcal C\) を含み、小極限と \(\alpha\)-有向余極限で閉じる最小の充満・同型閉部分圏を各ランクで作ることにより得られる。これらを十分大きい正則基数 \(\alpha\) 全体で交差すると \(S_{\mathcal C}^{\perp}\) になる。[Hébert, Corollary 4.5・Remark 4.6](https://www.kurims.kyoto-u.ac.jp/EMIS/journals/TAC/volumes/12/12/12-12.pdf)
