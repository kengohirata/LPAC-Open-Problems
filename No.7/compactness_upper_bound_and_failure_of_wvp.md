# No.7 の compactness 上界と WVP が成り立たない場合

2026-11-19。\(P_7\) を原著の No.7、\(A\) を「almost strongly compact 基数が任意に大きく存在する」という一階の文とする。以下では \(A\Rightarrow P_7\) を直接導く。集合パラメータ付き定義可能クラスを使う ZFC のスキーマでは、ZFC+\(A\) の無矛盾性から、\(A\) と \(P_7\) が成立し WVP のあるインスタンスが失敗するモデルの存在も従う。以下の No.7 への適用と無矛盾性の帰結は今回の導出で、独立検証前である。

## 積に入れる射の選び方

\(\mathcal K\) は局所可呈示、\(\mathcal C\) は小積とレトラクトで閉じる充満部分圏とする。\(H(\mathcal C)\) はすべての \(\mathcal C\)-対象が入射的になる射のクラスである。\(X\in\mathrm{Inj}(H(\mathcal C))\) を固定して \(X\in\mathcal C\) を示す。

局所可呈示圏の標準的な表示を取り、充満忠実な右随伴 \(N:\mathcal K\to\widehat D\) と左随伴 \(L\) を使う。ここで \(D\) は小圏で \(\widehat D\) はその前層圏、\(LNX\cong X\) である。例えば小さい可呈示対象の充満稠密部分圏に関する制限米田埋め込みが使える。前層のサイズには全ソートの元の総数を使う。

非可算正則基数 \(\delta>|NX|,|\mathrm{Mor}(D)|\) を取る。\(A\) により、正則 \(\kappa>\delta\) で、任意の \(\kappa\)-完備フィルターが \(\delta\)-完備超フィルターに延長できるものがある。正則にするには、まずこの性質を満たす基数を取り、それより大きい後続基数に上げればよい。[Brooke-Taylor–Rosický, Definition 2.3, Proposition 2.4](https://arxiv.org/pdf/1506.01986)

1. \(NX\to B\) で \(|B|<\kappa\) となるものの同型類の代表集合を \(S\) とする。各 \(f:X\to C\)、\(C\in\mathcal C\) に対し、\(Nf\) がその射を通じて因子化するような \(S\) の元の集合を \(T(f)\) と置く。実現される \(T(f)\) は \(\mathcal P(S)\) の部分集合である。各 \(T\) につきそれを実現する射 \(f_T:X\to C_T\) を一つ取る。実現射の最小ランクに制限して集合上で選べる。
2. \(P=\prod_T C_T\) と \(p=\langle f_T\rangle:X\to P\) を取る。\(P\in\mathcal C\) である。\(Np\) の像を含むサイズ \(<\kappa\) の部分前層 \(B\subseteq NP\) を取り、誘導射を \(b:NX\to B\) とする。射影 \(NP\to NC_T\) を \(B\) に制限すると、すべての \(T\) について \(Nf_T\) は \(b\) を通じて因子化する。従って任意の \(f:X\to C\) も、その \(T(f)\) の定義から \(Nf\) が \(b\) を通じて因子化する。
3. 随伴によってこれは \(Lb:X\cong LNX\to LB\) が \(H(\mathcal C)\) に属することを意味する。\(X\in\mathrm{Inj}(H(\mathcal C))\) なので \(\mathrm{id}_X\) は \(Lb\) に沿って延長する。随伴で前層に戻すと \(r_B:B\to NX\) で \(r_B b=\mathrm{id}_{NX}\) を得る。こうして選んだ \(r_B\) 同士の整合性は仮定しない。

## 一つのレトラクションを作る

上記の \(B\) の集合を包含で順序付けて \(I\) とする。\(I\) は \(\kappa\)-有向であり、\(NP\) の全要素を覆う。実際、\(<\kappa\) 個の元と \(Np\) の像を入れ、\(D\) の制限写像で閉じてもサイズは \(<\kappa\) である。上方錐が生成する \(\kappa\)-完備フィルターを \(\delta\)-完備超フィルター \(\mathcal U\) に延長する。

各 \(y\in NP(d)\) について、\(y\in B(d)\) を満たす \(B\) は \(\mathcal U\)-大である。その上で \(r_B(y)\) は \(\delta\) 個未満の値しか取らないので、\(\mathcal U\)-ほとんどすべての \(B\) に共通する一意な値 \(r(y)\in NX(d)\) がある。各制限写像について \(r_B\) の自然性を使えば \(r:NP\to NX\) は自然変換である。\(r_B b=\mathrm{id}\) から \(r\,Np=\mathrm{id}_{NX}\) も従う。\(N\) は充満忠実だから \(p\) は分裂し、\(X\) は \(P\) のレトラクトとなる。これで \(\mathcal C=\mathrm{Inj}(H(\mathcal C))\) が従う。□

No.1 と共通なのは、固定した小さい値域に対する局所解を完備超フィルターで一つにまとめる段階である。No.7 では、局所解を得る前に \(T(f)\) ごとに代表を選んで積を取る必要がある。No.1 の肯定を仮定する箇所はない。[No.1 の compactness 上界 §3](../No.2/p1_p2_measurable_wvp_almost_compact_2026-11-17.md)

## 可測基数が任意に大きく WVP が失敗する場合

まず、従来の被約冪の反例にどんな変化が起きるかを直接確認できる。前稿の \(\rho=|\Omega|\) より大きい可測基数 \(\mu\) を一つ取る。\(\mu\) 上の非主的 \(\mu\)-完備測度による値の評価は、定数列を元の値に送り、\(<\mu\) 個の座標の変更で値が変わらず、\(\Omega\) の全自己写像と可換である。従って \(\Omega\to Q_\mu\) は分裂する。元の族は \(Q_\mu\) を含むため、その積・レトラクト閉包には実際に \(\Omega\) が入る。この対象は当該領域での反例の証人には使えない。

さらに \(A\) が成り立てば、上の証明は WVP の成否によらず適用できる。そのような WVP の失敗には次の相対無矛盾性の裏付けがある。\(T=\mathrm{ZFC}+A\) とし、集合パラメータ付き定義可能クラスを採用する。

- WVP の下で、定義可能な閉非有界クラス \(E\subseteq\mathrm{Ord}\) は強到達不能基数を含む。Wilson の定理で \(E\)-strong な \(\eta\) を取る。もし \(E\cap\eta\) が有界なら、\(\gamma\in E\) を \(\gamma>\eta\) とし、後続順序数 \(\beta>\gamma\) で \(E\)-strongness を目撃する \(j\) を \(j(\eta)>\beta\) と取る。すると \(j(E)\cap j(\eta)=j(E\cap\eta)=E\cap\eta\) である一方、\(j(E)\) は \(\beta\) 未満で \(E\) と一致し \(\gamma\) を含む。矛盾である。よって閉性から \(\eta\in E\) であり、臨界点 \(\eta\) は可測基数である。[Wilson, Definitions 1.3–1.5, Theorem 1.6、後続順序数での強さに関する注記](https://arxiv.org/pdf/1907.00284)
- \(A\) の論理的複雑さに十分な有限の \(n\) を固定し、Lévy 反映による閉非有界クラス \(E=\{\alpha:V_\alpha\prec_{\Sigma_n}V\}\) に適用する。\(A+\mathrm{WVP}\) の下では、得られた \(V_\eta\) が ZFC と \(A\) をともに満たす。従って \(T+\mathrm{WVP}\) は \(\mathrm{Con}(T)\) を証明する。ここでは一つの固定した \(E\) についての Wilson の定理だけを使う。[Bagaria–Wilson, §3 の \(C^{(n)}\)](https://arxiv.org/pdf/2012.11202)
- \(T\) が無矛盾なら、第二不完全性定理により \(T+\neg\mathrm{Con}(T)\) は無矛盾である。そのモデルでは上記の推論に使った有限個の WVP インスタンスがすべて成立することはできない。一方、\(A\) により \(P_7\) の各インスタンスが成立し、前稿の下界により可測基数も任意に大きく存在する。このモデル論的帰結は推移的モデルの存在を主張しない。

従って \(T\) の無矛盾性を仮定すると \(P_7\Rightarrow\mathrm{WVP}\) は一般に成立しない。「可測基数が任意に大きい」と「WVP のあるインスタンスが失敗する」の二仮定だけで \(P_7\) が常に成り立つか、その領域にも否定例があるかは、ここでの議論からは決まらない。

## Π₂-strong 上界の適用範囲

No.1 の証明では、**集合個のテスト**をパラメータとして、固定標的上の同値射のクラスを \(\Pi_2\) で記述し、Bagaria–Wilson の積反映を適用する。No.7 で直接積反映を適用したいのは、各 \(X\) に対する射 \(X\to C\)、\(C\in\mathcal C\) のクラスである。このクラスに積反映があれば、得られる積は弱反射になり、レトラクト閉性で結論が出る。しかし \(\mathcal C\) の定義複雑性には仮定がない。従って No.1 の \(\Pi_2\) 計算だけでは一般の \(P_7\) に届かない。射のクラスが集合パラメータ付き \(\Pi_2\) で符号化でき積を保存する構造表示がある場合には、その制限版に同じ手法が使える。例えば前層圏で、\(\Pi_2\) で定義できる部分圏に対しては、\(X\) の元に定数記号を加えた構造を使える。[No.1 の積反映による証明](../No.2/p1_restricted_product_reflection_pi2_strong_2026-11-17.md)・[Bagaria–Wilson, Definition 3.1 と主定理](https://doi.org/10.1017/jsl.2022.42)
