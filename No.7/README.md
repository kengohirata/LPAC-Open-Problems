# No.7　積とレトラクトで閉じる部分圏は入射性類か

Adámek–Rosický の No.7 は、局所可呈示圏 K の充満部分圏 C が任意の小積（空積を含む）と分裂部分対象で閉じるとき、C を射のクラスに関する入射性で定義できるかを問う。弱 Vopěnka 原理（WVP）の下では肯定される。一方、非可算可測基数が存在しないとき、No.5(b) のアーベル群の例が No.7 の反例にもなる。後者には、公刊された弱非反射性の結果に加えて、下記の座標を用いた補題を使う。[原問題 p.296](https://doi.org/10.1017/CBO9780511600579.011)・[Casacuberta–Gutiérrez–Rosický, Proposition 2.6](https://www.ub.edu/topologia/casacuberta/articles/cgr.pdf)

**上界の更新。** almost strongly compact 基数が任意に大きく存在すれば、一般の No.7 が肯定される。この仮定と ZFC の無矛盾性に相対的に、可測基数が任意に大きく存在し、No.7 が成立し、WVP が失敗するモデルがある。No.1 のもう一つの上界である Π₂-strong 基数の真クラスから一般の No.7 への含意は未確定である。今回の導出は独立検証前である。[compactness 上界の証明と WVP の分離](compactness_upper_bound_and_failure_of_wvp.md)

**中間領域を調べるための還元。** 一般の No.7 と、集合個の成分の非交和上で指定したすべての上方錐を含む完備超フィルターが存在するという条件との同値を導出した。各成分が個別に延長を持たないとき、残る場合は成分の添字に非主的な完備超フィルターが誘導される積である。独立検証前。[同値の両方向と反例候補](fine_ultrafilters_on_disjoint_unions.md)

## 何を示せばよいか

非交和による判定の最初の例は、指定した完備性を超える最初の可測基数 μ の直下で計算できる。各成分で最小の失敗濃度を選ぶと、μ 個を合わせて初めて成功する。同じ添字でも成分の濃度を一様に引き上げると、μ で当該フィルター延長性が失敗するという仮定の下で、すべての持ち上げを排除できる。[正規測度による構成と押し出しによる否定](first_measurable_index_size.md)

射 u∶U→V に対して、対象 X が u-入射的であるとは、各 f∶U→X が g∶V→X により f=gu と書けること、すなわち K(V,X)→K(U,X) が全射であることをいう。射のクラス H のすべての元に入射的な対象の類を Inj(H) と書く。No.7 では H が真クラスでもよく、u の単射性も仮定しない。

Inj(H) は ZFC で積とレトラクトに閉じる。積への射は各成分で延長でき、レトラクトへの射は大きい対象で延長してから引き戻せるからである。逆向きが No.7 である。H(C) を「すべての C の対象が入射的になる射全体」とすると、C⊆Inj(H(C)) である。任意の表示 C=Inj(H) があれば H⊆H(C) なので、等号 C=Inj(H(C)) が成り立つ。したがって反例には、C の外にありながら H(C) のすべての射に入射的な対象 X を一つ示せばよい。

## WVP が与える肯定方向

原著の定理 6.26 と注意 6.27(2) により、同注意の原理 (*) の下で、積とレトラクトで閉じる C は弱反射的である。Wilson により (*) は WVP と同値である。各 X の弱反射 r∶X→Cₓ に対して、すべての C の対象は r-入射的である。X 自身も r-入射的なら、恒等射が r を通じて延長でき、X は Cₓ のレトラクトになる。従って C=Inj(H(C)) を得る。注意 6.27(3) は、定理の三条件すべての同値と、No.7 の含意単独の集合論的強さを区別している。[原著 §6.D、定理 6.26・注意 6.27](https://doi.org/10.1017/CBO9780511600579.009)・[Wilson, Theorem 1.4](https://arxiv.org/abs/1909.09333)

## No.5(b) の例を No.7 の反例にする

無限基数 κ について、Qκ を ℤ の κ 個の直積を、台の濃度が κ 未満の列の部分群で割ったものとする。C は Qκ 全体の積とレトラクトによる閉包とする。非可算可測基数が存在しないとき、Casacuberta–Gutiérrez–Rosický の命題 2.6 の証明は、ℤ が C への弱反射を持たないことを示す。特に ℤ∉C である。ℤ∈C なら恒等射が弱反射になるからである。[命題 2.6 とその証明](https://www.ub.edu/topologia/casacuberta/articles/cgr.pdf)

**補題（ZFC）。** アーベル群の射 u∶U→V と、max(ℵ₀, |U|, |V|) より大きい正則基数 κ を取る。Qκ が u-入射的なら、ℤ も u-入射的である。

**証明。** 任意の f∶U→ℤ を取り、定数列の対角射 d∶ℤ→Qκ と合成する。仮定により g∶V→Qκ で gu=df となるものがある。各 $v\in V$ について $g(v)$ を表す整数列 $t_v$ を選ぶ。

- 各 $v,w\in V$ について、$t_{v+w}$ と $t_v+t_w$ が異なる座標は κ 個未満である。これは g の加法性による。
- 各 $a\in U$ について、$t_{u(a)}$ と値 $f(a)$ の定数列が異なる座標も κ 個未満である。これは gu=df による。

条件の総数は κ 未満であり、κ は正則なので、これらの例外座標の合併も κ 個未満である。その外の一座標 $i$ で $h(v)=t_v(i)$ と置くと、h∶V→ℤ は加法的で hu=f を満たす。□

いま u∈H(C) を任意に固定し、その U,V に応じて十分大きな正則 κ を選ぶ。Qκ∈C なので補題を適用できる。従って ℤ∈Inj(H(C)) である。非可算可測基数が存在しないという仮定の下では、上で見た ℤ∉C と合わせて C⊊Inj(H(C)) となる。これで母圏を Ab に固定しても No.7 の否定例が得られる。H が真クラスでも、一度に扱う u は一本なのでこの証明が通る。

命題 2.6 が公刊している結論は No.5(b) に関する弱反射の不存在である。No.7 への適用は今回の補題を組み合わせた帰結で、独立検証と先行研究における同一の主張の有無の確認は今後に残る。

## 一般の No.7 は可測基数が任意に大きく存在することを含意する

以下は母圏を変えて得る下界である。一般の No.7 を \(P_7\) と書く。これまでの導出を合わせると、WVP ⇒ \(P_7\) ⇒「任意の基数より大きな可測基数が存在する」となる。逆向きの含意はここでは得ていない。下界の導出は独立検証前である。

**証明。** 無限基数 \(\rho\) より大きい可測基数が存在しないと仮定する。\(|\Omega|=\rho\) として \(M=\operatorname{End}(\Omega)\) の左作用の圏を取る。これは小さい一対象圏上の前層圏であり、局所可呈示である。自然な作用を持つ \(\Omega\) を考える。任意の集合 \(I\) について、\(M\)-射 \(\Omega^I\to\Omega\) は座標評価に限る。実際、これらの射は \(I\) 上の \(\rho^+\)-完備超フィルターに対応し、非主なものがあれば \(\rho\) より大きな可測基数が存在する。\(I=\varnothing\) の場合には射は存在しない。[No.1 の超フィルター計算、補題 1・2](../No.1/codex_sset_handoff/investigations/measurable_thresholds_and_strong_compactness_2026-11-17.md)

各無限正則基数 \(\kappa\) について、\(Q_\kappa\) を \(\Omega^\kappa\) の列を「異なる座標が \(\kappa\) 個未満」で同一視した商とする。後合成による \(M\)-作用は商に降りる。これらの積のレトラクト全体を \(\mathcal C\) とすれば、\(\mathcal C\) は積とレトラクトで閉じる。

1. **\(\Omega\notin\mathcal C\)。** 仮に積 \(\prod_{j\in J}Q_{\kappa_j}\) から \(\Omega\) への射があれば、商射の積を前合成して \(\Omega^{\coprod_j\kappa_j}\to\Omega\) を得る。これは座標評価でなければならない。しかし一座標だけ値を変えても商射の積の値は変わらず、その座標での評価値は変わる。空積からも射はない。従って \(\Omega\) はどの積のレトラクトにもなれない。
2. **\(\Omega\in\mathrm{Inj}(H(\mathcal C))\)。** テスト \(u:U\to V\) を一本固定し、\(|U|,|V|,|M|,\aleph_0\) より大きい正則 \(\kappa\) を取る。任意の \(M\)-射 \(f:U\to\Omega\) を定数列で \(Q_\kappa\) に送る。\(u\in H(\mathcal C)\) ならこれを \(g:V\to Q_\kappa\) に延長できる。各 \(g(v)\) の代表列 \(t_v\) を選ぶ。必要な条件は全 \(m,v\) について \(t_{mv}(i)=m(t_v(i))\)、全 \(a\in U\) について \(t_{u(a)}(i)=f(a)\) である。各等式の例外座標は \(\kappa\) 個未満で、等式の数も \(\kappa\) 未満である。正則性により全条件が成立する一座標 \(i\) があり、\(v\mapsto t_v(i)\) が求める \(M\)-射 \(V\to\Omega\) となる。

よって \(\mathcal C\) は入射性類ではなく \(P_7\) は偽である。任意の無限基数 \(\rho\) にこの対偶を適用すれば主張を得る。□

## 他の問題との関係

- **No.5** の (b) と No.7 の Ab 版は仮定が同じである。弱反射があればレトラクト閉性から入射性表示が従うので、(b) の結論が強い。(a) で使われた非反射的な右直交類は、それ自体が入射性類になる。各テスト u∶U→V について u の入射性で延長の存在を、折り畳み射 $V\sqcup_U V\to V$（$u$ と $u$ の押し出しからの射）の入射性で一意性を表せるからである。[No.5 の二問と反例](../No.5/README.md)
- **No.6** の解集合が各 X で得られれば、積閉性によりその族を一本の弱反射にまとめられる。さらにレトラクト閉性があれば上の肯定方向が適用できる。No.6 が仮定する λ 有向余極限閉性は No.7 にはない。逆に No.6 で扱った離散グラフ族は積で閉じない。[No.6 の解集合条件](../No.6/README.md)
- **No.4** の小極限閉性は積閉性とレトラクト閉性を含む。レトラクトは対応する冪等射と恒等射の等化子として得られる。従って No.4 の候補は No.7 の仮定も満たすが、そこでの候補を No.7 に移すには、反射や弱反射の不存在に加えて H(C) のテストでは分離できない対象を示す必要がある。[No.4 の定式化と研究状況](../No.4/README.md)
- **No.1・2** は、母圏 K の言葉では K(X,U)→K(X,V) の全単射性で定まる左直交類の余反射性などを問う。No.7 では、指定された対象に対して K(V,X)→K(U,X) が全射になるテストを探す。以前の被約冪を用いた検討と同じく、小さい台を除いて座標を比較できるが、今回必要な計算は上記の一座標での延長で完結する。[No.1・2 の定式化](../No.2/p1_p2_measurable_wvp_almost_compact_2026-11-17.md)・[被約冪を用いた検討](../No.2/p1_lower_bound_reduced_powers_accessibility_boundary_2026-11-17.md)
- **No.3** との接点は入射性を**集合個**の射で定義した場合に現れる。局所可呈示圏では、小入射性類はちょうどアクセス可能で、アクセス可能に埋め込まれ、積で閉じる充満部分圏である（原著定理 4.8）。No.3 は生成対象からなる強生成集合を持つ余完備圏の局所可呈示性を問い、No.7 自体は部分圏にアクセス可能性を仮定しない。[原著第4章、定理 4.8](https://doi.org/10.1017/CBO9780511600579.007)・[No.3 の原問題](../No.3/README.md)
