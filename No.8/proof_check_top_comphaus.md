# No.8(b) の証明の再点検

2026年11月19日。同じ証明者による再点検。対象は Top 版の反例、CompHaus 版の肯定・否定、および相対独立性の導出である。結論は Top 版では ZFC で否定、CompHaus 版では VP と同値となる。後者の逆向きから WVP を除く部分は今回の導出である。外部査読・形式検証は経ていない。

## 1. Top の証明で確認した点

出発点は Koubek の原論文 pp. 662–663 の、パラコンパクト Hausdorff 空間の stiff な真クラスである。このとき「異なる二対象間には定数射しかない」と「各自己射は恒等か定数」の両方が使える。非退化な stiff Hausdorff 空間は連結である。非自明な開閉分割があれば、それぞれ一点に潰す自己射ができ、離散二点空間なら入替えもできる。以下では空と一点を除く。[Koubek の原論文](https://dml.cz/dmlcz/105589)

1. **等化子の位相。** 積から一因子への写像を一変数ずつ切る。恒等切片と定数切片は、二点での評価で互いに交わらない閉集合に入り、他変数の積は連結である。全座標で切片が定数なら、一つの点から有限個の座標だけを変えた稠密集合上で値が同じである。こうして得る等化子の方程式は、同じ型の変数の等置と値の指定に限られる。両立する場合、自由な同値類から一座標ずつ選ぶ射影に対し、指定値の代入と座標の反復が連続な逆写像を与える。従って等化子は部分空間位相まで含めて再び積である。自由座標がなければ一点、矛盾があれば空で、いずれも部分圏の対象である。
2. **離散二点への延長。** テスト \(u:A\to B\) ごとに \(\lambda=\max(|B|,\aleph_0)\) を選べる。\(i:D\hookrightarrow T\) との合成を延長した \(g:B\to T\) は、部分空間 \(S=g[B]\cup i[D]\) に余域制限しても連続である。必要な開閉集合は \(S\) の中で取る。その特性写像で \(D\) への延長を得る。一意性だけは、二つの延長を同じ単射 \(i\) と合成して \(T\) の直交性を使う。異なるテストに共通の \(T\) も、\(T\) 全体からのレトラクションも要求しない。
3. **輪の切断と極限段。** 長さ \(\theta=\kappa+\kappa\) の鎖の第 \(i\) 片から二端を除いた \(U_i\) は、貼り合わせる前には \(\pi_i^{-1}(M_i\setminus\{a_i,b_i\})\) で、商に関して飽和開である。\(i<j\) とすると \(Y\setminus(U_i\cup U_j)\) は \([v_{i+1},v_j]\) の像と \([v_{j+1},v_\theta]\cup[v_0,v_i]\) の像に分かれる。両者は閉かつ互いに素なので、補空間で開閉である。\(v_\delta\) が極限頂点なら、それより下の頂点は積の各有限座標でやがて \(v_\delta\) と一致する。従って極限頂点においてのみ値を変える連続写像は作れない。この議論は \(\kappa\) の正則性を必要としない。
4. **一つの片を欠く輪の射影。** \(K_i=Y\setminus U_i\) は、閉な右側 \([v_{i+1},v_\theta]\) と左側 \([v_0,v_i]\) が貼り目で会う。\(j>i\) の座標射影は右側では元の \(\pi_j\)、左側では \(b_j\)。\(j<i\) の場合は右側では \(a_j\)、左側では元の \(\pi_j\) である。いずれも閉集合上の貼り合わせで連続。同じ側の異なる点を分け、左右の点が全座標で一致するのは貼り目だけである。このため \(K_i\) に入る射の定数性を全射影で検査できる。
5. **自己射の混合の場合。** 元の族が小部分空間での開閉分離条件を満たさない場合、その否定の量化順序は \(\exists\mu\,\forall M\,\forall x\ne y\,\exists S\) である。小さい \(S\) で二点を開閉分離できないことと上記の二切断から、各 \(M\to Y\) は \(K_0\) または \(K_\kappa\) に入る。射影の剛直性により、非定数射なら同じ型の片の包含に限られる。逆向きの \(Y\to M_i\) は \(K_i\) 上で定数で、残った片の両端で値が同じだから全体で定数である。最後に自己射がある片を固定し、別の第 \(i\) 片を潰すとする。任意の \(z\in U_i\) で 1、二端で 0 となる連続実関数を \(K_i\) 上に 0 で延長できる（片の完全正則性と閉集合上の貼り合わせ）。この関数と自己射の合成は各片で定数であり、固定片で 0 だから全体で 0 となる。従って自己射の像は \(K_i\) に入り、4 の全射影との合成が定数なので自己射も定数になる。固定片の存在に矛盾する。

以上により、小極限閉性、\(D\notin\mathcal C\)、\(D\in({}^{\perp}\mathcal C)^\perp\) の三条件に欠落は見つからなかった。[元の二分法と輪の証明](top_stiff_circles.md)

## 2. コンパクトな片の場合は輪もコンパクトである

鎖 \(L\) を積の部分集合として書き直すと

\[
L=\bigcap_{\alpha<\beta<\theta}
\left(\{x:x_\alpha=b_\alpha\}\ \cup\ \{x:x_\beta=a_\beta\}\right).
\]

右辺の点で、全座標が終値なら \(v_\theta\) である。そうでなければ、終値でない最初の座標を \(\gamma\) とする。その前はすべて終値で、その後は表示された条件によりすべて始値になる。これはちょうど第 \(\gamma\) 片の点である。逆包含は各片と各頂点の定義から従う。従って \(L\) は閉である。各 \(M_\alpha\) がコンパクト Hausdorff なら \(L\) はコンパクト Hausdorff で、二端同一視の同値関係は対角線に二組を加えた閉関係なので \(Y_\kappa\) もコンパクト Hausdorff である。

Rosický–Trnková の Remark 2 は剛直なグラフの真クラスから **コンパクト Hausdorff** 空間の stiff な真クラスを与え、Remark 3 は前提が \(\neg\mathrm{VP}\) に相当すると述べている。この族に §1 の場合分けを適用する。分離条件が初めから成り立てば元のコンパクトな族を使い、そうでなければ上のコンパクトな輪を使う。どちらでも空空間と小積の同型閉包は CompHaus 内で極限閉である。\(D\) の延長の証明では内部の射 \(u:A\to B\) を任意に取ればよく、構成する延長 \(B\to D\) は CompHaus の射である。よって \(\neg\mathrm{VP}\) だけで CompHaus 版は偽となり、離散二点空間そのものを外部の証人にできる。[Rosický–Trnková, Remarks 2–3](https://dml.cz/bitstream/handle/10338.dmlcz/107347/ArchMath_025-1989-1_16.pdf)

## 3. クラス全体の選択関数を使わないための補足

任意の定義可能な stiff 真クラス \(\mathcal M\) から出発すると、すべての輪の片・標識を一度に選ぶクラス関数は自明には得られない。この問題は、選択を各集合内に限り、可能な輪をすべて採用して処理できる。

1. \(\mathcal M\) の対象の集合論的ランクが取る値は順序数の非有界クラスである。その増加列挙と順序数対の定義可能な単射符号化を用い、各位置 \((\kappa,i)\) に互いに異なるランク \(\rho_{\kappa i}\) を割り当てる。このランクの候補 \(M\in\mathcal M\) と相異なる二標識からなる三つ組の集合は非空である。
2. 各 \(\kappa\) ごとに、これらの候補の積の**すべての元**から輪を作る。位置は集合個であり、この積の非空性に通常の選択公理が使える。構成は同じ入力から同じ空間を返すよう固定する。
3. これらすべての輪も stiff な族になる。異なる \(\kappa\) では型が重ならない。同じ \(\kappa\) の輪 \(Y,Y'\) の間の射では、各源の片は定数になるか、同じ位置・同じ型の目標の片に恒等で写る。これは §1 の 5 の \(M\to Y'\) の分類である。非定数射 \(h\) なら少なくとも一片は恒等で写る。もし目標の第 \(i\) 片に恒等で写る源の片がなければ、§1 の 5 の実関数を **目標側** で使って \(h[Y]\subset K'_i\) を得る。目標の切断射影と合成すれば、源の輪から元の各型への写像はすべて定数なので \(h\) も定数となり、矛盾する。
4. 従って全位置で型が一致し、各片は対応する片に恒等で写る。後続頂点は隣接する二片の唯一の交点なので対応する後続頂点へ写る。極限頂点は後続頂点の収束で決まり、終点と同一視した始点にも同じ議論が使える（\(\theta\) は極限順序数）。従って全片の標識も一致し、二つの入力は同一で、\(h\) は恒等である。

この補足は Top の出発族にも使え、Koubek の個々の空間から二標識を一様に読み出す必要を除く。クラスを集合パラメータ付き定義可能クラスとして ZFC で扱う場合、失敗した VP インスタンスの剛直なグラフのクラスに原論文の表現を適用し、得られた族から以上の構成を行う。直交類表示の判定も、与えた \(\mathcal C\) から定義できる \(H={}^{\perp}\mathcal C\) について \(\mathcal C=H^\perp\) と書ける。この読みにおける VP との同値はスキーマ間の意味である。[Bagaria–Wilson, Introduction、グラフによる一階スキーマの定式化](https://arxiv.org/pdf/2012.11202)

## 4. CompHaus 側の独立性

肯定方向は既知の定理から従う。\(\mathrm{CompHaus}^{\mathrm{op}}\) は局所可呈示であり、VP の下でその余極限閉充満部分圏は余反射的である。双対に戻すと、元の部分圏は反射射のクラスへの直交類である。§2–3 の否定方向と合わせると、CompHaus 版は VP と同値になる。[Adámek–Rosický、第6章・定理 6.28](https://doi.org/10.1017/CBO9780511600579.009)・[Marra–Reggio、双対代数表示](https://arxiv.org/abs/1508.07750)

以前の WVP 上の証明も確認した。スライス内で各持ち上げが一意であるという条件は空極限も含めて極限閉である。反射で得た始対象から引き戻しへの一意射は、その射影との合成が始対象の自己射なので切断になる。従ってこの証明でも WVP 下の直交類の反射性は従う。今回の逆向きはこのスライス補題を使わず、より広い集合論的仮定で反例を構成する。[旧証明](comphaus_vopenka_bounds.md)・[局所可呈示圏での WVP の役割](https://www.ub.edu/topologia/casacuberta/articles/Semiweak.pdf)

したがって肯定側の無矛盾性には \(\mathrm{Con}(\mathrm{ZFC}+\mathrm{VP})\) を仮定すればよい。否定側だけなら \(\mathrm{Con}(\mathrm{ZFC})\) で足りる。例えば第二不完全性定理により、ZFC が無矛盾なら \(\mathrm{ZFC}+\neg\mathrm{Con}(\mathrm{ZFC})\) も無矛盾で、そのモデルは強到達不能基数を持たない（あればそのランク初期区間は ZFC のモデルになる）。従ってそこで VP は偽である。ここでの無矛盾性は通常の構文論的な主張である。
