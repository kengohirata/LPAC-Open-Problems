# Top 版 No.8(b) に対する ZFC 反例の証明案

2026年11月19日。目標は、Top の小極限で閉じる充満・同型閉部分圏 \(\mathcal C\) と、\(\mathcal C\) の満たす直交性テストをすべて通る \(D\notin\mathcal C\) を作ること。以下の \(D\) は離散二点空間である。出発点は Koubek の文献にある位相空間の族で、長い輪を使う以下の応用は独立検証前の証明案である。

## 1. 入力となる空間と極限閉性

輪の切断、極限段、直交性の存在・一意性、真クラスからの選択についての再検算を別記した。[証明の再点検](proof_check_top_comphaus.md)

Koubek, pp. 662–663 の Trnková の構成を使う。連結パラコンパクト Hausdorff 空間の順序数添字の真クラス \(\mathcal M\) があり、異なるものの間の連続写像はすべて定数、各自己射は恒等または定数である。この性質を原文は *stiff* と呼ぶ。非退化な空間に限る。この結果は ZFC で成り立つ。同論文の Theorem 12 を大きな離散圏に適用してもこの族の存在が従う。標識が必要な以下の構成では pp. 662–663 の明示族を使える。各空間にある最初の Cook 連続体片の内部から、原構成の有限個の標識を避けた同じ二点のコピーを指定しておく。[Koubek, *Each concrete category has a representation by \(T_2\) paracompact topological spaces*](https://dml.cz/dmlcz/105589)

任意の非退化な連結 Hausdorff 空間の stiff な族 \(\mathcal T\) について、\(\mathcal C(\mathcal T)\) を、空空間と \(\mathcal T\) の元の集合添字積（空積を含む）の同相コピーすべてからなる充満部分圏とする。これは小極限閉で、\(D\) は入らない。

実際、\(h:\prod_i T_i\to N\in\mathcal T\) は定数または \(T_i=N\) である座標への射影である。一変数切片は定数または恒等で、同じ型の座標の場合、異なる二点 \(a,b\in N\) における切片の値の対は \(\Delta_N\sqcup\{(a,b)\}\) に入る。他の変数の積が連結なので、その変数について一斉に恒等か一斉に定数である。どの変数についても後者なら、有限個の座標だけを変えても値は同じで、稠密性と Hausdorff 性により \(h\) は定数になる。従って二射の等化子を定める条件は、同型の座標を等置する条件と定数の値を指定する条件である。解空間は空か、値を指定されていない座標の同値類を添字とする積に同相である。積閉性と合わせて小極限閉性が従う。非空な対象はすべて連結である。

## 2. 離散二点がすべてのテストを通る条件

族 \(\mathcal T\) について、次の条件を考える。

\[
(\ast)\quad
\forall\lambda\text{ 無限基数}\quad
\exists T\in\mathcal T,\ a\ne b\in T\quad
\forall S\subseteq T,\quad
\{a,b\}\subseteq S,\ |S|\le\lambda
\ \Longrightarrow\ a,b\text{ は }S\text{ の開閉集合で分離できる}.
\]

この条件なら、\(\mathcal T\) のすべての元が直交するどの射 \(u:A\to B\) にも \(D\) が直交する。実際、\(\lambda=\max(\aleph_0,|B|)\) に対する \(T,a,b\) を選び、\(i:D\to T\) をその二点を選ぶ射とする。\(f:A\to D\) に対し \(if\) を延長して \(g:B\to T\) を得る。\(S=g[B]\cup\{a,b\}\) 上の開閉分離から \(ri=1_D\) を満たす連続写像 \(r:S\to D\) がある。従って \(rg\) が延長である。二つの延長は \(i\) との合成が \(T\) の直交性によって一致し、\(i\) は単射なので元から同じである。この議論は \(A\) または \(B\) が空でも成立する。

従って \(\mathcal M\) が \((\ast)\) を満たせば §1, §2 で証明は終わる。以下、その否定を仮定する。この否定をそのまま書くと

\[
\exists\mu\text{ 無限基数}\quad
\forall M\in\mathcal M,\ \forall x\ne y\in M,\quad
\exists S\subseteq M,\ |S|\le\mu,\ \{x,y\}\subseteq S,\quad
x,y\text{ を }S\text{ の開閉集合で分離できない}.
\tag{1}
\]

この \(S\) に連結性を仮定する必要はない。以下では (1) から、別の stiff な族で \((\ast)\) を満たすものを作る。

## 3. 一列に貼ってから両端を同一視する

無限基数 \(\kappa>\mu\) ごとに、順序数 \(\theta=\kappa+\kappa\) を取り、\(\alpha<\theta\) ごとに相異なる \(M_{\kappa,\alpha}\in\mathcal M\) を一つ割り当てる。異なる \(\kappa\) でも使い回さない。順序数の対を順序数に単射で符号化して、§1 の明示族から取ればよい。\(\kappa\) を固定したときは \(M_\alpha\) と略記し、各片の二標識を \(a_\alpha,b_\alpha\) とする。

積 \(\prod_{\alpha<\theta} M_\alpha\) の中に鎖 \(L\) を定める。頂点 \(v_\gamma\)（\(0\le\gamma\le\theta\)）の \(\alpha\) 座標は \(\alpha<\gamma\) なら \(b_\alpha\)、それ以外なら \(a_\alpha\) とする。片 \(e_\alpha(M_\alpha)\) は \(v_\alpha\) の \(\alpha\) 座標だけを自由に動かした部分空間で、両端は \(v_\alpha,v_{\alpha+1}\) である。\(L\) は全頂点と全片の和集合に積の部分空間位相を入れたものとする。最後に \(v_0\sim v_\theta\) として得られる商を \(Y_\kappa\) とする。各片からその二端点を除いたものを \(U_\alpha\) と書く。これは開であり、\(U_\alpha\) 同士は交わらない。

以下に使用する位相の性質を確認する。

- 鎖の閉区間 \([v_\xi,v_\zeta]\) は、その外側の座標を指定値に固定して切り出される閉部分空間である。各片の埋め込みは同相である。極限順序数 \(\delta\) では \(v_\gamma\to v_\delta\)（\(\gamma\uparrow\delta\)）である。積の有限座標近傍から直接従う。連結な片を後続段で貼り、極限段でその閉包にある頂点を加える帰納法により、鎖とその閉区間は連結である。
- \(L\) は完全正則 Hausdorff で、閉な二点を一つにする商は Hausdorff である。例えば、指定した二点の同値類と第三の点を互いに素な飽和開集合で分けられる。商写像は閉写像でもある。閉集合の飽和は高々二点を加えるだけだからである。従って \(Y_\kappa\) は連結 Hausdorff、各片は閉埋め込みされたままである。
- 一つの開いた片 \(U_i\) を取り除くと、残り \(K_i\) は \(v_{i+1}\) を始点に \(v_\theta=v_0\) を経て \(v_i\) に至る一本の鎖になる。各 \(j\ne i\) に対し、\(K_i\to M_j\) で、\(j\) の片上では恒等、その前では \(a_j\)、後では \(b_j\) という射影がある。連続性は閉な二区間 \([v_{i+1},v_\theta]\), \([v_0,v_i]\) 上で確認できる。一方では元の座標射影、他方では定数で、貼り目で一致する。これらの射影は \(K_i\) の点を分離する。実際、鎖をこの順に読むと、既に通過した座標は終値、まだ達しない座標は始値で、片の二端以外の点には自由座標がちょうど一つある。この記述は極限段の頂点も区別する。
- 鎖または途中の閉区間から Hausdorff 空間への射が各片上で定数なら、その区間上で定数である。後続段では共通端点、極限段では上記の収束を使う。\(Y_\kappa\) と \(K_i\) にも同じ結論が成り立つ。異なる二つの \(U_i,U_j\) を除くと、その補空間は二つの互いに素な閉弧（閉区間の像、または貼り目を介した二閉区間の像の和）に分かれ、各弧は補空間で開閉である。

## 4. 輪の剛直性

**(a) \(M\in\mathcal M\) から \(Y_\kappa\) への非定数射は、同じ型の唯一の片をそのまま入れる射に限る。** まず写像の像が \(U_0\) と \(U_\kappa\) の双方に会うと仮定する。それらに入る原像二点に (1) を使う。その \(S\) の像は濃度が \(\mu\) 以下なので、\(0<i<\kappa<j<\theta\) で \(U_i,U_j\) の双方を避けるような \(i,j\) がある。§3 の二閉弧によって像の二点は \(f[S]\) で開閉分離される。逆像を取れば (1) に矛盾する。従って像は \(K_0\) または \(K_\kappa\) に入る。

その切り開いた鎖の射影と合成する。stiff 性により \(M\) と型が異なる全座標は定数で、同じ型の座標は高々一つである。射影族は点を分離するので、非定数写像なら同じ型があり、その座標は恒等である。そこで二標識以外の点の像は、当該片のその点に一意に定まる。この集合は非退化連結 Hausdorff 空間 \(M\) で稠密だから、二標識でも値は片の包含と一致する。

**(b) \(Y_\kappa\to M\in\mathcal M\) はすべて定数である。** 同じ型が現れなければすべての片で定数なので §3 による。同じ型が第 \(i\) 片にあっても、残りの鎖 \(K_i\) 上では定数になる。第 \(i\) 片の両端はともに \(K_i\) に属するので二端で値が同じである。従ってこの片でも恒等は不可能で、定数になる。

**(c) \(\{Y_\kappa:\kappa>\mu\}\) は stiff である。** 異なる輪の間の射は、各片で (a) により定数なので定数になる。自己射 \(h\) は各片で恒等か定数である。全片で定数なら定数、全片で恒等なら極限頂点での連続性から恒等である。残るのは、ある片では恒等、別の第 \(i\) 片では定数となる場合である。

この場合 \(h[Y_\kappa]\) は \(U_i\) を避ける。実際、任意の \(z\in U_i\) に対し、\(i\) 片の完全正則性から、二端で 0、\(z\) で 1 の連続実関数を取り、閉な \(K_i\) 上で 0 として貼って \(w:Y_\kappa\to[0,1]\) を作る。\(wh\) は各片上で定数である。定数に潰れた片では自明であり、恒等の片は \(i\) 以外なので \(w=0\) である。よって \(wh\) は全体で定数 0 であり、\(z\) は像に入らない。こうして \(h\) は \(K_i\) に入るが、点を分ける各射影と合成すれば (b) によりすべて定数となる。これは恒等に写る片の存在に矛盾する。

## 5. どの小さいテストにも離散二点が直交する

\(Y_\kappa\) の二点を \(v_0=v_\theta\) と \(v_\kappa\) に取る。この二点を含む濃度 \(<\kappa\) の任意の部分空間は、\(0<i<\kappa<j<\theta\) にある二つの開いた片 \(U_i,U_j\) を丸ごと避ける。§3 の二閉弧は二点を別々に含み、その部分空間で開閉分離を与える。任意の無限基数 \(\lambda\) に対して \(\kappa>\max(\lambda,\mu)\) を使えば、輪の族が \((\ast)\) を満たす。

§1 と §2 をこの族に適用する。得られる \(\mathcal C\) は Top で小極限閉、\(D\notin\mathcal C\) であるが \(\mathcal C\) の全対象が直交するすべての射に \(D\) が直交する。最初の族がすでに \((\ast)\) を満たした場合も同じ結論であった。これが ZFC での否定の導出であり、VP を追加しても同じ推論が通る。コンパクト Hausdorff 空間からなる stiff な真クラスを出発点にしていないため、VP 下の CompHaus 版の肯定とは両立する。
