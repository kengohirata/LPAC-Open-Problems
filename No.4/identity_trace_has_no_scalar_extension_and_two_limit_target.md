# 恒等列での評価の不可能性と、二つの極限を持つ標的

\(M=\mathrm{End}(\omega)\)、\(F=\{m\in M:|\mathrm{im}(m)|<\aleph_0\}\)、
\(P=(F\overset{\mathrm{id},\,\mathrm{shift}}{\rightrightarrows} F)\) とする。
\(R\) は [二周期の計算の §4](two_cycle_does_not_receive_the_ordinal_seed_hull.md)
で定めた \(H_\delta\times E(P)\) の対角初期写像の最小 \(\mathcal A\)-部分対象。
その初期写像を \(\eta:X\to R\)、第2因子への射影を \(\pi\) と書く。
左作用は出力の付け替え、右作用は入力の付け替えである。

**定理（ZFC）。** 左 \(M\)-同変な写像 \(\ell:R_1\to\omega\) で
\[
 \ell(z\cdot m)=(\pi_1z)(m)\qquad(z\in R_1,\ m\in F)                 \tag{1}
\]
を満たすものは存在しない。さらに \(Y_*\in C\) と初期写像
\(j_*:X\to E(Y_*)\) を明示でき、\(k\eta=j_*\) を満たす
\(\mathcal P\)-射 \(k:R\to E(Y_*)\) は存在しない。

## 1. 有限値の指定はそれ自体では整合する

\(W=(F\overset{\mathrm{incl},\,\mathrm{shift}}{\rightrightarrows}M)\)
と置く。\(R\to E(W)\) の第2成分 \(k_1\) があれば、
\(\ell(z)=k_1(z)(\mathrm{id}_\omega)\) とおける。右同変性から任意の
\(a\in M\) で \(k_1(z)(a)=\ell(z\cdot a)\)。
初期写像を保つ場合、\(P\to W\) の双対との合成は \(\pi\) に等しい。
これは \(R\) の最小性と、\(\mathcal A\) 内の二射の等化子から従う。
従って (1) が必要。逆に左同変な \(\ell\) が (1) を満たせば、
上の式と \(k_0=\pi_0\) が所要の射を与える。二本の構造射の入力は
有限値の列またはそのシフトであり、どちらも (1) の範囲である。
種の第2成分の各元は右作用で固定されるので、その値も (1) で定まる。

有限値の右移動の合併上で、(1) の右辺は表示に依存しない。実際
\(z\cdot m=z'\cdot m'\) なら、有限集合 \(\mathrm{im}(m,m')\)
の各値に原像を一つ選び、各 \(n\) を同じ値の選んだ原像に送る
\(b\in F\) を作れる。\(mb=m,\ m'b=m'\) である。等式を
\(\pi_1\) で送り、列 \(b\) で評価すれば右辺は等しい。
この部分写像は左同変でもある。

## 2. 一つの初期写像から任意の軌道列関数を解釈する

\(f:X\to Z\)、\(Z\in\mathcal A\) を取る。第0ソートの後続の反復を
\(h_n(f)\)、その一意な balanced な第1ソート延長を
\(\widetilde h_n(f)\) とする。これらは \(f\) に関して自然である。
各ソートで、これらのいずれか一方の列を \(v_n(f)\) と書く。
前稿の最初の不一致を記録する演算にゼロ判定を適用すれば、
指定した語 \(w\in\omega^\omega\) と軌道列が一致することを表す元
\(B_w(f)\) がある。第1ソートでも証明は同じで、有限個の
\(\widetilde h_n(f)\) に対する有限項演算を用いる。各 \(B_w\)
は自然で、full power では座標ごとの一致の指示関数である。
[不一致演算の構成](two_cycle_does_not_receive_the_ordinal_seed_hull.md)

任意の集合写像 \(\Phi:\omega^\omega\to\omega\) について自然な元
\(a_\Phi(f)\) が存在し、full power では座標ごとに \(\Phi\) を
軌道列に適用した値を取る。以下でこの主張の一意性と存在を確認する。
\(L(b,t)\) は \(b=1\) なら \(t\)、それ以外は 0 とする二項演算。
有限項演算は前稿の tuple coding で解釈する。

* 各 \(B_w(f)\) で \(L(B_w(f),a)=L(B_w(f),a')\) なら \(a=a'\)、
  という性質が \(\mathcal A\) の全対象で成り立つ。\(D\) の full
  power の各座標には実際の語が一つあるのでそこで成り立つ。極限では
  射影ごとに検査する。有向合併では \(f,a,a'\) を一つの段階に取る。
  \(X\) は有限生成で、段階の単射はすべての表示等式を反映する。
  \(B_w\) は自然なので、同じ段階ですべての \(w\) を検査できる。
* \(a_\Phi(f)\) を、各 \(w\) 上で定数 \(\Phi(w)\) と上記の意味で一致する
  元として指定する。定数は \(v_0(f)\) への左定値作用で表せる。
  一意性は直前の性質から従う。存在する対象間の射はこの解を保つ。
  存在は \(D\) で点ごとの式から従い、極限では一意性により整合する
  解を取り、有向合併では \(f\) の入る一段階で解を取る。

この論証のパラメータは一つの有限生成な初期写像である。可算個の
任意に独立した元が合併の一段階に入るという仮定は使わない。

## 3. \(\ell\) への矛盾

\(\omega\) 上の自由超フィルター \(U\) を取る。存在には余有限フィルター
を極大フィルターに延長すればよい。[超フィルター補題の証明](https://www.math.uchicago.edu/~may/VIGRE/VIGRE2009/REUPapers/Davis.pdf)

有限値の語 \(w\) に
その \(U\)-極限を返す \(\Phi_U\) を固定し、残りの語には 0 を与える。
有限値の場合は、値の逆像が \(U\) に入る唯一の値が極限である。
full power \(E(Y)\) の各第0ソート軌道列は有限値である。
各 \(y\in Y_0\) の有限支持にすべての \(h_n(y)\) が属するためである。

§2 の第0ソート演算を \(R\) の種に適用した元を \(a_U\) とする。
\(R\hookrightarrow E(Y_\delta)\times E(P)\) の二成分で
\[
 a_U=\bigl(g\mapsto g(\omega),\quad s\mapsto\lim_U s\bigr).
\]
順序数側では \(g(n)\) は \(g(\omega)\) に最終的に一致する。
両成分は入力の付け替えと可換なので \(a_U\) は balanced である。
実際に \(a_U\) を初期生成元の像とする \(X\to R\) を作れる。
第0ソートではその左移動、第1ソートでは元の種にある定数を使う。
二本の構造等式は上の単射の各成分で成立する。
\(\mathcal A\) は \(E(\sigma)\) に直交するので、balanced な延長
\(b_U\in R_1\) がある。各因子での一意延長を取ると
\[
 b_U=\bigl(r\mapsto r(\omega),\quad s\mapsto\lim_U s\bigr).
\]
特に \(b_U\cdot m=m\cdot b_U\) である。

仮に (1) を満たす \(\ell\) があり \(k=\ell(b_U)\) とする。有限値の
\(m\) ごとに
\[
 m(k)=\ell(m\cdot b_U)=\ell(b_U\cdot m)=(\pi_1 b_U)(m)=\lim_U m .
\]
\(m=\mathbf1_{\{k\}}\) とすれば左辺は 1、右辺は 0 である。
これは現に \(R_1\) に入る一つの元を使った矛盾である。

## 4. 実際の \(C\)-標的でも延長が失敗する

\(S=\omega\sqcup\{\infty_0,\infty_1\}\) を、偶数列が \(\infty_0\)
に、奇数列が \(\infty_1\) に収束する二つの収束列の位相的直和とする。
\(d(n)=n+1,\ d(\infty_i)=\infty_{1-i}\) と置き、
\[
 Y_*=(C(S,\omega)\overset{\mathrm{incl},\,d^*}{\rightrightarrows}
           \omega^S)
\]
を 0 の評価で根付ける。第0ソートは各点が有限支持である。第1ソートの
指標は点評価に尽きる。実際 \(S\) と \(\omega\) の全単射一つから
すべての関数が付け替えで得られる。第0ソートの指標も同じ点評価である。
有限 tuple coding により指標は clopen 指示関数上に超フィルターを
定める。二つの clopen 成分の一方を選んだ後、その成分の有限・余有限
代数の超フィルターは孤立点または極限点の評価である。各連続関数の
値の逆像は有限 clopen 分割をなすので、この点が指標全体を決める。
従って \(Y_*\in C\)。

自由超フィルターを \(n\mapsto2n+i\) で押し出し、偶数集合を含む
\(U_0\) と奇数集合を含む \(U_1\) を作る。第1ソートで恒等語
\((0,1,2,\ldots)\) が実現されることを表す §2 の \(B_{\rm id}\)
を用いる。\(R\) では
\[
 L(B_{\rm id},b_{U_0})=L(B_{\rm id},b_{U_1}).                     \tag{2}
\]
順序数の成分では二つの \(b\) がともに \(\omega\) の評価である。
\(P\) の成分ではどの第1ソートの語も有限値なので \(B_{\rm id}=0\)。
この二成分は \(R\) 上で共同単射である。

仮に \(R\to E(Y_*)\) が初期写像を保てば、自然性により \(a_{U_i}\)
の像は \(\infty_i\) の評価である。一意な balanced 延長により
\(b_{U_i}\) の像も第1ソートでの \(\infty_i\) の評価になる。そこで
\[
 r(n)=n,\qquad r(\infty_0)=0,\qquad r(\infty_1)=1
\]
という第1ソートの点を取る。この点では \(B_{\rm id}=1\) であり、
(2) の両辺は 0 と 1 になる。従って所要の射はない。

以上は選んだ \(R\) が \(X\) の反射にならないことを決める。
別の \(\mathcal A\)-対象による反射の存在、および No.4 は未解決。
証明は直接点検した段階であり、独立査読・形式検証は未実施。
