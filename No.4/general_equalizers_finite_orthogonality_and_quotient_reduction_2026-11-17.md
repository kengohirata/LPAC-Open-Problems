## 4. Finite pairing/tuple coding (ZFC)

この operation は W の射に自然で、右 M_1-作用及び二本の diagram arrows と可換 (これらが左 M_2 action を保つため)。等化子 Eq(a,b) はこの操作の下で閉じる。

## 11. No.1 順序数 witness に対する agreement locus の countable-cofinality closure (ZFC)

    t(f)=b((f(x_n))_{n∈ω})
で定める。

    m_n·t=ev_{x_n},  m_∞·t=ev_λ。

## 12. 無限 cofinality の素朴な single-generator coding に対する障害

X を任意の Stone (zero-dimensional compact Hausdorff) 空間、Y=C(X)=Cont(X,Ω_discrete), Ω=ω とする。各 x∈X の evaluation e_x∈Ω^Y を考える。
任意の t∈Ω^Y に対して
  S_t={x∈X: ある m_x∈Endω により e_x=t·m_x}
と置く (右 action は (t·m)(f)=t(m∘f))。

**補題 (ZFC):** |S_t|≤ℵ0。

証明: η(n)=t(const_n) と置く。e_x=t·m_x なら定数関数上の評価から η(m_x(n))=n、したがって m_x は単射。
異なる x,y に対して range(m_x)∩range(m_y) に異なる二点 v_0,v_1 があるとする。η(v_i)=n_i と置けば m_x(n_i)=m_y(n_i)=v_i、n_0≠n_1。
X の zero-dimensional Hausdorff 性で x と y を clopen U で分離し、f:X→Ω を U 上 n_0、補集合上 n_1 と置く。すると m_x∘f=m_y∘f だが
  t(m_x∘f)=e_x(f)=n_0,
  t(m_y∘f)=e_y(f)=n_1、
矛盾。
よって {range(m_x):x∈S_t} は pairwise intersection≤1 な infinite subsets of ω の族。各 range から異なる二整数の pair を一つ選ぶと、異なる x に同じ pair を選べない。したがって S_t は countable な [ω]^2 に単射であり可算。□

これは右 M_1 action **のみ**による生成に対する bound。左 M_2 action を組み合わせた全 orbit の評価点数まで可算とは主張しない。ただし F が P で finitely generated なら、固定 signature M_1,M_2 の unary operation 全体は cardinality 𝔠 なので、F の各 sort の carrier は高々 𝔠。従って κ>𝔠 で `{e_x:x∈[0,κ]}` 全体を一つの finitely generated P-subobject に載せることはできない。

この二つは、§11 の countable-cofinality propagation を単純な single-element/finite-generator code で任意の大 cofinality に拡張する手順が使えないことを示す。一般の equalizer closure そのものの否定ではない。
