# Problem 4：Y_(ω₁) template の標準射と非 stage 射への帰着

## 1. 設定

λ=ω₁、κ≥λ とし、各順序数 μ について

    X_μ=[0,μ],
    C_μ=Cont(X_μ,Ω_discrete),  B_μ=Ω^(X_μ),
    Y_μ=(C_μ --p_μ=inclusion,q_μ=d_μ^*--> B_μ)

と置く。d_μ は μ 未満で後続点へ送り、μ を固定する。

本ノートの分類定理では N（非可算 measurable cardinal が存在しない）を仮定する。これにより E は fully faithful で、Y_κ,Y_λ∈C。No.1 の因子化下界・非 coreflectivity 入力は使わない。

旧 T_α（α<ω₁）を用い、

    R=Y_λ,
    V^R=colim_(α<ω₁) E(T_α・Y_λ)

とする。各 stage は D、遷移は mono なので V^R∈M。

Finitely generated な固定 source X=E(B)、B=(Ω⇉1) と、0での評価 ψ_κ:Y_κ→B による

    j_0=E(ψ_κ):X→E(Y_κ)

を使う。

## 2. Y_λ→Y_κ の射の分類

**定理（N）。** K-map k:Y_λ→Y_κ は、ある一意な β∈[0,λ] に対する

    h_β:[0,κ]→[0,λ],
    h_β(x)=min(β+x,λ)

との前合成で与えられる。すなわち k_i(f)=f∘h_β。

### 証明

H_1(C_μ)≅[0,μ] は位相も保つ同定であり、N の下で H_1(B_μ)≅[0,μ] は集合としての同定である。

k_0:C_λ→C_κ は連続写像 h:[0,κ]→[0,λ] を誘導し、k_1:B_λ→B_κ は集合写像 ℓ:[0,κ]→[0,λ] を誘導する。p についての自然性から h=ℓ。q についての自然性から

    h d_κ=d_λ h

となる。各 x の evaluation を合成すれば k_i(f)(x)=f(h(x)) なので、k は h から復元される。

β=h(0) とする。後続段では h(x+1)=d_λ(h(x))。極限段 δ では h の連続性を使える。超限帰納法により

    h(x)=min(β+x,λ)

が全 x≤κ で得られる。極限段では ordinal addition の右変数についての連続性と、既に得た単調な値の極限を使う。

逆に h_β は連続で、κ≥λ により h_β(κ)=λ。後続点と終点の双方で h_βd_κ=d_λh_β が成り立つ。従ってその前合成は K-map となる。β=h(0) より一意。□

特に、全ての k は [0,κ]→[0,λ], x↦min(x,λ) に双対な標準射 Y_λ→Y_κ を経由する。

## 3. 一段階を経由する P-map の完全な分類

上の k を k_β と書く。N の下で、射

    E(Y_κ)→E(T_α・Y_λ)

は、一意な集合写像 b:T_α→[0,λ] を用いて

    Θ_(α,b,i)(F)(t,r)=F(k_(b(t),i)(r))

と表せる。これは E の fullness と、copower からの K-map の分類による。

stage を上げる操作は b を T の restriction と前合成する操作に対応する。従って stage-bounded な射全体は

    colim_(α<ω₁) [0,λ]^(T_α)

と同一視できる。

さらに、j_0 を前合成すると、対応する K-map T_α・Y_λ→B の第0成分は各 t における b(t) での評価になる。C_λ の連続関数は [0,λ] の点を分離するため、異なる b は j_0 上でも区別される。

**帰結。** stage-bounded な二射 a,b:E(Y_κ)⇉V^R が aj_0=bj_0 を満たすなら a=b。

## 4. 任意の射には同じ j_0 制限を持つ標準 stage 射がある

θ:E(Y_κ)→V^R は、まだ stage-bounded と仮定しない。

X は ambient finitely generated なので、θj_0:X→V^R は一つの stage E(T_α・Y_λ) を経由する。B の両 sort は可算なので、この stage map は ZFC の countable-index duality により K-map

    T_α・Y_λ→B

に対応する。その第0成分は、各 t に対する H_1(C_λ) の点、すなわち b(t)∈[0,λ] を与える。

§3 の明示的な射 Θ_(α,b) を V^R へ送ったものを θ_std と置くと

    θ_std j_0=θj_0。

この構成は stage 表示の選択に依存しない。二つの表示を共通 stage に上げると、C_λ の点分離性により b が一致し、標準射も一致する。

N の下では、θ_std は同じ j_0 制限を持つ唯一の stage-bounded map である。

従って制限写像

    Hom_P(E(Y_κ),V^R)→Hom_P(X,V^R),  θ↦θj_0

は全射で、標準 stage 射を選ぶ canonical section を持つ。また、N の下で次は同値。

1. 全ての E(Y_κ)→V^R が stage-bounded。
2. 上の制限写像が injective。
3. 全ての θ が θ_std と一致する。

## 5. j_0 を含む D-subobject の極小性（N）

**定理。** E(Y_κ) の D-subobject で j_0 を含むものは E(Y_κ) 自身だけである。No.1 の因子化下界・非 coreflectivity 入力は不要。

### 証明

m:E(Q)↪E(Y_κ)、Q∈C と t:X→E(Q) が mt=j_0 を満たすとする。N の下で E は full なので、m=E(q) となる K-map q:Y_κ→Q がある。E(q) の各成分が単射であることから q の各成分は全射である。また t を双対化して ψ_κ が q を経由することが分かる。

Q_0 は finite-support なので H_1(Q_0) は compact Hausdorff であり、q_0 の前合成

    H_1(q_0):H_1(Q_0)→H_1(C_κ)≅[0,κ]

は連続単射である。その像 L は閉集合で、ψ_κ の因子化から 0∈L。

L が d_κ で閉じていることを示す。x∈L を hq_0=ev_x、h∈H_1(Q_0) と表す。Q∈C より g∈H_1(Q_1) を gp_Q=h と一意に取れる。p の自然性と H_1(p_κ) の全単射性から gq_1=ev_x:B_κ→Ω。従って

    (gq_Q)q_0=gq_1q_κ=ev_x d_κ^*=ev_(d_κ(x))。

よって d_κ(x)∈L。0 を含み、後続点を含み、極限で閉じる L は、超限帰納法により [0,κ] 全体である。

H_1(q_0) が全射であるため、q_0(a)=q_0(b) なら全ての x≤κ で a(x)=b(x)、従って a=b。よって q_0 は全単射。また H_1(p_Q), H_1(p_κ) が全単射なので、p の可換正方形から H_1(q_1) も全射となる。B_κ の evaluation による点分離性から q_1 も単射、従って全単射である。以上より q と m は同型。□

**帰結。** N の下で W∈M と異なる二射 a,b:E(Y_κ)⇉W が aj_0=bj_0 を満たせば、Eq(a,b)∉M。

実際 j_0 は Eq(a,b) を経由する。もし Eq(a,b)∈M なら、X が fg なので、この因子化はある D-subobject E(Q)↪Eq(a,b) を経由する。合成 E(Q)↪E(Y_κ) は上の定理から同型となり、a=b という矛盾を得る。

## 6. 反例探索への意味と未解決点

この target については、j_0 上で一致する二射を別々に探す必要はない。**一つの非 stage 射 θ を構成できれば、θ と θ_std が自動的に異なる二射で j_0 上で一致する。**

§5 により、N の下でこの二射の equalizer は実際に M に属さない。従って、この target への一つの非 stage 射の構成は、M の equalizer 閉性への反例をそのまま与える。ただし、非 stage 射の存在そのものは本ノートでは示していない。

今回の分類は、stage-varying な ordinal truncation の公式を無条件で射と認めていない。元 F ごとに stage を変える公式には、全 M_2・M_1作用との整合性と二本の構造射の自然性が必要であり、その一貫した構成は残課題である。
