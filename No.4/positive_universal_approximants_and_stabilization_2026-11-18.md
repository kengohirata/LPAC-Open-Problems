## 1. 反射性だけに必要なものを分離する

P=Set^(D^op)、A⊆P は full replete かつ全小極限閉とする。本ノートの構成自体には directed-union 閉性はまだ不要。

X∈P を固定する。h:X→H∈A が H=cl_H(im h) を満たすとき、h を X からの生成対象と呼ぶ。これらの圏 G_X は thin で、その射は A-strong epi。

全ての生成対象のサイズを抑えると、反射が存在する場合でもその全 strong quotients のサイズまで抑えることになる。ここでは、特別に選んだ一つの近似列だけのサイズを調べる。

## 2. Canonical な普遍近似

無限基数 κ≥max(ℵ0,|Mor D|,|X|) に対し、S_κ を次の **集合**とする。

    各 sort の台集合が κ の部分集合である A-presheaves の全て。

これらは各 |B|≤κ の A-object の同型コピーを含む。S_κ は κ に関して包含で増加する。対象を一つずつ arbitrary に選ばず、全ての標準コードを取ることで global choice を避ける。

I_κ={(B,f):B∈S_κ, f:X→B} とし、

    T_κ = ∏_{(B,f)∈I_κ} B,
    d_κ:X→T_κ = 全ての f の対角射,
    R_κ X = cl_(T_κ)(im d_κ),
    r_κ:X→R_κ X

と定める。全て集合サイズの積と交わりであり、R_κ X∈A。

**近似の普遍性。** |B|≤κ、B∈A、f:X→B なら、一意な f̄:R_κ X→B が f̄r_κ=f を満たす。

存在は B の標準コピーに対応する product projection、一意性は seed による生成性による。対象 R_κ X 自身が κ 以下であるとは要求しない。

κ≤κ' なら I_κ⊆I_κ' なので積の射影があり、hull の自然性から

    p_(κ',κ):R_κ' X→R_κ X,
    p_(κ',κ) r_κ'=r_κ

を得る。これらは一意なので合成法則を満たす。また全て A-strong epi。

したがって、普遍近似は **逆向きの列**である。directed union の図式と取り違えない。

### 2.1 各段階の明示的なサイズ

標準コードの数と射の数は各々 2^κ 以下なので

    |I_κ|≤2^κ,
    |R_κ X|≤|T_κ|≤κ^(2^κ)=2^(2^κ).                (B_κ)

これは各 κ ごとの集合上界。κ 全体にわたる一様な上界ではない。

## 3. 反射性の正確な停止条件

**定理 3.1。** 次は同値。

1. X の A-reflection が存在する。
2. ある κ0 があり、全 κ≥κ0 について p_(κ,κ0) は同型。
3. ある集合基数 ν があり、全 κ について |R_κ X|≤ν。
4. ある κ0,ν があり、全 κ≥κ0 について |R_κ X|≤ν。

### (1)⇒(2)

η:X→RX を反射とし、κ0≥|RX| とする。全 κ≥κ0 に対し、近似の普遍性から a:R_κ X→RX、反射の普遍性から b:RX→R_κ X がある。どちらも X 上の射。

η は RX を生成するので RX と R_κ X は G_X の対象。thin 性から ab=id、ba=id。従って R_κ X≅RX、全ての transition も同型。

### (2)⇒(3) と (3)⇒(4)

κ<κ0 の段階は集合個であり、各段階のサイズも集合。停止後の一つのサイズと合わせて上界を取る。(3)⇒(4) は明らか。

### (4)⇒(2)

|H|≤ν の presheaves H および射 X→H の同型類は集合個。従って tail に現れる (R_κ X,r_κ) の over-X 同型類も集合個。

各同型類が tail に最初に現れる基数 α を取り、それらの集合を上から抑える κ1≥κ0 を取る。

κ≥κ1 に対し、R_κ X はある α≤κ1 の R_α X と over-X 同型である。transition

    R_κ X → R_κ1 X → R_α X

とこの同型の逆を合成すれば、R_κ1 X→R_κ X という over-X の逆向きの射を得る。G_X の thin 性から両合成は恒等射。従って p_(κ,κ1) は同型。

最初の出現段階を使うため、proper-class choice は要らない。

### (2)⇒(1)

任意の f:X→B∈A に対し、κ≥max(κ0,|B|) を取る。近似の普遍性による R_κ X→B を、同型 R_κ0 X≅R_κ X と合成する。これが f の延長であり、生成性から一意。従って r_κ0 は反射。□

### 3.2 Small-hull bound との差

定理 3.1 は、固定 source X に対する **選ばれた普遍近似**のサイズだけを抑える。全ての X-generated A-objects のサイズは要求しない。

反射 RX がある場合、全ての生成対象は RX の A-strong quotients である。それらのサイズは未制御でも、普遍近似は RX に停止する。従って「全ての hull を小さくする」方法から、必要以上の strong quotient smallness を切り離した。

ここで主張するのは条件の論理的な差であり、今回の P4 の仮定の下で反射的だが (SH) を満たさない具体例を構成したわけではない。

## 4. 元の source 上の等式は必ず集合段階で安定する

K_κ を r_κ の P 内の kernel pair とする。各 sort では X(d)×X(d) の同値関係であり、κ≤κ' なら

    K_κ' ⊆ K_κ.

これは固定集合上の減少列なので、ある κs 以後は安定する。具体的には、一度でも除かれる各 pair について最初に除かれる段階を取り、その集合個の段階の上限を取ればよい。

安定値は

    K_A(X) = {(x,y) : 全ての f:X→B, B∈A について f(x)=f(y)}

である。各 f は十分後の r_κ を経由し、各 r_κ 自身も A を値域にする射だからである。

P 内の商 q:X→Q=X/K_A(X) を取る。κ≥κs について

    r_κ = j_κ q,    j_κ:Q↪R_κ X

と因子化し、j_κ は ambient mono。これらの j_κ は transition と整合し、Q の像が各 R_κ X を A-hull として生成する。

**重要な限界。** 元の source の等式が安定することは、反射の近似が安定することを意味しない。追加される元と、その間の等式が未制御だからである。No.3 の像の反復でも問題となった混同をここでは避ける。

例えば A を simplicial sets 内の group nerves とし、X を二つの simplicial circles の wedge とする。自由群 F(a,b) と自由可換群 Z² に、二つの loop を各々 a,b と標準基底へ送ると

    X ↪ N(F(a,b)) → N(Z²)

を得る。X の二つの写像はどちらも mono で、各 target を A-hull として生成する。従って元の X 上の kernel はどちらも対角関係。

しかし中央の abelianization は非同型の A-strong epi。元の二つの loop は潰さず、後から生成された commutator を潰す。この例は、生成対象の間でも seed 上の kernel だけでは対象を決定できないことを示す。二つの対象が上記の canonical tower の特定の段階だと主張しているわけではない。

### 4.1 閉じる特別な場合

もし Q∈A なら、j_κ は seed を含む A-subobject なので同型。よって Q が X の反射になる。

特に A が全ての ambient subobjects にも閉じる場合、Q⊆R_κ X から Q∈A となり、反射は ambient regular epi として得られる。これは既知の epireflective な特別場合を再現する。

一般には Q が A に属するとは限らない。

## 5. Union 閉性をどこで使う必要があるか

ここまでの構成と同値定理は全小極限閉性だけによる。λ-directed-union 閉性を追加して一般の P4 を解くための残る十分かつ必要な目標は、各固定 X について

    ∃ν_X ∀κ  |R_κ X|≤ν_X                           (UA_X)

を証明すること。

これは新しい一般証明ではなく、正確に切り出した未解決補題である。

次の三つの近道はまだ使えない。

- 逆列 p_(κ',κ) を mono の順列と見なすこと。実際の transition は A-strong epi であり、mono なら既に同型。
- K_κ の安定を R_κ X の安定と見なすこと。
- 各段階の (B_κ) を κ に依存しない一様上界と見なすこと。

small-hull route は (UA_X) を全 X で導くが、前段ノートで示した通り局所可呈示性まで導く強い方法。反射性だけの肯定証明には、(UA_X) をより直接に抑える余地が残る。
