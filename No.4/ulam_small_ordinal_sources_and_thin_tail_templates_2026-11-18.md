# Ulam-small ordinal sources and thin tail templates in ZFC

2026-11-18. Status: **PROOF_RECONSTRUCTED**. The coordinating agent proposed both constructions and subsequently read and reconstructed the complete proof, including the ultrafilter classifications and cardinal bounds, finding no gap. No external review or formal verification. This note removes the initially suggested GCH hypothesis from their carrier bounds. It gives an explicit limitation of the endpoint-stability argument and a smaller row template; it does not construct or exclude the hypothetical paired monomorphism.

Put Ω=ω, c=2^ω and λ=c^+. The [canonical-orbit reduction](paired_tail_canonical_ordinal_orbit_and_endpoint_gap_2026-11-18.md) leaves open eventual constancy of second-sort profiles along a λ-long orbit. The first construction below shows that membership in C and carrier size λ do not by themselves imply that constancy, even when k already equals the limiting first-sort character.

## 1. Two cardinal and character facts

We have

    λ^ω=λ                                                  (1)

in ZFC. Every countable sequence in λ is bounded, since cf(λ)>ω. For each bound the sequence takes values in a set of size at most c, and c^ω=c. Taking λ possible bounds proves the upper estimate in (1).

Consequently a sigma-algebra generated by at most λ subsets has size at most λ. One can use countable labelled well-founded tree codes for its elements, or close under countable operations through ω_1 stages. The set of its Ω-valued measurable functions also has size at most λ, since each function is determined by its countable list of fibres.

Let B be a sigma-algebra on a nonempty set X, and let L(B) be all B-measurable functions X→Ω, with postcomposition action. Its equivariant characters are in bijection with the countably complete ultrafilters on B. Briefly, finite tuple coding forces a character to preserve all finite pointwise operations, so its values on indicators define an ultrafilter. Each countable B-partition is the fibre partition of an element of L(B), and its selected function value chooses a partition cell. This implies countable completeness. Conversely a countably complete ultrafilter selects exactly one fibre of every such function and hence defines an equivariant character.

In particular, if every countably complete ultrafilter on B is principal and B separates points, then

    H(L(B))=X

by evaluation, in ZFC.

## 2. A sigma-algebra of size λ whose countably complete ultrafilters are principal

First work on the underlying set λ. For each β<λ choose an injection

    e_β:β→c.

For α<λ and i<c put

    A_(α,i)={β>α:e_β(α)=i}.                            (2)

For fixed α these sets partition the tail β>α. For fixed i, the sets A_(α,i) are pairwise disjoint as α varies. This is the same Ulam matrix used in [the scalar cogeneration obstruction](monic_local_tail_object_not_cogenerated_by_v_templates_2026-11-18.md), §3.

Choose an injection c→2^ω. For every α include the countably many sets

    B_(α,n)=∪{A_(α,i):the n-th code bit of i is 1}.       (3)

Also include all bounded initial intervals I_η={β:β<η}, and, for each η<λ, countably many subsets of I_η separating its points, obtained from an injection I_η→2^ω. There are only λ generators. Let B_* be the sigma-algebra they generate.

**Lemma 2.** Every countably complete ultrafilter U on B_* is principal.

If some bounded initial interval I_η belongs to U, select the U-side of each of its countably many separating bits, relative to I_η. Their intersection belongs to U by countable completeness and has at most one point, so U is principal. The same bit intersections show that all singleton sets belong to B_*.

Otherwise every tail β>α belongs to U. For fixed α, select the U-side of each code set (3). Their countable intersection, also intersected with the tail, is a U-member. It is nonempty and, by injectivity of the code, is exactly one cell A_(α,i_α). Thus each row selects a column i_α<c.

Since there are λ>c rows, two distinct rows select the same column. Their selected cells are disjoint by (2), contradicting the ultrafilter property. This proves the lemma. ∎

The conclusion persists in any larger sigma-algebra on the same set: restriction of a countably complete ultrafilter to B_* is principal and contains a singleton, so the larger ultrafilter is principal too. The construction did not require adding all subsets of bounded intervals. The countable separating codes suffice, so no estimate 2^c=λ was used.

## 3. A C-source of size λ with an unstable binary orbit profile

Let X=[0,λ·2] with its compact ordinal topology, and choose a bijection X→λ. Transport B_* along it. Enlarge the transported generators by:

- all ordinal clopen subsets of X;
- the set A of successor ordinals strictly below λ;
- all inverse images of the generators under finite iterates of the ordinal successor map d_X, whose top endpoint is fixed.

Let B be the resulting sigma-algebra. There are λ generators, so |B|=λ and |L(B)|=λ. It is stable under d_X^−1: this holds on the iterated generators and passes to their sigma-algebra.

Define

    Y_0=C(X,Ω),       Y_1=L(B),
    p_Y=inclusion,   q_Y=d_X^*.

Both carriers have size exactly λ. The lower bound for Y_0 follows from its λ distinct interval indicators, and the upper bound is the usual clopen calculation for a compact ordinal. Every continuous function has finite image, so Y_0 is finite-support. Its character space is X by the compact evaluation lemma. Lemma 2 and §1 identify H(Y_1) with the same X, and restriction along p_Y is the identity on evaluation points. Thus

    Y∈C                                                    (4)

in ZFC.

Its character dynamics is D(ev_ξ)=ev_(d_X ξ). Starting at h=ev_0, the continuous canonical orbit is

    a_α=ev_α       (α≤λ).

Choose k=ev_λ, so k=a_λ already holds. Nevertheless the binary finite-support point z=χ_A∈Y_1 has profile

    s_(a_α)(z)=χ_A(α)       (α<λ),

which is not eventually constant: both successor and limit ordinals occur unboundedly below λ. Hence the left-limit character required by the endpoint argument does not exist for this trajectory.

This disproves the inference

    Y∈C and |Y_0|,|Y_1|≤λ  ⇒ all second profiles stabilize.

It does not give a paired-tail monomorphism E(Y)↪W. Any proof excluding that monomorphism must use an additional relation supplied by the actual full-power map, beyond these source properties.

## 4. A thin row template of size λ, again without GCH

There is also a useful smaller replacement for the full trimmed row template. Work now on X₀=[0,λ]. Let A_thin be the sigma-algebra generated by:

- all clopen ordinal subsets of X₀;
- for each bounded initial interval [0,β], countably many subsets of that interval separating its points;
- all inverse images of these generators under finite iterations of d_λ.

Every generator is either bounded below λ or is the complement in X₀ of such a bounded set. The class of bounded-or-complementary-bounded subsets is a sigma-algebra because cf(λ)>ω, and it is stable under d_λ^−1. Therefore every set in A_thin is of one of these two forms. Its cardinality is λ by (1) and the clopen lower bound.

Put

    R^thin_0=C(X₀,Ω),       R^thin_1=L(A_thin),
    p=inclusion,           q=d_λ^*.

For any r∈R^thin_1 the fibre at r(λ) contains the endpoint. A set of A_thin containing the endpoint is the complement of a bounded subset, so r is constant on some endpoint tail. Hence

    R^thin_1 ⊂ {r:[0,λ]→Ω : r is eventually constant,
                                      including the endpoint}.

Both thin carriers have size exactly λ in ZFC.

To classify countably complete ultrafilters U on A_thin, first suppose U contains a bounded set. A bounded initial interval then lies in U, and its countable separating codes make U principal, exactly as in §2. Otherwise U contains no bounded set and therefore selects precisely the sets containing an endpoint tail. This is the principal ultrafilter at λ. Thus every character of R^thin_1 is evaluation at one point of X₀. Restriction to R^thin_0 gives the compact ordinal evaluation bijection, and

    R^thin∈C                                               (5)

in ZFC.

## 5. What thin rows improve in the paired-tail reduction

For the thin-row quotient

    W^thin=colim_(γ<λ) E([γ,λ)·R^thin),

both component sets have cardinality at most 2^λ in ZFC. The earlier full trimmed carrier estimate required 2^{<λ}=λ to obtain this bound; the thin construction removes that requirement.

To infer |Y_i|≤λ from a hypothetical monomorphism E(Y)↪W^thin, one still needs the separate cardinal strictness

    2^λ<2^(λ^+).                                          (6)

Under (6), |Y_i|≥λ^+ would imply |Ω^(Y_i)|≥2^(λ^+)>|W^thin_i|. GCH implies (6), but no full GCH hypothesis is required for this particular inference. We do not infer (6) in ZFC.

The stage-induced paired-witness obstruction and the canonical-orbit construction carry over: they use the continuous first sort, the evaluation character classification on both sorts, and successor dynamics. All these remain available in (5). Thinness alone does not produce total row maps or strengthen arbitrary partial character filters to ultrafilters.

## 6. The Ulam constraints have not yet crossed the actual-map gap

The free-ultrafilter contradiction in §2 needs selection of a cell in **every one of λ matrix rows**. For a single row, countably many binary code choices suffice. But there are λ such rows, while the current partial-row synchronization has only c parameters at one stage. Applying the Ulam contradiction to all those rows at one retained tail coordinate is therefore not justified.

Moreover the source sets in (3), regarded as indicators in Y_1, are source *points*. Their simultaneous appearance as atomic row labels is a separate matter from preservation of c joins and meets among the functions in E(Y)_1. These two levels must not be conflated. Monicity gives unbounded recurrence of each point; it has not been shown to give a single row carrying all the required Ulam codes.

Thus the new source is a concrete counterexample to the size-only stabilization inference, and the thin row is a genuine cardinal improvement. Neither supplies the missing actual-map coherence argument. A use of Ulam's matrix to finish the paired-tail obstruction would have to derive simultaneous row choices, or an equivalent global ultrafilter, from j itself.
