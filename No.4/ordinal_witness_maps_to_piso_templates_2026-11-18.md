## 1. 対象と結論

[有限彩色ノート](ordinal_witness_maps_to_v2_finite_coloring_2026-11-18.md) と同じ実際の

    Y_κ=(C_κ --p=inclusion,q=d_κ^*--> B_κ),
    C_κ=Cont([0,κ],Ω_discrete),  B_κ=Ω^[0,κ]

を始域側に使う。

R∈C は各 sort が可算で、p_R が同型とする。正規化して

    R=(A --id,s--> A)

としてよい。A は可算有限支持 M_1-set、s は equivariant endomorphism。旧 T_α を使って

    V^R=colim_(α<ω_1) E(T_α・R)

と置く。この target の各 sort は L=Kappa^A、二本の構造射は id と s に沿う前合成 S。

**結論（ZFC）。** 任意の射 E(Y_κ)→V^R は、一つの V^R stage を経由する。特に

    R=(Ω²×ω --id,shift--> Ω²×ω)

もこの安全な範囲に入る。従って N の下では、全ての E(Y_κ)⇉V^R の equalizer が D に属する。

## 2. Scalar map は可算 Boolean meet を保存する

任意の集合 U に対し、M_2-map φ:Ω^U→Kappa が誘導する

    Φ:P(U)→B(Kappa),   Φ(S)=φ(χ_S)

は countable joins/meets を保存する。この部分には |U|≤𝔠 の仮定は不要である。

これは旧 scalar-stage lemma の前半の議論である。有限 Boolean 演算は tuple coding で保存される。可算族 S_n を disjointification して、各 u の最初の所属番号を記録する Ω 値関数を作る。その像を一つの stage に取り、各値の fibre を調べると可算 union の保存が従う。complement により可算 intersection も保存する。Kappa の Boolean 部分の可算演算は、可算個の元を共通の α<ω_1 に集めて点ごとに計算できる。

## 3. 全ての有限回の後続前合成が連続な関数

部分集合 C_n⊆C_κ を

    C_0=C_κ,
    C_(n+1)={f∈C_κ:q(f)∈p(C_n)}

と再帰的に定義する。つまり C_n は f,f∘d_κ,…,f∘d_κ^n が全て連続となる関数全体。

    C_∞=intersection_(n<ω) C_n。

**補題。** C_∞ は可算な有限支持 M_1-set であり、d_κ^* で閉じる。

κ<ω なら C_κ=Ω^(κ+1) 自体が可算なので直ちに従う。κ≥ω とする。この場合 C_∞ は、初めの有限個の自然数でだけ値を変更でき、それ以外では一定値を取る関数全体である。

証明。f∈C_∞ を取る。ω での連続性から、十分大きい自然数 n では f(n)=f(ω)=c。

f が [ω,κ] 上で常に c でないと仮定し、f(α)≠c となる最小の α≥ω を取る。連続性により α は極限でなく、α=β+1、β≥ω である。β=λ+n（λ は非零極限順序数、n<ω）と書く。

g=f∘d_κ^(n+1) は C_∞ の定義により連続。しかし

    g(λ)=f(λ+n+1)=f(α)≠c。

一方 ξ<λ なら ξ+(n+1)<λ である。λ=ω の場合は自然数上での f の eventual constancy、λ>ω の場合は α の最小性により、λ に十分近い ξ<λ では g(ξ)=c。これは λ での g の連続性に反する。

従って f は [ω,κ] 上で c。逆に、初めの有限個の自然数以外で一定の関数は、任意の有限回 d_κ と前合成しても同じ形であり連続。

こうした関数は有限列と一つの末尾値で記述できるので可算。C_∞ は C_κ の M_1-subset なので有限支持で、定義から d_κ^* で閉じる。□

Y_∞=(C_∞ --id,d_κ^*--> C_∞)∈C と置く。両 sort の inclusion により r:Y_∞→Y_κ がある。

## 4. 構造射の自然性が C_∞ への依存を強制する

θ:E(Y_κ)→V^R を取る。自然性は

    θ_1=θ_0 E(p),
    θ_0 E(q)=S θ_1=S θ_0 E(p)

を与える。各 a∈A について θ_0 の a 座標を

    φ_a:Ω^(C_κ)→Kappa

と書き、対応する Boolean map を Φ_a とする。二つ目の等式の a 座標は

    φ_a E(q)=φ_(s a) E(p)。

ここに χ_(p(C_n)):B_κ→{0,1} を入れると

    Φ_a(C_(n+1))=Φ_(s a)(C_n)

となる。Φ_a(C_0)=1 なので、全 a と全 n について Φ_a(C_n)=1。§2 の可算 meet 保存により

    Φ_a(C_∞)=1。

従って、f,g:C_κ→Ω が C_∞ 上で一致すれば φ_a(f)=φ_a(g)。これは有限彩色ノートと同じ sel(χ_(C_∞),f,g) の有限演算を使えばよい。全座標 a で成り立つから、θ_0 は制限 Ω^(C_κ)↠Ω^(C_∞) を経由する。

θ_1=θ_0E(p) も同じ制限を経由し、二つの構造射との自然性は全射な制限写像に沿って反映される。従って一意な射

    θ_∞:E(Y_∞)→V^R

が存在し、θ=θ_∞E(r) となる。

## 5. Stage 因子化と equalizer

C_∞ は可算で、定数関数を含むため countably infinite。よって Ω^(C_∞) は左 M_2-set として、全単射 C_∞→Ω 一つから生成される。E(Y_∞) は両 sort に一つずつ生成元を取ればよく、ambient finitely generated。

V^R は stage monos の directed union だから、θ_∞ は一つの stage E(T_α・R) を経由する。従って θ も同じ stage を経由する。

この stage map は、明示的な K-map T_α・R→Y_∞ の E 像である。実際、各 output 座標の M_2-map Ω^(C_∞)→Ω は、C_∞→Ω の全単射を生成元に取ると、一つの座標評価として一意に表せる。両作用と構造射の自然性から K-map が得られる。N は不要。

N の下で Y_κ∈C を使うと、任意の二射 E(Y_κ)⇉V^R は共通 stage で明示的な E(k_a),E(k_b) として表せる。C 内の coequalizer of k_a,k_b の E 像が元の二射の equalizer であるため、その equalizer は D に属する。

## 6. 探索上の境界

shift の無限軌道を導入しても、この template では反例が生じない。各 label の前向き軌道が、関数の全ての有限回の後続前合成を同時に連続にする条件を強制し、残る関数集合が可算になるためである。

実際の Y_κ を始域に保ち、この V^R 型を用いるなら、少なくとも p_R が同型という範囲を外す必要がある。本ノートは、p_R が同型でない場合の成否を結論しない。
