## 1. 研究目標

|Ω|=ρ、M=End(Ω)、H=Hom_M(-,Ω)。λ>ρ を正則とし

    L_λ=Ω^λ /（<λ 個の点での違いを同一視）

と置く。前段階の Hom 計算により H(L_λ) の元は ρ^+-complete uniform ultrafilter。

固定した ρ の圏・テスト・標的の coreflector R から μ(R,ρ) を得て、H(L_λ)=∅ のとき一様に小さい非空 null subact Y⊆L_λ を取り出す補題を狙った。その抽出自体は今回なお未構成。

## 2. 局所評価を相対化した purity

κ>max(|M|,ρ) が正則、F が proper κ-complete filter なら、L_F の <κ サイズの部分 M-set で全定数を含むものは、Ω への retraction を持つ。代表関数を選び、<κ 個の作用方程式が成立する集合を交叉し、共通の座標で評価する。定数は実際の定数関数を代表にする。

従って δ_F:Ω→L_F は κ-pure mono。ただし H(L_F)=∅ なら大域的 retraction はない。高い purity だけから目的の選択写像を結論できない。

## 3. 本質的値域への一様圧縮

S=P^+(Ω) に直接像作用を入れる。正則 λ>ρ について

    ess_λ([f])={a∈Ω:|f^(-1)(a)|=λ}

は同変な全射 L_λ↠S で、定数 a を {a} に送る。λ の正則性により、≤ρ 個の小さい fibre の合併は小さい。

|S|=2^ρ、H(S)=∅。後者は {0,1} を固定する交換による矛盾から従う。λ>max(|M|,2^ρ) なら Hom_M(S,L_λ)=∅。射があれば、その像は一様に小さい非空 null subact になり、前段階の局所評価に反する。

**小さい null な商があることと、小さい null 証人が L_λ の中にあることは逆向きであり、代用できない。**

## 4. 固定された小界面を保持しても圧縮できる

固定した M-set D と a:D→L_λ を取る。μ≥max(ρ,|D|,ℵ₀)、λ>ρ^μ を正則とする。

代表関数 f_d を選び、同時値パターン t(i)=(f_d(i))_(d∈D) により λ を分割する。パターンは ≤ρ^μ 個。サイズ λ のセル C_v を v∈J で索引すると、残りの合併は <λ、J≠∅。

各 C_v 内を置換し、例外部分を固定する群 Γ_a は a[D] を固定する。写像

    Ψ_a:L_λ→S^J,
    Ψ_a([f])(v)={b∈Ω:|C_v∩f^(-1)(b)|=λ}

は同変な全射であり、その fibres は正確に Γ_a 軌道となる。逆方向は、全ての小さい fibre を <λ 点の変更で除き、各大きな同値 fibre の間に全単射を選ぶことによる。

従って Ψ_a は群作用の coequalizer であり、

    |S^J|≤2^(ρ^μ),
    ker(Ψ_a a)=ker(a)。

特に a が mono なら、界面の全ての区別を残したまま圧縮できる。S^J も null。

## 5. 対称性を保つ貼合せ候補族の一様な因子化先

K は局所小で余完備、A⊆K は小余極限閉、G:(D↓M-Set)→K は上の群作用 coequalizer を保存するとする。Z_λ=G(a_λ)∈A、b_λ:Z_λ→B は固定標的への射で、Γ_(a_λ) に不変と仮定する。

すると b_λ は G(D→S^(J_λ)) を経由する。この対象は群作用図式の coequalizer なので A に残る。元の界面付き商のサイズは 2^(ρ^μ) 以下であり、その同型類は集合個。従って全 b_λ は集合個の A-対象を経由する。

これは、任意の商閉性ではなく **小余極限閉性** の適用である。A 全体の coreflectivity を証明したわけではない。適用に必要な仮定は (i)固定小界面、(ii)貼合せ関手が該当 coequalizer を保存、(iii)標的射が群作用に不変、の三つ。非対称な構造射、大きくなる界面、非不変な標的射などは排除していない。

## 6. 二つの具体的な構成の判定

### 元の平行二射クラスへの直接挿入

A_ρ={Z:Z_0 は有限支持、H(p_Z) 全単射}、B_ρ=(Ω⇉1) を維持する場合、Z∈A_ρ と Z→B_ρ から H(Z_1)≠∅ が従う。null L_λ から Z_1 への射は、これと合成すれば矛盾する。したがって L_λ を直接受け取る pushout を Z_1 に入れる方法は、合格性と標的への射を同時に満たせない。

### 固定した選択射

E={(A,a):a∈A∈P^+(Ω)}、π:E↠S とする。ess_λ の π に沿う lift は H(L_λ) と同値。さらに任意の proper filter F の商 q_F:Ω^I↠L_F は π に一意左直交する。

よって射の圏の一本の固定テスト (id_E)→π に対し q_F は合格対象となる。しかし標的 (Ω→1) は自ら合格するので障害なし。別の不合格標的 (Ω→S), a↦{a} については Hom_Arr(q_F,(Ω→S))≅H(L_F) となり、null な場合には試験対象から標的への射そのものが存在しない。

## 7. 次に残る点

固定小界面を増やすだけでは対称商は消えない。固定 signature のまま、λ に伴って増える分割・Boolean incidence を保持する構成は今回の除外定理の範囲外。

診断として、各大きいセルを二分した A⊆λ では χ_A と χ_(λ\A) が Ψ_a で同一視される。非自明な Boolean algebra の演算を同時に保存すれば x=¬x は不可能なので、この特定の圧縮を防げる。ただし Boolean 2 への高完備写像を先に要求すると目的の ultrafilter を入力に仮定することになり、循環する。

必要なのは、ultrafilter がなくても構成できる合格対象と固定標的への射を保ち、coreflector の普遍性の後で初めて選択を抽出する仕組み。その実現補題は未証明。
