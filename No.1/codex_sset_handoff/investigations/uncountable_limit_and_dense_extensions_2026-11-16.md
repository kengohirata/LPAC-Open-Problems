# 非可算極限の障害と固定自由群の拡大への還元

2026年11月16日。母圏は Ab。Hom は通常の群準同型、Ext は Ext¹_Z とする。既存の証明済み結果はユーザーの指示に従い前提として採用した。本稿の直接証明の状態は `PROOF_RECONSTRUCTED`。独立性の証明が完了したという意味ではない。

$$\mathcal T=\{A:\operatorname{Hom}(A,\mathbb Z)=0\},\qquad
\mathcal F=\{K:\operatorname{Hom}(T,K)=0\ (T\in\mathcal T)\}.$$

これは既存の torsion pair であり、T は商・直和・拡大で、F は部分群・積・拡大で閉じる。T∩F={0}。F は torsion-free 群からなり、自由群は F に、可除群は T に属する。t(A) は A の最大の T-部分群で、A/t(A)∈F である。

**今回の結果。** 非可算極限の零整数双対はまだ証明できていない。一方、その障害の正規形、後続段で核の整数双対を固定する構成、および

$$\mathcal T\text{ が well-powered}
\quad\Longleftrightarrow\quad
\mathcal F\text{ が co-well-powered} \tag{1}$$

を ZFC で得た。可算標的に限れば、固定した S=Z^(ω) の F 内の拡大、または固定した B₀=(Q/Z)^(ω) の T 内部部分対象に問題を統一できる。

## 1. 非可算極限で現れ得る整数値準同型

λ は cf(λ)>ω の極限順序数とし、(E_α)_{α<λ} は途中の全極限段で連続な全射逆塔、各 E_α∈T とする。L=lim E_α、p_α:L→E_α、N_α=ker p_α と置く。各 p_α の全射性は既存の連続逆塔の補題を使う。

### 1.1 尾部の像の安定化

**補題。** 非零 h:L→Z があれば、ある β<λ と d>0 に対し

$$h(N_\alpha)=d\mathbb Z\qquad(\beta\le\alpha<\lambda).\tag{2}$$

**証明。** h(N_α)=0 なら h は E_α を経由するので零となり矛盾。各像は非零の Z の部分群で、α とともに下降する。Z の部分群は可算個しかないので、各現れる値の最初の添字を集め、その可算集合の上界を β<λ に取れる。β 以降に新しい値はなく、下降性から一定になる。∎

これは「すべての準同型はある段階を経由する」という結論ではない。未排除の可能性は、すべての十分深い核に同じ非零像が残ることである。

### 1.2 稠密な直和因子への正規化

h をその像の生成元で割り、h:L→Z を全射としてよい。(2) の β 以降に制限する。h mod d は

$$q_\alpha:E_\alpha\to\mathbb Z/d\mathbb Z$$

を誘導する。E'_α=ker q_α、L'=h^−1(dZ) と置く。

有限指数部分群 A'≤A∈T も T に属する。実際、指数を m とすると、任意の f:A'→Z に対し a↦f(ma) は A→Z なので零である。a'∈A' について mf(a')=0 となり、f=0。

従って各 E'_α∈T である。q_α は射と整合し、E'_α の逆塔は連続かつ全射で、その極限は L'。後続射の核は元の塔の核と同じである。

$$h'=h/d:L'\twoheadrightarrow\mathbb Z,\qquad M=\ker h'$$

とすると、h'(N_α)=Z。Z が自由なので L'=M⊕Z。また M→E'_α は全射である。実際、x∈L' の α 座標を保ったまま、h'(n)=h'(x) を満たす n∈N_α を引けば M の元になる。

したがって、もし零双対の保存が失敗するなら、有限指数の修正後の極限は **全段へ全射する真の直和因子 M を持つ M⊕Z** となる。N_α を零の近傍とする位相では M は稠密である。

### 1.3 球完備性とその限界

今回の L では、N_α の剰余類からなる任意の包含で全順序づけられた非空族に交点がある。添字が λ に共終なら整合座標が L の元を定める。添字が δ<λ に共終で最大値を持たなければ、E_δ の連続性で元を得て L→E_δ の全射性で持ち上げる。最大値を持つ場合はその剰余類を使う。これがここでいう球完備性である。

しかし、これだけで §1.2 の稠密な直和因子を排除する証明は得られていない。可算個の条件を合わせても、その添字の上限 δ は λ 未満に留まり、N_δ 上で h' は依然全射である。通常の可算無限和による矛盾は、この段階で止まる。

適用範囲の対照として、κ が可測なら、連続全射塔 E_α=Z^α (α<κ) の極限 Z^κ には一様な κ-完全 ultrafilter による h_U:Z^κ→Z がある。整数値関数は可算分割のちょうど一つの値を U 上で取るので h_U は定義でき、加法的である。各 α の尾部の指示関数は N_α に属して値1を持つため、どの段にも因子化しない。この塔も球完備で後続核は Z である。ただし各 E_α∈T という条件は満たさず、V=L や ω₁ の構成への反例でもない。

[El Bashir–Kepka, Modules commuting (via Hom) with some limits, §11.1, §11.5](https://matwbn.icm.edu.pl/ksiazki/fm/fm155/fm15535.pdf) も調べた。§11.1 の可算列に関する結果は使えるが、§11.5 の非可算全射系は連続な塔への反例を与えない。これを今回の欠けた補題の代用にはしない。

## 2. 後続段では核の整数双対を増やさずに巨大化できる

N は可測基数の非存在とする。固定した短完全列

$$0\to K\to E\to B\to0,\qquad E,B\in T,\quad K\in F$$

を考える。制限 res:Ext(E,Z)→Ext(K,Z) の下で、像が Z-線形独立となる拡大類 ξ_j (j∈J) を選ぶ。それらの Z-拡大の fiber product を Y とし、K'=ker(Y→B) と置く。

**補題。**

$$0\to\mathbb Z^J\to Y\to E\to0,\qquad
Y\in T,\quad K'\in F,\quad K^*\xrightarrow{\sim}(K')^*.\tag{3}$$

ここで (−)*=Hom(−,Z) であり、最後の同型は K'→K からの引戻しである。

**証明。** N より (Z^J)*=Z^(J)。connecting map で標準基底の像は ξ_j なので、その独立性から Y*=0。K 上に引き戻した拡大の connecting map は標準基底を res(ξ_j) に写すので、これも単射。Hom–Ext 完全列から K*→(K')* が同型となる。K' は F に属する二群 Z^J と K の拡大なので F に属する。∎

Ab の Ext²=0 と長完全列から

$$\ker(\mathrm{res})=\operatorname{im}(\operatorname{Ext}(B,Z)\to\operatorname{Ext}(E,Z)).$$

κ=max(ℵ₀,|B|) とすれば |Ext(B,Z)|≤2^κ。V=L、E が非零 torsion-free、2^|E|>2^κ なら、既存の Ext 階数公式 r₀Ext(E,Z)=2^|E| により、制限後も 2^|E| 個の独立な類を選べる。従って (3) で |Y|=2^{2^|E|}>|E| とできる。

**帰結。** 既存の E₁→G_b から始め、V=L の下で全可算順序数にわたる増大後続構成を、核の双対 K_α* がずっと K₁* と同型となるように選べる。可算極限では核の塔も連続・全射であり、Z の可算 inverse-limit slenderness により極限の各整数値準同型がある段を経由するからである。

この改良は、後続段で新しい双対が増えることを防ぐ。**ω₁ の極限で初めて現れる準同型を排除したものではない。** したがって、双対を後続段で固定する選択だけでは極限の問題は解消しない。

## 3. 内部全射と内部単射の双対的なサイズ問題

### 3.1 F 内の全射の判定

**補題（ZFC）。** f:S→K は F の射とする。次は同値である。

1. f は F 内で epi。
2. 通常の coker f は T に属する。
3. f*:Hom(K,Z)→Hom(S,Z) は単射。

**証明。** (2)⇒(1) は、差が f 上で零となる二射 K→F' の差が coker f を経由し、Hom(T,F')=0 となることによる。(1)⇒(2) では C=coker f とし、K→C/t(C)∈F が f 上で零となるので零。通常の全射 K→C と C→C/t(C) から C=t(C)。最後に (2)⇔(3) は Hom(−,Z) の左完全性である。∎

通常の単射 S↪K も満たす場合、以下では K/S∈T となるこの拡大を **F-dense extension** と呼ぶ。この語は §1 の逆極限位相での稠密性とは別の、ここで定義した代数的条件である。

### 3.2 T well-powered ⇔ F co-well-powered

**定理（ZFC）。** (1) が成立する。

**証明：F co-well-powered ⇒ T well-powered。** B∈T を固定する。内部単射 m:E→B の通常の像 A は E の商なので T に属する。A≤B の選択肢は集合個である。従って A を固定し、m:E↠A が通常の全射の場合を扱えばよい。

自由表示 0→H→P→A→0 を固定し、X=E×_A P と置く。K=ker m∈F であり、

$$0\to K\to X\to P\to0$$

は P の自由性で分裂する。従って X≅K⊕P∈F。一方、

$$0\to H\to X\to E\to0$$

も完全なので H→X は F 内の epi。co-well-poweredness により、固定 H からのこれらの行き先 X のサイズには一様な集合基数上界がある。E は X の商なので同じく有界。集合個の A を合わせても上界が得られ、そのサイズ以下の群と B への射は同型を除き集合個である。

**証明：T well-powered ⇒ F co-well-powered。** S∈F を固定し、通常の単射 i:S↪D を D=Q⊗S に取る。D は可除で T に属し、B=D/S も T に属する。

任意の F 内の epi f:S→K に対し pushout

$$E=(D\oplus K)/\langle(i(s),-f(s)):s\in S\rangle$$

を取る。i が単射なので K→E は単射であり、

$$0\to K\to E\to B\to0$$

が完全である。また D→E の像は D の商なので T に属し、その余核は coker f∈T。拡大閉性により E∈T。従って E→B は T 内部単射である。固定 B の内部部分対象のサイズが有界なら |K|≤|E| も有界であり、固定 S からの epi の同型類は集合個となる。∎

この証明では、後半の f を通常の単射とは仮定していない。pushout で K↪E となる根拠は、もう一辺 i:S↪D の単射性である。

## 4. 可算標的は一つの自由群の拡大へ統一できる

$$S_0=\mathbb Z^{(\omega)},\qquad D_0=\mathbb Q^{(\omega)},\qquad B_0=D_0/S_0=(\mathbb Q/\mathbb Z)^{(\omega)}.$$

**定理（ZFC）。** 次は同値である。

1. ある可算 B∈T の T 内部部分対象が集合個でない。
2. 固定した S₀ の F-dense extensions S₀↪K のサイズが、すべての集合基数上界を超える。
3. 固定した可算可除 torsion 群 B₀ の T 内部部分対象が集合個でない。

**証明。** (1) の内部部分対象について、§3.2 と同様に集合個の通常の像 A≤B へ分ける。少なくとも一つの A で始域のサイズが非有界でなければ、全体にも集合上界がある。A の自由表示 H↪P↠A では H,P を可算自由群に選べる。pullback で得る H↪X は F-dense extension で、X↠E だからサイズも非有界である。

可算自由群 H に可算自由直和因子 C を足し、H⊕C≅S₀ と固定する。H⊕C↪X⊕C は依然 F-dense extension で、余核は E のままである。これにより (2) を得る。

(2)⇒(3) は固定した S₀↪D₀ と S₀↪K の pushout を用いる §3.2 の構成。|E|≥|K| であり、E→B₀ は内部単射かつ通常の全射。(3)⇒(1) は直接である。∎

この同値は、T の非 well-poweredness が常に可算標的で検出できると主張するものではない。**現在調べている可算標的での否定問題**を統一した結果である。

既存の全可算順序数の族にもこの変換を適用できる。従って N の下で、S₀ の F-dense extensions と B₀ の内部部分対象の双方に、各 α<ω₁ に対応する既存の beth_{α+1} 以上のサイズを実現できる。しかしこの族も依然として集合個である。

### 4.1 有限 rank の自由群では非有界拡大は起こらない

**補題（ZFC）。** S は有限生成で、S↪K は F-dense extension とする。このとき K は有限 rank の自由群である。

**証明。** S∈F なので有限 rank の自由群であり、K*↪S* から K* も有限生成自由群となる。その基底で評価すると K/R(K) は有限積 Z^r の部分群なので有限 rank 自由群。従って 0→R(K)→K→K/R(K)→0 は分裂する。分裂により R(K) から Z への任意の射は K に延長できるが、R(K) の定義上それは零である。ゆえに R(K)∈T∩F={0}。∎

したがって §4 の可算無限 rank の S₀ は、有限 rank の同じ問題へ置き換えられない。

## 5. 非 well-poweredness から P の否定へは別の構成が必要

**補題。** 固定 B 上の整合的な逆塔 m_α:E_α→B と固定した充満部分圏 A を考える。この塔の項のうち A に属するものが存在すれば、その最初の項 E_α₀ 一つで、該当する全項から B への射を因子化できる。

**証明。** 該当する添字の非空族には最小の順序数 α₀ があり、β≥α₀ では m_β=m_α₀ p_{βα₀}。∎

候補族が集合個の逆塔で覆われる場合も、各塔の最初の A-項を集めた集合が、その候補族に対する弱終集合となる。これは候補族以外も含む A↓B 全体に解集合があるという主張ではない。

従って巨大な内部単射の下降塔を任意に長く構成できても、その項で A={}^⊥S に入るものをそのまま使うだけでは、解集合条件の失敗を示せない。仮想的な coreflection R→B に E_α が因子化した場合にも、E_α→R が内部単射だからというだけでは |E_α|≤|R| は言えない。

必要なのは、固定した集合 S に対して、A に属する中間対象への**通常の因子化に無界なサイズ下界を与える仕組み**である。本稿はその仕組みを構成していない。

## 6. 到達点と実際に止まっている箇所

今回、後続段の双対の固定、球完備性、成長する T-部分群の保持、F の dense extension、一般の随伴関手定理からの接続を検討した。成長する T-部分群を保持する案も、その核の F-dense extension を作る問題に戻る。F に generator Z があっても、包含 F→Ab が余極限を保存するわけではないので、co-well-poweredness と随伴関手定理だけから直ちに矛盾は出ない。

今後の具体的な新補題として残るのは、次のいずれかである。

- V=L で、§1 の稠密な直和因子が生じないように拡大を選び、最初の ω₁ 極限で Hom(L,Z)=0 を保つ。
- 同じ仮定の下で、固定した S₀=Z^(ω) について K∈F、K/S₀∈T を満たす K を、任意の集合基数より大きく作る。こちらは逆極限の保存を経由しない。

どちらも未証明であり、現時点の方法ではここで止まっている。さらに一方を解決して非 well-poweredness を得た後も、§5 の第二の関門が残る。**非 well-poweredness、P の否定、ZFC 独立性は今回も未確立である。**
