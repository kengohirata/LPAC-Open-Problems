# リスト彩色から独立性への還元と内部単射の障害

2026年11月15日。対象は ordinary Hom による Adámek–Rosický Problem 1 の命題 P。本稿の新しい直接証明は `PROOF_RECONSTRUCTED` とし、主担当による点検までで、独立査読・形式検証・新規性確認はしていない。

**独立性の証明および否定側モデルは得られていない。** 調べたのは、可算色リスト彩色の非コンパクト性を、固定したテスト集合と標的における解集合条件の失敗へ移す方法である。得られたのは、次の必要条件と、具体的な符号化を除外する証明である。

- 非 coreflective な small coorthogonality class があるなら、そのテストの「持ち上げの一意性だけ」を課した部分圏は well-powered ではない。
- 彩色不能クラスをそのまま使う方法も、各連結成分に彩色不能性を課す方法も、この必要条件を満たさない。後者では、内部単射の始域のサイズを明示的に抑えられる。
- すべての部分彩色の一意な完成を要求する固定テスト、および彩色の制限写像が全単射になる射を arrow category で扱う固定テストにも、ZFC の肯定証明がある。

したがって、前の提案で掲げた P ⇒「ω₁-strongly compact cardinal が存在する」は、依然として未証明の研究目標である。以下の証明はこの含意を成立させたものではない。

## 1 集合論側で使える反例

色を ω に固定する。C_κ を「各頂点にリスト L(v)⊆ω を指定した任意のグラフについて、すべての頂点数 <κ の部分グラフが彩色可能なら、全体も彩色可能」とする。非可算 κ について

\[
C_\kappa\quad\Longleftrightarrow\quad
\kappa\text{ is }\omega_1\text{-strongly compact}
\]

は Feller–Holy, Definition 6, Theorem 7 の δ=ω の場合である。2026年11月15日に [arXiv:2608.20883v1](https://arxiv.org/html/2608.20883v1) の定義と定理を確認した。通常の可算彩色とリスト彩色を同一視しない。

従って、そのような巨大基数がない場合、各非可算 κ に対して、全体は彩色不能だが <κ の部分グラフはすべて彩色可能という例が存在する。しかし、この文献定理は coreflectivity について何も結論していない。

圏論的符号化は旧ノートと同じものを使う。Λ は頂点集合 P(ω) を持ち、各順序対に辺を一本持つ quiver。K=Quiv/Λ とする。D の頂点は (L,n), n∈L、辺は色の異なる二頂点間に一本ずつであり、リストへの射影を構造射とする。すると K((G,L),D) はリスト彩色の集合である。K は局所可呈示な前層圏である。

## 2 一意性の部分圏と well-poweredness

ここでは K を任意の局所可呈示圏、S={f_i:U_i→V_i | i∈I} を射の集合とする。

\[
\mathcal A={}^\perp S,\qquad
\mathcal I=\{X:\mathcal K(X,f_i)\text{ がすべて単射}\}.
\]

### 2.1 一意性だけの条件には ZFC で coreflector がある

P_i=U_i×_{V_i}U_i とし、対角単射 δ_i:U_i→P_i を取る。Hom(X,δ_i) が全単射であることは、Hom(X,f_i) が単射であることと同値なので

\[
\mathcal I={}^\perp\{\delta_i:i\in I\}.
\]

単射への coorthogonality class は小余極限および strong quotient に閉じる。後者は strong epi と mono の持ち上げ性から従う。固定した B の部分対象で I に属するものを集合個集め、その余積の B への strong image を取れば I に属する。任意の I-対象から B への射の strong image もその集合に含まれるので、これが I-coreflection となる。一意性は B への単射性による。

従って包含 J:I→K は右随伴 R を持ち、counit JR(B)→B は K の単射である。I は小余極限を K で計算し、小極限は K の極限に R を適用して計算できる。

### 2.2 残る条件は I の内部の単射になる

随伴から、X∈I について

\[
\mathcal I(X,Rf_i)\cong\mathcal K(JX,f_i).
\]

右辺は単射なので、Rf_i は **I の中で** mono である。また

\[
\mathcal A={}^\perp_{\mathcal I}\{Rf_i:i\in I\}.
\]

Rf_i が K でも mono であるとは限らない。例えば Ab で f:Q→Q/Z とすると I={A:Hom(A,Z)=0}。Q と Q/Z は I に属し、f は I では mono だが、Ab では kernel Z を持つ。

### 2.3 well-powered なら coreflectivity が従う

**命題。** 上の I が well-powered、すなわち各対象の I 内の部分対象が同型を除いて集合個なら、A は K において coreflective である。

**証明。** I は完備かつ well-powered なので strong epi–mono 分解を持つ。実際、ある射を通す mono の集合を取り、その交わりを形成すると最小の部分対象が得られる。そこへの射は extremal epi であり、pullback があるので strong epi である。

A は I の小余極限に閉じる。さらに Rf_i が I-mono であるため、A は I の strong quotient にも閉じる。従って、固定した T∈I に対する A-対象の I-subobject を集合個集め、余積の strong image を取る方法で、T の A-coreflection を構成できる。I→K の coreflection と合成すれば、K 全体での A-coreflection が得られる。∎

従って

\[
\boxed{\mathcal A\text{ が非 coreflective}
\ \Longrightarrow\ \mathcal I\text{ は非 well-powered}.}
\]

これは必要条件であって十分条件ではない。I が非 accessible であるだけでは足りない。また、非 well-poweredness が分かっても、A↓B の解集合条件の失敗は別途必要である。

## 3 彩色不能クラスを一意性の部分圏にする案

ここから §5 までは、特記した有限例を除き K=Quiv/Λ に戻す。

N={0}∪{X:K(X,D)=∅} は {}^⊥{0→D} であり、coreflector は B が彩色不能なら B、彩色可能なら 0 である。

**補題。** N の内部の mono は K でも mono である。

**証明。** m:X→Y を N-mono とする。X=0 の場合は初対象が strict なので自明。X≠0 なら X は彩色不能である。任意の u,v:T→X について mu=mv と仮定する。X⊔T は X を含むため彩色不能、従って N の対象である。二つの射

\[
[1_X,u],[1_X,v]:X\amalg T\longrightarrow X
\]

の m との合成は等しい。N-mono 性から u=v。従って m は K-mono。∎

従って N は well-powered である。あるテスト集合の一意性部分圏 I を N と一致させることに成功しても、§2.3 により、そのテストの coorthogonality class は coreflective になる。

旧ノートの「N が非 accessible になり得る」という事実を、そのまま一意性の部分圏へ移すだけでは、この障害を回避できない。

## 4 連結成分ごとの彩色不能性

前節の X⊔T による議論を避けるため、次の改良を調べる。

\[
\mathcal C_D=\{X:X\text{ のすべての非空連結成分が }D\text{ に写らない}\}.
\]

連結成分は quiver の辺の向きを忘れて定義する。ラベルは引き続き保存する。空対象も C_D に含める。

### 4.1 固定した単射と coreflector

K の終対象を 1 とし、余積の包含 j:1→1⊔D を取る。連結成分から余積への射は一方の summand に入る。1 への射は一意なので

\[
\mathcal C_D={}^\perp\{j:1\longrightarrow1\amalg D\}.
\]

coreflector R_D(B) は、B の D に写らない連結成分だけの合併である。C_D の対象の各成分が B に写ると、その像を含む B の成分は彩色不能である。従って R_D(B)→B は全対象・全射に対する普遍性を満たす。

### 4.2 内部単射のサイズを抑える

**定理。** m:A→B を C_D の内部の mono とし、

\[
\mu=\max(\aleph_0,|B_v|+|B_e|)
\]

とする。このとき |A_v|+|A_e|≤2^μ。特に C_D は ZFC で well-powered である。

**証明。** まず、A のある頂点 x を始点に持つ相異なる辺 e,e' が m_e(e)=m_e(e') を満たすことはない。仮にあれば、K の kernel pair A×_B A の辺 (e,e') は対角頂点 (x,x) から出る。その辺を含む連結成分 H は、x の属する A の連結成分 C の対角像全体を含む。C は彩色不能なので H も彩色不能であり、H∈C_D である。

二つの射影 H⇉A は辺 (e,e') 上で異なるが、m との合成は等しい。これは C_D-mono 性に反する。同じ議論を終点に適用できる。

従って、A の各頂点から出る辺と入る辺の数は、それぞれ |B_e| 以下である。連結成分の任意の頂点は根から有限の無向道で到達できるため、各連結成分の頂点・辺の総数は μ 以下となる。

サイズ μ 以下の連結 quiver と B への射の同型類は 2^μ 個以下である。Λ へのラベルは B への射から決まるので、この数え上げに Λ 全体のサイズを追加する必要はない。

A の二つの異なる連結成分 C,C' が B 上で同型なら、C∈C_D から A への包含と、C≅C' の後の包含が、m との合成の等しい相異なる二射となる。従って同じ同型類が二度現れることはない。

以上から A の連結成分数は 2^μ 以下、総サイズも μ·2^μ=2^μ 以下である。B=0 なら A=0 であり同じ上界で足りる。サイズ有界の対象と B への射は同型を除いて集合個なので、well-poweredness が従う。∎

これは有限グラフの定理ではない。D およびリストにサイズ制限を置かず、任意の大きさの A を対象として証明している。

### 4.3 内部単射は元の単射と異なる

前節より強い「すべての内部単射が元の単射」という主張は偽である。具体例は K=Quiv、D=双方向の K₂ で作れる。

B は頂点一つと二つのループ a,b を持つ。A は頂点 {0,1,2} を持ち、各頂点 x から (0 1)(x) への a 辺と、(1 2)(x) への b 辺を持つ。m:A→B は全頂点を一点へ、辺をそのラベルへ写す。

A は連結でループを持つため D に写らず、B も同様である。K の kernel pair A×_B A は、対角の3頂点成分と、非対角の6頂点成分に分かれる。前者は A と同型で彩色不能、後者は二部グラフである。従って C_D 内の kernel pair は対角成分だけとなり、m は C_D-mono である。一方、m は頂点でも辺でも単射ではない。

この具体例は `checks/verify_colouring_internal_mono.py` で構造と全二彩色を検算する。一般のサイズ上界の証明は §4.2 にあり、この有限計算から推論しない。

### 4.4 非 accessibility は依然として起こる

§1 のリスト彩色対象 D に戻すと、C_D が accessible であることも ∃κ C_κ と同値である。

前向きは accessible generators のサイズを一様に抑える。任意の非空な彩色不能連結グラフ X∈C_D に、ある非空 generator から射がある。その generator の非空成分は彩色不能なので、像から小さい彩色不能部分グラフが得られる。一般の彩色不能グラフには彩色不能な成分があるから、同じ上界で C_κ が従う。

逆向きは C_κ を仮定し、十分大きい非可算正則 λ>κ を取る。X∈C_D のサイズ <λ の部分集合に対して、それが触れる各成分内の小さい彩色不能部分グラフを加え、選んだ頂点と証人を有限の道で結ぶ。必要なら証人内の頂点も有限の道で結ぶ。得られる部分 quiver のサイズは <λ で、各成分は彩色不能である。このような部分対象は λ-directed に X を覆い、母圏および C_D で λ-presentable である。同型類は集合個なので accessibility が従う。

従って ω₁-strongly compact cardinal が存在しない場合の C_D は **非 accessible だが well-powered かつ coreflective** である。C_D をテストの一意性部分圏にする案も、§2.3 と §4.2 により反例を与えない。

## 5 すべての部分彩色を一意に完成する固定テスト

「一つの彩色の存在」から「すべての部分彩色の一意延長」へ移す、直接的な候補を定義する。以下は §1 の K=Quiv/Λ での構成である。

V の頂点を (L,a), a∈L∪{⋆} とする。⋆ は未指定を表す。二頂点間の辺は、いずれかが ⋆、または指定された二色が異なる場合に一本存在する。X→V は X の任意の頂点部分集合上の、適正な部分リスト彩色に対応する。

U の頂点を (L,a,n), n∈L, a=⋆ または a=n とする。二頂点間の辺は完成色 n,m が異なる場合に一本存在する。f:U→V は完成色を忘れる射である。従って Hom(X,f) の各 fibre は、指定された部分彩色の全体彩色への完成の集合である。

**命題。** X⊥f と、次の二条件は同値である。

1. X の各頂点のリストが一元集合である。
2. 辺の両端にある、その唯一の色が異なる。

**証明。** 全頂点を ⋆ とする射 X→V は常にある。X⊥f ならその一意な持ち上げが一意な全体彩色 c を与える。特に各リストは非空で、X にはループがない。

頂点 x と n∈L(x) を任意に取り、x だけを n に彩色して他を ⋆ とする。ループがないのでこれは適正な部分彩色である。その完成は必ず c だから n=c(x)。従って各リストは一元集合であり、辺の条件も c から従う。逆は、唯一の色の割当がすべての部分彩色を一意に完成することから従う。空対象にも同値性は成立する。∎

Λ のうち一元リストの頂点と、色の異なる二頂点間の辺だけを残した部分対象を M↪1 とすると、上のクラスは {}^⊥{M↪1} と一致する。従って ZFC で coreflective。B の coreflection は、一元リストの頂点と、適正な両端を持つ辺を残した部分 quiver である。

この候補では、元の彩色不能グラフはそもそも A_f に入らない。全く指定しない部分彩色の持ち上げが存在しないためである。

### 固定した唯一の証人を追加する改良も有界である

次の一般化も直接証明できる。K を局所可呈示、{D_j} を対象の集合、M を単射の集合とする。

\[
\mathcal B=\{X:|\mathcal K(X,D_j)|=1\ (\forall j)\}\cap{}^\perp M
\]

は coreflective である。D=∏_j D_j とすれば、最初の条件は |K(X,D)|=1 と同値である。

任意の a:A→B, A∈\(\mathcal B\) について、唯一の c:A→D を合わせた射 A→B×D の strong image Q を取る。Q は D への射を持ち、A↠Q が epi なのでその射は一意。また {}^⊥M は strong quotient に閉じるため Q∈\(\mathcal B\)。こうした Q↪B×D の集合の余積を取り、再び strong image を取ると、B の coreflector R_B↪B×D が得られる。B への因子分解の一意性は、D への成分も一意であることから従う。

従って、集合個の固定した唯一の彩色・証人と mono 条件を組み合わせる限り、固定した B×D の中に候補を収められる。独立性の反例に必要な無界な因子化サイズは生じない。

## 6 彩色の一意延長を arrow category で扱う案

別の候補として、部分グラフの包含も対象の一部として保持する方法を調べる。この節は任意の局所可呈示圏 K と固定対象 D に適用できる。

K^→ 内の固定射

\[
\tau_D:(D\xrightarrow{1_D}D)\longrightarrow(D\longrightarrow1)
\]

を、成分 (1_D,!) で定める。対象 e:A→B に対し

\[
K^\to(e,1_D)\cong K(B,D),\qquad
K^\to(e,D\to1)\cong K(A,D).
\]

従って

\[
\mathcal E_D={}^\perp\{\tau_D\}
=\{e:A\to B:K(e,D)\text{ が全単射}\}.
\]

リスト彩色の場合、これは「A の各彩色が B に一意に延長する」という条件であり、§5 と異なり、対象として選んだ一つの境界射 e を保持している。

### 固定対象の全体彩色への Hom を保存する射のクラスは coreflective

**定理。** E_D は K^→ において ZFC で coreflective である。

**証明。** 固定した標的 b:X→Y を取る。e:A→B∈E_D から b への任意の正方形 (u:A→X,v:B→Y) を考える。pushout Z=X⊔_A B を取り、j:X→Z と z:Z→Y を得る。

Hom(-,D) は pushout を pullback に移すので、j も E_D に属する。H=K(X,D) と置く。各 h∈H は一意に \widetilde h:Z→D に延長する。これらと z を合わせた射を strong epi–mono 分解する。

\[
Z\xrightarrow{q}Q\lhook\joinrel\longrightarrow Y\times D^H.
\]

j'=qj:X→Q は再び E_D に属する。実際、各 h:X→D は記録した座標 Q→D によって延長する。r,s:Q→D が rj'=sj' を満たすなら、j∈E_D によって rq=sq、q が epi なので r=s である。

元の正方形 e→b は、(u,q\circ(B→Z)) により j'→b を経由する。Q は固定対象 Y×D^{K(X,D)} の部分対象であり、そのような Q と j':X→Q、Q→Y の組は同型を除いて集合個である。従って E_D↓b には weakly terminal な集合がある。

E_D は coorthogonality class なので小余極限閉、E_D↓b は余完備である。弱終集合から終対象を得る初対象補題の双対により、b の coreflection が存在する。∎

対象の集合 {D_j} に対しても、固定対象を

\[
Y\times\prod_jD_j^{K(X,D_j)}
\]

に置き換えれば同じ証明が成立する。彩色の一意延長を射として保持する方法そのものも、今回必要な非 coreflectivity を生まない。

## 7 還元に残る条件

今回検査した案は、単に有限範囲で反例が見つからなかったのではない。それぞれ、任意の大きさの対象を含む ZFC の肯定証明によって除外された。

| 調べた符号化 | 全サイズについての判定 |
|---|---|
| 彩色不能クラス N を一意性部分圏とする | 内部 mono は元の mono。well-powered なので反例にならない |
| 成分ごとの彩色不能クラス C_D を一意性部分圏とする | 内部 mono は増えるが、固定 B に対し始域は 2^μ 以下。反例にならない |
| 全部分彩色を一意に完成させる f | 一元リストの適正なグラフだけになり、mono test に帰着する |
| 固定した唯一の証人と mono 条件の組合せ | B×∏D_j 内の strong image で coreflector を構成できる |
| 境界射の彩色を一意に延長する τ_D | Y×D^{K(X,D)} 内の像から解集合条件が得られる |

否定側へ進む構成には、少なくとも次が必要である。

1. 固定したテスト集合 S の一意性部分圏 I_S を、上記の well-powered なクラスとは異なるものにする。
2. I_S のある固定対象に、集合個では尽くせない内部部分対象が生じることを証明する。これが §2 の新しい必要条件である。
3. その障害が A_S 内にも残り、同じ固定 B について、小さい A_S-対象を経由できない射が各基数で存在することを示す。

2 だけでも独立性の証明にはならず、3 の全称的な因子化障害を要する。I_S の内部での大小と、母圏の carrier の大小も混同しない。

**現時点では、この三条件を満たす固定テストは構成できていない。** リスト彩色の反例そのものの存在は §1 から得られるが、それを 2 および 3 に移す対応が未解決である。従って、P から巨大基数の存在を導く含意、¬P のモデル、ZFC 独立性はいずれも未確立である。

肯定側の十分条件は既存の [集合論的監査](../audits/set_theoretic_upper_bound.md) に記録したものを維持する。本稿の除外結果から、すべてのリスト彩色に基づく還元が不可能であるとも、P が ZFC 定理であるとも結論しない。
