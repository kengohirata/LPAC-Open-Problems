# 可測基数が存在しない場合を否定側の作業仮定にする

2026年11月15日。目的は P の集合論的強度を最適化することではなく、ZFC 独立性に必要な否定側のモデルを得ることである。以下では

\[
Q=\text{supercompact cardinal が真のクラス存在する},\qquad
R=\text{可測基数が存在する}
\]

と置き、**¬R を否定側の作業仮定に採用する**。具体的な構成で必要なら V=L のモデルに限定する。P⇒R、¬R⇒¬P、および V=L⇒¬P は、いずれもまだ証明していない。

## 1 この選択で十分な理由

Q⇒R なので、¬R⇒¬Q。従って既知の肯定側 Q⇒P と衝突しない領域で反例を探せる。

必要なのは R⇒P という新しい十分条件ではない。否定側の目標は P⇒R、同値に ¬R⇒¬P であり、それより限定した、¬R を満たす特定のモデルでの ¬P の構成でも独立性には足りる。Q と R の間で P の正確な強度を決めることは、今回の目標には不要である。

可測基数が存在しないという仮定は、ZFC が整合的なら ZFC と相対的に整合的である。V=L はその具体的な選択肢である。従って、もし ¬R⇒¬P を証明できれば、既知の Q⇒P と合わせ、Con(ZFC+Q) を仮定して P の ZFC 独立性が得られる。ここで「もし」の含意は未証明の部分であり、仮定を選んだことだけで独立性が得られたわけではない。[Kurz–Rosický, Remark 2.8(1)](https://alexhkurz.github.io/papers/cosig/cosig.pdf)、[Göbel–Shelah, §5 の V=L と可測基数への言及](https://shelah.logic.at/files/95925/190.pdf)

なお、V=L に限定すること自体を ¬R の形で書きたければ、R'=「V≠L」と置いてもよい。可測基数の存在は V≠L を含意するので、Q⇒R⇒R' となる。仮定の最弱性を先に要求しないという方針を明確にするための観察であり、R'⇒P を主張するものではない。

## 2 可測基数の非存在を選ぶ具体的な利点

### 2.1 可算集合が Set において codense になる

Kurz–Rosický, *Operations and Equations for Coalgebras*, Proposition 2.7 の証明および Remark 2.8(2) により、可測基数が存在しなければ、一つの可算無限集合 Ω とそのすべての自己写像からなる充満部分圏は Set において codense である。[一次資料 pp.7–8](https://alexhkurz.github.io/papers/cosig/cosig.pdf)

つまり、任意の集合 X は、X→Ω というすべての写像からなる標準図式の極限として回収できる。これは、真のクラスにわたる対象を固定した小さいデータで扱うための道具である。ただし、**反鎖型 C の所属が可算サイズの商だけで判定できることを、この結果だけから結論してはいけない。**

同論文 Proposition 2.7 は、Set の自己関手 F が cofiltered limits を保存する場合に、可測基数が有界であるという仮定の下で F-coalgebra を一つの操作記号で表示する結果も与える。ここには保存性という追加仮定がある。

### 2.2 解集合条件が破れる具体的な既知例がある

Casacuberta–Gutiérrez–Rosický, *Are all localizing subcategories of stable homotopy categories coreflective?*, Proposition 2.6 は、可測基数が存在しない場合、Ab に積と retract に閉じるが weakly reflective でない充満部分圏を構成する。[一次資料 p.15](https://www.ub.edu/topologia/casacuberta/articles/cgr.pdf)

その対象は、群 Z^κ/Z^{<κ}（κ は無限基数を動く）の積・retract 閉包である。固定した Z からの弱反射を仮定し、その候補の表示に現れる基数より大きい λ を選んで矛盾を得る。従って、任意の解集合候補を、より大きい対象で破るという実際の仕組みが利用可能である。

これは weak reflectivity の否定であり、今回の ordinary Hom による small coorthogonality class の coreflectivity の否定とは別の主張である。Ab の反対圏を取るだけでは、元の問題に必要な局所可呈示性は確保されない。接続するなら、方向と小さいテスト集合を保つ符号化が必要である。

## 3 反鎖型への最初の適用で分かった障害

[前段階の反鎖型](antichain_test_presentation_2026-11-15.md) C=Quot Coprod(G∪{1}) を用いる。G は非空のループなし quiver の rigid な真のクラスであり、各自己射は恒等射、異なる生成対象の間の射は存在しない。coreflector と包含との合成を r_C:Quiv→Quiv と書く。以下で問題にするのは、この自己関手の極限保存性である。

**補題。** r_C は cofiltered limits を保存しない。これは可測基数の有無によらず成り立つ。

**証明。** L_n を、一頂点と、各 m≥n に対応する一本のループを持つ quiver とする。辺集合の包含により逆列

\[
\cdots\longrightarrow L_2\longrightarrow L_1\longrightarrow L_0
\]

を作る。各 L_n は終対象 1 の余積の全射商なので C に属する。一方、Quiv における極限 D は、一頂点・辺なしの quiver である。頂点の逆列は恒等写像であり、辺集合の共通部分は空だからである。

各生成グラフは辺を持つ。実際、辺なしで頂点が二つ以上なら非恒等自己射があり、一頂点なら他の非空生成グラフへ射があるため、いずれも rigidity に反する。また 1 も辺を持つ。従って、いずれの非空生成対象からも D には写らず、r_C(D)=0。よって

\[
r_C(\lim_n L_n)=0,
\qquad
\lim_n r_C(L_n)=D\ne0.
\]

添字 ω^op は cofiltered なので、保存性が失敗する。∎

したがって §2.1 の coalgebra の表示定理を、反鎖型の coreflector に直接適用してテスト集合を得ることはできない。定理の基底が Set であるという違いに加え、基底を拡張して類似の方法を使うとしても、この保存性の障害がある。

**点検用の対照例。** この障害は、I_S 表示が存在しないことの証明ではない。各頂点に少なくとも一つループがある quiver のクラス C_loop を考える。V を頂点 g,b と辺 g→g, g→b, b→g の quiver、U⊂V を g とそのループだけの部分 quiver とする。このとき C_loop={}^⊥{U↪V} である。

実際、すべての頂点にループがあれば、V への射はすべての頂点を g に送るため U を経由する。ループを持たない頂点 x があれば、x を b、他の頂点を g に送る射が存在し、U を経由しない。fold によって C_loop は一つの射の I_S としても表示できる。それでも上の L_n と D は同じ極限保存性の失敗を与える。

以上の直接証明は `PROOF_RECONSTRUCTED`。主担当による点検であり、独立査読・形式検証は未実施。

## 4 継続する対象

反鎖型については、¬R の下で、前段階の C=C_κ となる基数 κ を探す。これは、C 外の各対象に一様に小さい C 外の商があることと同値であり、成功すれば固定したテスト集合を明示できる。[同値条件と標準的なテスト集合](antichain_test_presentation_2026-11-15.md)

可算 codensity を使って直ちに κ=ℵ₀ とする推論は採用しない。必要なのは、極限として対象を回収することから、C 外の小さい商を検出することへ移る追加の議論である。今回示した逆列は、その移行を coreflector の極限保存だけで済ませられないことを示している。

別の候補を使う場合も、§2.2 の解集合条件の失敗を参考にし、固定した ordinary-Hom テスト集合と固定標的を得られるかを判定する。既知の反例の圏論的な向きを反転しただけでは P の反例と扱わない。

今回の到達点は、扱いやすい否定側の仮定の採用、その下で使える二つの文献上の道具の確認、および反鎖型への直接の適用を妨げる極限保存性の反例である。小さい I_S 表示、¬P のモデル、独立性の証明は未確立である。
