# ZFC 肯定結果：終対象・subterminal 対象を終域に持つテスト

2026年11月16日。`INTERNAL_PROOF_CHECKED`。主担当と別担当が独立に構成を点検したが、形式検証・外部査読・新規性確認はしていない。一般の P の肯定証明ではなく、明示したテスト集合の範囲での ZFC 定理である。

## 1. 設定と既存の入力

K は任意の局所可呈示圏、Σ={f_i:U_i→V_i | i∈I} は射の集合とする。I という文字を添字集合に使い、一意性部分圏は太字風の記号 Q で書く：

    Q = {X∈K : K(X,f_i) はすべて単射},
    A = {X∈K : K(X,f_i) はすべて全単射}.

既存結果 `list_colouring_independence_2026-11-15.md`, §2.1 により、Q は K の monocoreflective な充満部分圏である。包含 J:Q→K と右随伴 R:K→Q を固定する。Q は完備であり、Q 内の極限は K の極限に R を適用して得られる。

D_i=R U_i、E_i=R V_i、g_i=R f_i と置く。任意の X∈Q に対して

    Q(X,g_i) ≅ K(JX,f_i)

は単射なので、g_i は Q 内の mono。したがって

    A = {X∈Q : Q(X,g_i) はすべて全射}.

subterminal 対象 D とは、任意の X に対し Hom(X,D) が高々一元である対象をいう。以下での subterminal 性は、指定しない限り Q 内のものである。

## 2. すべてのテストの終域が終対象の場合

**定理 1.** 各 V_i=1_K なら A は ZFC で coreflective である。D=∏_(i∈I)^Q R U_i とすると、B∈K の coreflection は

    J(D×_Q R B) → J R B → B

で与えられる。

**証明。** X∈Q の条件は K(X,U_i) がすべて高々一元であること。随伴により各 D_i=R U_i は Q の subterminal 対象であり、その積 D も subterminal である。X∈Q について、X∈A は各 Hom(X,D_i) が非空、すなわち Hom(X,D) が一元であることと同値。

C=D×_Q RB は D への射影を持つので A に属する。任意の A∈A について、射影と counit による写像は

    K(JA,JC) = Q(A,C)
             ≅ Q(A,D)×Q(A,RB)
             ≅ Q(A,RB)
             ≅ K(JA,B)

という自然な全単射である。したがって提示した射は coreflection。∎

**境界点検。** 空のテスト族なら Q=K、D=1_K なので C≅B。U_i が初対象でも証明は変わらない。例えば Set のテスト ∅→1 のクラスは {∅} で、公式も C=∅ を与える。Set の 2→1 では一意性部分圏 Q 自体が {∅} となり、再び C=∅。Ab では 1_K=0 であるため、定理は Hom(X,U_i)=0 という既存の null class の coreflectivity を含む。

## 3. Subterminal 終域：添字集合上の activation closure

**定理 2.** 各 E_i=R V_i が Q の subterminal 対象なら、A は ZFC で coreflective である。従って、特にすべての V_i が K の subterminal 対象であるテスト集合に対して肯定解がある。

**証明。** g_i:D_i→E_i が mono で E_i が subterminal なので、D_i も subterminal。T∈Q を固定する。添字の部分集合 H⊆I に対して

    D_H=∏_(i∈H)^Q D_i,
    C_H=T×_Q D_H,
    F(H)=H ∪ {i∈I : Q(C_H,E_i)≠∅}

と置く。空積は Q の終対象なので C_∅≅T。

H⊆H' なら積の射影から C_H'→C_H があるため、Q(C_H,E_i)≠∅ なら Q(C_H',E_i)≠∅。従って F は単調かつ拡大的。

H_0=∅、H_(α+1)=F(H_α)、極限順序数 δ では H_δ=⋃_(α<δ)H_α とする。θ=max(ℵ₀,|I|) とおけば、ある α<θ^+ で H_(α+1)=H_α が成立する。そうでなければ θ^+ 個の後続段のそれぞれで新しい添字を選べて、I に θ^+ 個の相異なる元があることになる。有限 I の場合、真の増大段は高々 |I| 回である。

固定点 H_* で C=C_H* とする。C→E_i が存在すれば i∈F(H_*)=H_* なので、積の射影 C→D_i が存在する。D_i→E_i と合成した射は、E_i が subterminal なので指定された C→E_i と等しい。さらに D_i も subterminal なので lift は一意。従って C∈A。

次に A∈A と a:A→T を取る。各段で a が C_Hα→T を一意に経由することを示す。これは、各 i∈H_α について A→D_i が存在することと同値である。一意性は D_i の subterminal 性による。

- α=0 は空積の普遍性。
- 後続段：i∈F(H_α)\H_α なら C_Hα→E_i が存在する。帰納仮定の A→C_Hα と合成して A→E_i を得る。A∈A より、これは A→D_i に一意に持ち上がる。
- 極限段：i∈H_δ ならすでにある H_α に入っているため、その段で得た A→D_i を使える。積の普遍性により A→C_Hδ を得る。

従って C→T は Q 内の A-coreflection である。T=RB として counit JRB→B と合成すれば K 内の A-coreflection を得る。∎

最後の「特に」は、V_i が K で subterminal なら Q(X,RV_i)≅K(JX,V_i) が高々一元であることから従う。

## 4. なぜこの構成はサイズの障害を避けられるか

対象の大きさや部分対象の鎖の長さを抑えたのではない。変化を記録する H は、固定した **集合** I の部分集合であり、固定点はその集合の大きさで抑えられる。

極限段では、過去に有効になった添字の和集合を取り、その D_i の積を取り直す。逆極限から固定テスト対象へのすべての射が有限段・早い段を経由するという仮定を使わない。極限で新たに C_H→E_i が現れても、次の activation でその添字を追加すればよい。

subterminal 性は二箇所で本質的である。(1) ある i に関して持ち上げる射の存在だけを記録すれば十分で、異なる射を別々に記録する必要がない。(2) 各 A→D_i は一意なので、任意の段・極限で両立性の追加問題がない。一般の V_i では、新しい段ごとに新しい C_H→RV_i が生じ得るため、この添字集合だけの停止論証は使えない。

## 5. Split epi のテスト

**命題 3.** すべての f_i が K の split epi なら A=Q、従って A は ZFC で monocoreflective。

**証明。** 各 K(X,f_i) は section を持つので常に全射。一意性条件と全単射条件が一致する。∎

定理 2 では、split epi のテストについて E_i の subterminal 性を仮定しなくてもよい。Q を全テストから定義した後、それらの f_i は全単射性の存在条件を自動的に満たすので、activation の添字集合から除けばよい。

## 到達点

終対象・subterminal 終域、および split epi のテストに対する一般の局所可呈示圏での肯定結果を得た。一般のテストについては、各テストへの射が複数あり得るため、「テスト i が有効になった」という集合個の情報だけで構成を止める議論は完成していない。
