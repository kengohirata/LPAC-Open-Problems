# ZFC 肯定方向：商による圧縮の正確な到達点

2026-11-16。母圏は小圏 C 上の presheaf 圏 K=Set^(C^op)。S={s_j:U_j→V_j} は射の集合、A={X:Hom(X,s_j) が全単射 (全 j)}。以下は直接証明した補題で、状態は `INTERNAL_PROOF_CHECKED`。外部査読・形式検証・新規性確認は行っていない。一般の P の肯定も否定も得ていない。

## 1. 商が A に残るための必要十分条件

X∈A を固定する。R は X 上の presheaf congruence（各 sort の同値関係で構造写像と整合するもの）、q_R:X↠X/R は成分ごとの商とする。

**補題。** X/R∈A であることと、全 j と u:X→U_j について

    R ⊆ ker(s_j u)  ⇒  R ⊆ ker u

が成り立つことは同値。

**証明。** 前件は s_j u が商 X/R に降りること。商が A に属すれば、その降りた射の唯一の lift を q_R と合成したものは u と等しいため、u も降りる。逆に v:X/R→V_j を取る。X∈A より vq_R の唯一の lift u がある。仮定で u が商に降り、v の lift を与える。一意性は q_R が epi であることと X∈A から従う。∎

## 2. 各入力に対する最大圧縮は ZFC で存在する

h:X→B、X∈A とする。R_0=ker h から開始し、congruence 上の演算

    T(R)=R ∩ ⋂{ker u : j∈J, u:X→U_j, R⊆ker(s_j u)}

を反復する。交わりの添字は集合であり、T(R) も congruence である。R⊆R' なら R' の条件を満たす u は R の条件も満たすので T(R)⊆T(R')。従って T は単調かつ T(R)⊆R。

後続段階 R_(α+1)=T(R_α)、極限段階 R_λ=⋂_(α<λ)R_α と置く。κ=max(ℵ₀, Σ_c |X(c)|²) とすると、κ^+ より前で R_α=R_(α+1) となる。そうでなければ各後続段階で新しい sort 付き対を一つ失い、κ^+ 個の段階を κ 個の対へ単射に送れることになる。極限の交わりは、すでに失われた対以外を新しく失わせない。

安定値 R_* は補題1により A-admissible であり、R_*⊆ker h のため

    X ↠ Q=X/R_* → B

という A を通る因子分解を得る。さらに R_* は ker h 以下の **最大の** A-admissible congruence である。実際、別の固定点 R⊆ker h は単調性と超限帰納法で全 R_α 以下になる。

したがってこの因子分解は、X の **A に属する商** を経由する h の因子分解の間で最大限の圧縮である。これは任意の A 対象を経由する因子分解全体での普遍性ではなく、B の coreflection を構成したわけではない。安定化の上界 κ^+ は X に依存する。

この最大商の存在自体は、A が小余極限に閉じることからも従う。X の A-商は congruence により集合個なので、h が降りるすべての A-商の wide pushout を取ればよい。上の演算の利点は、各段階で何が商への降下を妨げるかを明示する点にある。

## 3. 圧縮後の射について言えること

r:Q→B を上の射とする。

1. r は A から見て monic：任意の Z∈A と a,b:Z→Q について ra=rb なら a=b。
2. r は非同型な成分ごとの epi Q↠Q'（Q'∈A）を通らない。

2 は R_* の最大性そのもの。1 については a,b の presheaf coequalizer p:Q↠Q' を取る。A は小余極限に閉じるので Q'∈A、r は p を通る。2 により p は同型で、a=b。∎

これは **presheaf 圏の通常の mono** とは異なる。既存の有限例 U→V（[有限商失敗例](../audits/finite_quotient_witness.md)）では U∈A かつ f:U→V が coreflection である。f が A から monic であることは定義から従うが、f は presheaf 圏で非単射である。さらに、f が Q∈A を経由する epi U↠Q で商を持つなら、Hom(Q,f) の全単射性から射 Q→U があり、その U への合成は恒等射となる。epi U↠Q は同型である。この例の最大圧縮は U 自身であり、単なる像 V にはできない。

従って presheaf 圏が well-powered であることを、そのまま r の大きさの上界に使うことはできない。

## 4. 後続段階のサイズ制御と未解決の箇所

Q_α=X/R_α と書く。各 v:Q_α→V_j について vq_α の唯一の lift u_v:X→U_j を選択の余地なく得る。次段階の商は

    X → Q_α × ∏_j U_j^{Hom(Q_α,V_j)}

の presheaf image と同型である。第一座標は q_α、他の座標は u_v。この式は後続段階のサイズを Q_α と固定テストから評価する。

問題は **X に依存しない段階で安定すること**、または最終的な Q のサイズを B,S,C だけで抑えること。極限段階での Q_λ は X の商であり、inverse limit lim Q_α の中の X の像である。Q_λ→V_j がすべて前段階の Q_α を経由すると仮定する根拠はない。したがって後続段階の評価を繰り返しただけでは、全 X に共通するサイズ上界にはならない。

ここではこの具体的な再帰が無界長を必要とする例を構成していない。一般の inverse limit について Hom(-,V) の連続性が失敗するという観察だけから、本再帰の非収束や P の否定を結論してはいけない。

**十分条件。** すべての h:X→B（X∈A）について、上の Q のサイズを B,S,C に依存する一つの集合基数で抑えられれば、P が従う。実際、そのサイズ以下の Q∈A と Q→B の代表は集合個で、A↓B の weakly terminal set になる。A↓B は小余極限を持つため、随伴関手定理の solution-set 条件から終対象、従って coreflection を得る。

**必要条件とは主張しない。** Coreflection R(B)→B が存在しても、X→R(B) の presheaf image が A に属するとはまだ示していない。従って、この最大商 Q の一様なサイズ制御を P と同値だとは扱えない。

## 5. この方法の停止点

各入力 X ごとの最大圧縮、反復の収束、圧縮後の相対的 mono 性は証明できた。しかし、入力 X の大きさを除去する一様な制御は得られていない。この欠落は「同値な直交クラスの式を書く」だけでは埋まらない。今後この方法を続けるには、一意持上げが生む特別な congruence 反復に対する一様な評価、または商に限定しない別の solution-set 構成が必要になる。
