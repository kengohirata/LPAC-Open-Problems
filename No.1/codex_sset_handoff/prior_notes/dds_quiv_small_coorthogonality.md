# DDS と Quiv における small-coorthogonality

2026-11-15

## 結論と位置づけ

このノートでは次を直接証明する。

1. ZFC において、離散力学系 DDS = Set^(B N^op) の任意の small-coorthogonality class は coreflective である。実際、locally presentable である。
2. ZFC において、Quiv の有限な対象間の射の集合に対する coorthogonality class は coreflective である。

一般の Quiv における small-coorthogonality の反例や独立性を証明したものではない。引用文献の既存定理として上記二つを報告しているのではなく、以下が今回の導出である。

## 1. 設定

K は DDS または Quiv とする。S = {f_i: U_i → V_i | i ∈ I} は射の集合で、

A = {}^⊥S = {X | K(X,f_i) は全単射（すべての i について）}

とおく。これは、すべての h:X→V_i が f_i を通じて一意に持ち上がるという条件である。

A は小余極限で閉じる。実際、K(colim_j X_j,f_i) は全単射 K(X_j,f_i) の極限である。

対象の大きさは、DDS では台集合の濃度、Quiv では頂点集合と辺集合の濃度の和を意味する。

## 2. 共通の十分条件

W_i = U_i ×_{V_i} U_i、T = {V_i,W_i | i∈I} とおく。

ある無限基数 κ が次を満たすと仮定する。

任意の X と、その台集合の部分集合 Z（|Z|≤κ）について、Z を含む部分対象 Y⊆X が存在し、|Y|≤κ であり、任意の D∈T に対して制限写像

K(X,D) → K(Y,D)

が全射である。

このとき A は coreflective である。

### 2.1 小さい部分対象が A に残る

X∈A とし、上の Y を取る。

存在性：h:Y→V_i を X→V_i に延長し、X∈A によって X→U_i に持ち上げ、それを Y に制限する。

一意性：g_0,g_1:Y→U_i が f_i g_0=f_i g_1 を満たすなら、(g_0,g_1):Y→W_i を X→W_i に延長する。その二つの射影 X→U_i は f_i と合成すると等しいため、X∈A より等しい。制限して g_0=g_1 を得る。

したがって Y∈A。

### 2.2 大きさの有界性から coreflection を得る

X∈A の大きさ≤κの A-部分対象全体は κ^+-directed であり、合併は X である。実際、≤κ個のそのような部分対象の合併は大きさ≤κであり、2.1 によりそれを含む新しい小さい A-部分対象を取れる。

大きさ≤κの DDS または Quiv の対象は κ^+-presentable である。これは、それらが≤κ個の生成元と≤κ個の構造に関する等式で表示できることから従う。A の directed colimit は K で計算されるため、これらは A でも κ^+-presentable である。

よって A は accessible かつ cocomplete、すなわち locally presentable であり、余極限を保存する包含 A→K は右随伴を持つ。

随伴関手定理を使わずに終対象を得ることもできる。B を固定し、小さい A-対象 G の代表と全射ではない一般の射 G→B すべてからなる小さい comma diagram の colimit W→B を取る。任意の X∈A は小さい A-部分対象の合併なので、任意の X→B は W→B を経由する。したがって W→B は A↓B の弱終対象である。

A↓B は余完備かつ局所小である。一般に、そのような圏の弱終対象 W から終対象を作れる。W のすべての自己射を恒等射と同一視する余等化子 q:W→R を取る。R は依然として弱終対象である。u,v:X→R に対し、その余等化子 c:R→C と、弱終性による h:C→W を取る。qhcq=q なので q の epi 性から qhc=id_R。従って c は split mono かつ epi、よって同型であり、u=v。これで R が終対象になる。

## 3. DDS の逆向きランク

X=(X,t) とする。x∈X に対して、無限逆向き列

x=x_0, t(x_{n+1})=x_n

が存在するなら ρ_X(x)=∞ とする。存在しない場合、逆向きの関係は well-founded なので

ρ_X(x)=sup{ρ_X(y)+1 | t(y)=x}

と定義する。空集合の上限は0。すべての順序数を∞より小さいものとする。

射 h:X→D はランクを下げない：ρ_X(x)≤ρ_D(hx)。無限列は射の下でも無限列になり、順序数ランクについては well-founded induction で示せる。この degree と基本性質は Novotný に由来する monounary algebra の理論で用いられている。[1, §1]

### 3.1 相対的な延長補題

Y⊆X は t で閉じた部分集合、h:Y→D は射とする。すべての y∈Y について

ρ_X(y)≤ρ_D(hy)

であり、Y と交わらない X の各連結成分が D への射を持つと仮定する。このとき h は X→D に延長する。

連結性は、二点の前向き軌道が合流することを意味する。従って Y と交わる成分の各点は、有限回 t を適用すると Y に入る。

Y までの最小距離で帰納し、像を選ぶ。t(x) の像 d が決まっている場合、t_D(e)=d かつ ρ_D(e)≥ρ_X(x) となる e を選べばよい。

ρ_X(x) が順序数なら、それは ρ_X(t(x)) より小さい。従って ρ_D(d)>ρ_X(x) であり、ランクの定義から適当な e が存在する。ρ_X(x)=∞ なら d もランク∞であり、d にはランク∞の前駆点が存在する。異なる枝の像は同一視してよいので、これらの選択は衝突しない。

Y と交わらない成分には仮定された射を使えばよい。全体の選択は集合上の選択であり、ZFC の範囲内である。

### 3.2 小さいランク証人

ρ_X(x)≥α（αは順序数）なら、x を含む部分力学系 Z⊆X で

|Z|≤max(ℵ_0,|α|), ρ_Z(x)≥α

となるものが存在する。

α=0 では x の前向き軌道を取る。後続段階 α=β+1 ではランク≥βの前駆点を一つ取り、その証人を使う。極限段階ではより低いランクの証人を合併する。各証人は前向きに閉じており、後続段階でも x を含む。無限逆向き列がある場合にも同じ議論が適用できる。

### 3.3 固定した標的への非写像性にも小さい証人がある

D を固定する。D の点の順序数値ランクすべてより大きい順序数 δ を取り、κ≥ℵ_0,|D|,|δ| とする。

Hom(X,D)=∅ なら、|Z|≤κ の部分力学系 Z⊆X で Hom(Z,D)=∅ となるものが存在する。

まず D=∅ なら、Xの任意の非空な前向き軌道でよい。以下 D≠∅。

X の連結成分すべてが D に写るなら選択公理によって X 全体も写るため、D に写らない連結成分 C を一つ取れる。

C が長さ m の周期軌道を含む場合、その周期軌道だけが証人になる。実際、D に t_D^m(d)=d となる点があれば、周期軌道をそこに写し、3.1 により C 全体へ延長できる。周期軌道上のランクは双方とも∞である。

C が周期軌道を持たない場合、c_n=t^n(c_0) は相異なる点からなる。前向き軌道からの射は c_0 の像 d∈D によって決まる。3.1 により、それが C 全体に延長できるための必要十分条件は

ρ_C(c_n)≤ρ_D(t_D^n(d)) （すべての n）

である。

従って各 d∈D に対して、ある n_d でこの不等式が破れる。右辺 β_d は順序数であり β_d<δ。3.2 を使って c_{n_d} のランク≥β_d+1 を保証する大きさ≤κの部分力学系 Z_d を取る。

前向き軌道 {c_n} とすべての Z_d の合併 Z は大きさ≤κである。Z→D があれば c_0 の像はある d だが、c_{n_d} でランク単調性に反する。従って Hom(Z,D)=∅。

## 4. DDS の有界延長部分対象

T を DDS の対象の集合とする。T の全対象に現れる順序数値ランクすべてより大きい順序数 δ≥1 を取り、

κ≥ℵ_0, |T|, |δ|, sum_{D∈T}|D|

とする。

任意の X と |Z_0|≤κ の部分集合 Z_0⊆X に対し、以下のように Y⊆X を作る。

最初に、Z_0 の前向き閉包を取り、さらに Hom(X,D)=∅ となる各 D∈T について 3.3 の小さい非写像性証人を加える。これを Y_0 とする。

Y_n が得られたら、その各点 y に対してランク≥min(ρ_X(y),δ) の小さい証人を 3.2 で取り、すべて Y_n に加えて Y_{n+1} とする。min(∞,δ)=δ と解釈する。

Y=union_{n<ω}Y_n とおく。各段階も Y 全体も大きさ≤κであり、各 y∈Y について

ρ_Y(y)≥min(ρ_X(y),δ)

が成り立つ。

任意の h:Y→D（D∈T）を取る。ランク単調性から ρ_D(hy)≥min(ρ_X(y),δ)。D の順序数値ランクはすべてδ未満なので、ρ_X(y)≥δならρ_D(hy)=∞でなければならない。従って常に

ρ_X(y)≤ρ_D(hy)

が成り立つ。

また Hom(X,D)=∅ なら Y は既に D に写らない部分力学系を含むので、h は存在できない。従って h が存在する場合、X→D も少なくとも一つ存在する。これは、Y と交わらない X の各成分も D に写ることを保証する。

3.1 により h は X→D に延長する。これで第2節の有界延長部分対象の仮定が証明された。

T={V_i,U_i×_{V_i}U_i} に適用すると、ZFC において P_DDS が成立する。大きな基数公理、V=L、(M)、WVP はどこにも使用していない。

## 5. Quiv：有限なテスト対象は除外できる

S の各射の始域・終域が有限な quiver であると仮定する。このとき第2節の T の各対象も有限である。

任意の quiver X と可算な部分集合 Z に対して、それを含む可算な pure subquiver Y⊆X を取れる。具体的には、Y の元をパラメータとする有限個の等式からなる系のうち X で解けるものについて、解を一つずつ加える操作を可算回繰り返す。頂点・辺の二ソートと二つの構造写像しかないため、各段階で扱う系は可算個であり、辺の両端も加えれば部分 quiver が得られる。ここでの purity は有限連言・存在量化による等式の保存・反映である。[3, Definition 2.7]

D を有限 quiver、h:Y→D を射とする。X の各頂点・辺の像を有限集合 D_V,D_E の変数と考え、source・target を保存する等式と、Y 上で h に一致する条件を課す。

任意の有限個の条件は、Y の purity により満たせる。すなわち、関係する X の有限な図式を、有限個の指定された Y の点を固定して Y に写し、その後 h を適用する。

有限離散空間の積の compactness により、全条件を満たす像の選択が存在する。これが X→D への延長である。D のソートが空の場合も、h の存在と purity によって、対応する X のソートが非空という障害は排除される。

したがって第2節の基準が κ=ℵ_0 で適用でき、{}^⊥S は coreflective である。

結論：Quiv に small-coorthogonality による反例が存在するなら、有限な対象間の射だけでは定義できない。

## 6. 一般の Quiv について結論していないこと

無限な標的 D には有限集合の compactness をそのまま適用できない。また Quiv の辺は二つの端点を同時に制約するため、DDS の一つの前向き像を基準にしたランク延長証明は移せない。

この証明方法の限界は、P_Quiv の否定ではない。V=L や (M) の下で非 coreflective な small-coorthogonality class が存在することも、このノートでは示していない。

背景として、Cox–Feigert–Kamsma–Mazari-Armida–Rosický の Theorem 1.2 は、Set^C の pure monomorphisms が cofibrantly generated であることを、C が locally linearly preordered であることと同値とする。[3] 加法モノイド N はこの条件を満たす。一方、Quiv の表示圏 E⇉V は、source と target の二射が互いを通じて因数分解できないため満たさない。ただし、これは P とは別の性質である。
