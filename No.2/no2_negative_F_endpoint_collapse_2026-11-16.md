# Problem 2(b): 予想 F、順序数像の二点化、有限支持の観測不能対

2026-11-16。状態: `PROOF_RECONSTRUCTED`。今回の直接証明を主担当が再点検した段階であり、独立査読・形式検証・新規性確認はしていない。No.1 の主結果と必要な補題は、この研究で採用済みの入力として利用する。

## 0. 結論と未解決範囲

目的は Adámek–Rosický Open Problem 2(b) の否定方向を調べること。現在の候補について、次の予想 F を検討する。

> K_fs の full coreflective subcategory C が A を含むなら、B も含む。

B は A に属さないので、F が証明できれば A は二つどころか任意個の full coreflective subcategories の交わりとして表せない。

**今回、一般の F は証明も反証もしていない。** 得られた主結果は、F に反する C が存在するなら、その B-coreflection r:T→B の第1成分に、極めて具体的な有限支持の観測不能対が強制される、という必要条件である。

具体的には、非可算可測基数が存在しないという仮定 N の下で、T_0,T_1 はともに非空連結となり、標準の根 ρ_i:Ω→T_i はともに単射になる。さらに、ある {0,1}-支持の z∈T_0 が

    r_0(z)=0,
    q_T(z)=ρ_1(1),
    p_T(z)≠ρ_1(1),
    ℓ(p_T(z))=1  for every ℓ:T_1→Ω

を満たす。

従って、T_1→Ω の全ての同変写像による評価が T_1 の有限支持部分上で単射なら、必ず r は同型、従って B∈C となる。この分離条件の下では F を証明できた。

この必要条件は、単に H(p_T) が非全射であるという前段階の結果より強い。実際、r_0 は im H(p_T) の閉包からも離れており、その分離を一つの有限支持元 z が実現する。

## 1. 設定と採用済みの入力

Ω=ω、M=End_Set(Ω)、K_fs を次の充満部分圏とする。

    K_fs = {Z=(Z_0 ⇉ Z_1) in (M-Set)^(0⇉1) : Z_0 は有限支持}

構造射を p_Z,q_Z と書く。H(L)=Hom_M(L,Ω)。

    A = {Z∈K_fs : H(p_Z):H(Z_1)→H(Z_0) が全単射},
    B = (Ω ⇉ 1).

K_fs の local presentability と、A が一本の regular epi σ の coorthogonality class であることは、既存ノート `positive_route_and_regular_epi_obstruction_2026-11-16.md` §2 の入力とする。

No.1 の `investigations/parallel_actions_counterexample_2026-11-16.md` §§1,4–6 から、次を使う。

1. 有限支持 M-set L に対し H(L) は Ω^L の部分空間位相でコンパクト Hausdorff。
2. Stone 空間 X に対して C(X)=Cont(X,Ω_disc) と置くと、H(C(X))≅X は評価による同相。
3. N の下では F(X)=Ω^X に対し H(F(X))≅X は評価による集合の全単射。
4. 無限基数 κ に対して X_κ=[0,κ] とし、d_κ(α)=α+1 (α<κ)、d_κ(κ)=κ と置くと、

       Y_κ=(C(X_κ) --i,d_κ^*--> F(X_κ))

   は A に属する。任意の β≤κ に対して ψ_β:Y_κ→B を (ev_β,!) で定義できる。

以下で H(F(X_κ)) に X_κ の順序位相を与えているわけではない。順序位相を使うのは H(C(X_κ)) との同定の側である。

## 2. 実際に使う局所的な普遍性

主定理は C 全体を直接用いず、射 r:T→B の次の二条件から証明できる。

(R1) 全ての Z∈A に対し Hom(Z,r) は全単射。

(R2) Hom(T,r):End(T)→Hom(T,B)≅H(T_0) は全単射。

C⊇A が full coreflective なら、その B-coreflection は (R1),(R2) を満たす。

特に、任意の h∈H(T_0) に対し一意な e_h:T→T があり、

    r_0 (e_h)_0 = h

となる。また、r e=r を満たす自己射 e は恒等射に限られる。

**注意。** (R1),(R2) だけを満たす射を作れても、それを任意の標的に延長する coreflector が存在するとは限らない。今回、そのような非自明な射自体も構成していない。

## 3. 有限の試験対象から得られる連結性と根

### 3.1 M-set の成分

c_n∈M を値 n の定数写像とする。a∈L に対して

    ρ_a:Ω→L,  ρ_a(n)=c_n a

は同変であり、ρ_{ma}=ρ_a。

ρ_a=ρ_b なら c_0a=c_0b なので、作用の向きを忘れた連結成分は同じになる。逆に同じ成分なら ρ は変わらない。任意の同変写像 ρ:Ω→L は ρ=ρ_{ρ(0)} なので、Hom_M(Ω,L) は非空連結成分の集合と同一視できる。

また Hom_M(Ω,Ω) は {id_Ω} である。

### 3.2 二つの試験対象

    W=(∅ ⇉ Ω),
    D=(Ω --1,1--> Ω)

はいずれも A に属する。W では H(Ω) と H(∅) がともに一元集合、D では p_D=1 だからである。

(R1) を W に適用すると

    Hom_M(Ω,T_1) ≅ Hom(W,T) ≅ Hom(W,B) ≅ 1.

従って T_1 は非空連結。その唯一の Ω からの射を ρ_1 とする。

任意の ρ:Ω→T_0 に対して p_Tρ=q_Tρ=ρ_1 となるため、

    Hom(D,T) ≅ Hom_M(Ω,T_0).

再び (R1) によりこれは一元集合。従って T_0 も非空連結で、唯一の根を ρ_0 とする。r_0ρ_0=id_Ω なので ρ_0 は単射である。

ρ_1 は単射か定数写像のどちらかである。実際、異なる二点を同一視すれば、M の全ての自己写像との同変性により全ての二点を同一視する。

ρ_1 が定数なら、その値 t は M の固定点である。このとき

    s=(ρ_0, *↦t):B→T

は図式の射で r s=1_B を満たす。r(s r)=r なので (R2) の単射性から s r=1_T。従って r は同型。

**補題 1。** (R1),(R2) を満たす非同型 r:T→B では、T_0,T_1 はともに非空連結、ρ_0,ρ_1 はともに単射である。

なお r_0 は M-set として split epi、r_1:T_1→1 も全射。有限積と kernel pair は K_fs に残り、余極限は元の図式圏で計算されるため、r は K_fs の regular epi でもある。ただし、この regular epi 性だけで r の C 内での普遍性を代用してはいけない。

## 4. 主補題: 順序数像は両端点に潰れる

κ>|H(T_0)| を満たす非可算の無限基数を取り、初期順序数と同一視する。必要なら十分大きい successor cardinal を取ればよい。

(R1) により ψ_0:Y_κ→B の一意な因子化

    a=(a_0,a_1):Y_κ→T,
    r a=ψ_0

がある。

    X=H(T_0),
    h=H(a_0):X→H(C(X_κ))≅[0,κ],
    F=h(X)

と置く。X はコンパクト、h は連続、[0,κ] は Hausdorff なので F は閉集合。h(r_0)=0 であり、0∈F。また |F|≤|X|<κ。

### 4.1 順序数の左平行移動

β≤κ に対して

    f_β(α)=min(β+α,κ)

と置く。β<κ なら、α<κ に対して β+α<κ であり、f_β は順序位相で連続かつ d_κ と可換。κ における連続性は β+α≥α と共終性から従う。β=κ では定数写像なので同じ結論。

従って両成分で f_β に沿う前合成を取った

    m_β=(f_β^*,f_β^*):Y_κ→Y_κ

は図式の自己射で、ψ_0 m_β=ψ_β となる。

### 4.2 自己射の普遍性から像の加法閉性を得る

β∈F を取る。h(x)=β を満たす x∈H(T_0) がある。(R2) により r_0(e_x)_0=x となる e_x:T→T を取る。

r e_x a と r a m_β はともに ψ_β なので、(R1) の一意性より

    e_x a=a m_β.

第0成分を H で双対化すると

    h H((e_x)_0)=f_β h.

従って

    f_β(F)⊆F  for every β∈F.                 (4.1)

特に F∩κ は順序数加法について閉じている。

### 4.3 中間の正の順序数が一つでもあれば大きすぎる

0<β<κ が F に属すると仮定する。全ての ξ<κ に対して β·ξ∈F となることを超限帰納法で示す。

- ξ=0: 0∈F。
- 後続: β·(ξ+1)=β·ξ+β。帰納法と (4.1) による加法閉性を使う。
- 非零極限: β·λ=sup_{ξ<λ}β·ξ なので F の閉性を使う。

β·ξ<κ は基数の評価から従う。また ξ↦β·ξ は β>0 に対して厳密単調増加。従って |F|≥κ となり矛盾。

**補題 2（N）。**

    F⊆{0,κ}.                              (4.2)

これは単なる大きさの上界ではない。A-対象からの因子化の一意性と、T 自身に対する自己射の普遍性を組み合わせることで、中間の全順序数を像から除外した。

## 5. 二点化から有限支持の観測不能対を取り出す

    S=H(T_1),
    u=H(p_T):S→X,
    v=H(q_T):S→X,
    l=H(a_1):S→H(F(X_κ))≅[0,κ]

とする。図式 a の可換性から

    h u=l,
    h v=d_κ l.                             (5.1)

任意の s∈S について l(s) と d_κ(l(s)) はともに F に属する。(4.2) と d_κ(0)=1∉F により

    l(s)=κ  for every s∈S.                 (5.2)

S=∅ の場合も、この全称文として成立する。

### 5.1 原点だけで値を変える連続関数

同変写像 k:Ω²→C(X_κ) を

    k(x,y)(α) = x  (α=0),
                y  (α>0)

で定める。{0} は clopen なので、これは連続関数を与える。また

    d_κ^* k = c π_1

であり、c:Ω→F(X_κ) は定数関数の写像である。

    b_0=a_0 k:Ω²→T_0

と置く。すると

    r_0 b_0=π_0,
    q_T b_0=a_1 c π_1=ρ_1 π_1.             (5.3)

最後の等式は、Ω→T_1 が ρ_1 だけであることによる。

また (5.2) より、任意の ℓ∈H(T_1) について

    ℓ p_T b_0=π_1.                        (5.4)

従って p_T b_0 と ρ_1π_1 は、全ての Ω-値同変写像で区別できない。

### 5.2 これらが実際に等しければ r は同型

p_T b_0=ρ_1π_1 と仮定すると、(5.3) と合わせて p_T b_0=q_T b_0。

    D_2=(Ω² --1,1--> Ω²)

は A に属し、b=(b_0,p_T b_0):D_2→T は図式の射となる。一方、

    c_2=(ρ_0π_0,ρ_1π_0):D_2→T

も図式の射である。両者は r と合成すると (π_0,!) になるため、(R1) の一意性から b=c_2。従って

    ρ_1π_0=p_T b_0=ρ_1π_1.

よって ρ_1 は定数写像であり、§3 の retract 論法により r は同型となる。

従って r が非同型なら p_T b_0≠ρ_1π_1。

Ω² は (0,1) を生成元とする巡回 M-set なので、この不等式は (0,1) で既に成り立つ。そこで

    z=b_0(0,1)

と取れば、{0,1} は z の支持であり、

    r_0(z)=0,
    q_T(z)=ρ_1(1),
    p_T(z)≠ρ_1(1),
    ℓ(p_T(z))=1  (全ての ℓ∈H(T_1)).        (5.5)

**定理 3（N、局所的必要条件）。** (R1),(R2) を満たす非同型射 r:T→B には、補題1と (5.5) が成立する。

### 5.3 非延長性より強い位相的分離

z は {0,1}-支持なので、全ての h∈H(T_0) について h(z)∈{0,1}。

    U_z={h∈H(T_0):h(z)=0}

は clopen で r_0 を含む。他方、(5.3),(5.4) から im u と im v はともに U_z と交わらない。

従って

    r_0∉closure(im H(p_T)),
    r_0∉closure(im H(q_T)).                (5.6)

(5.6) は同型 r の場合にも、同じ構成から成立する。B では H(B_1)=∅ なので矛盾しない。

## 6. 予想 F が成立する範囲

評価写像

    η_1:T_1→Ω^{H(T_1)},
    η_1(t)(ℓ)=ℓ(t)

を考える。

**系 4（N）。** C⊇A が full coreflective、r:T→B がその coreflection とする。η_1 の有限支持部分 (T_1)_fs への制限が単射なら、r は同型、従って B∈C。

**証明。** 非同型なら、(5.5) の p_T(z) と ρ_1(1) は相異なる有限支持元で、η_1 により同一視される。矛盾。□

特に T_1 全体が Ω-値写像で分離される場合、または T_1 が Ω の冪に埋め込める場合には F の結論を得る。

注意すべき違い:

- 必要なのは、T_1 全体から Ω への写像による有限支持元の分離。
- (T_1)_fs 自身から Ω への写像が分離するだけでは足りない。その写像が T_1 に延長できるとは限らない。
- T_0 が C(H(T_0)) と同型である、あるいは全ての clopen を実現する、という追加仮定は最終証明では不要。順序数試験対象から必要な二値観測 b_0 を直接取り出したためである。

## 7. 分離条件は一般の M-set では自動ではない

    L=P_fin^+(Ω)

を Ω の非空有限部分集合の M-set とし、作用を直接像とする。これは非空連結で、根 ρ:Ω→L は n↦{n} という単射。全ての元が有限支持を持つ。

しかし H(L)=∅ である。仮に h:L→Ω が同変なら、{0,1} の支持から h({0,1})∈{0,1}。0 と1を交換する自己写像は {0,1} を固定するので、その値も交換で固定されなければならず矛盾する。

従って、連結性・単射な根・有限支持性だけから Ω 分離を導くことはできない。

これは **予想 F の反例ではない**。この L を第1成分にした (R1),(R2) を満たす T→B や、A を含み B を除く coreflective C を構成したわけではない。§6 の分離条件を無条件に落とせないことを示す例である。

## 8. 前の候補 P,Q との関係

既存ノートの

    P=(M_fin --j,tj--> M),  ε=(ev_0,!):P→B

は (R1) を満たすが (R2) を満たさない。(5.6) からもその失敗が見える。H(P_0)=Ult(ω)≅βω、im H(j) は主 ultrafilter の集合 ω で、これは稠密。従って ev_0 をその閉包から分離する U_z は存在できない。

稠密性は、非空の基本 clopen がある非空な A⊆ω に対応し、そこに A の点の主 ultrafilter が入ることから直接分かる。

重複座標の候補 Q は、B 上の非自明な自己同型により (R2) の単射性で既に失敗していた。

今回の定理はこれらを再否定するだけでなく、未知の候補全てに対して、どのような観測不能対が必要かを与えている。

## 9. 残った核心

F の証明に残るのは、(5.5) の特定の観測不能対が、実際の C-coreflector に現れることを排除すること。

一般の M-set で評価写像 η_1 が単射だと主張することは、§7 の例により不可能。したがって、排除するなら A⊆C と coreflection の普遍性をさらに使わなければならない。

逆に F を反証するには、(5.5) を備えた非自明な局所候補を作った上で、任意の標的について coreflection が存在する full subcategory C を構成する必要がある。観測不能対だけでは足りず、(R1),(R2) の検証、さらに大域的 coreflectivity が必要。

今回は次を主張しない。

- 予想 F の一般的な証明または反例。
- Problem 2(b) の肯定または否定。
- 観測不能対の存在から coreflective 拡大を構成できること。
- 評価表示への反射が任意の coreflective 部分圏を保存すること。
- 独立査読または形式検証を完了したこと。
