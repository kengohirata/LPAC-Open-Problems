## 1. 記号と目標

ρ を無限基数、|Ω|=ρ、M=End_Set(Ω)、H(X)=Hom_M(X,Ω) とする。作用は左作用、写像への作用は後合成。

λ>ρ を正則基数とし、

    F_λ={A⊆λ:|λ\A|<λ},
    L_λ=Ω^λ / ~,
    f~g ⇔ |{i:f(i)≠g(i)}|<λ

と置く。δ_λ:Ω→L_λ は定数関数による対角、q_λ:Ω^λ→L_λ は商射。

採用済みの ZFC 計算：H(L_λ) は λ 上の ρ^+-complete uniform ultrafilters と対応する。ρ^+-complete は ρ 個以下の交叉を保存すること。

目指しているが未証明の抽出条件は、固定 ρ のデータに対する coreflector R から μ(R,ρ) を得て、十分大きい正則 λ について

    H(L_λ)=∅ ⇒ ∃ 非空 Y⊆L_λ, |Y|≤μ, H(Y)=∅

を示すこと。先の小部分対象への座標評価の補題と合わせれば右辺は不可能となり、eventual uniformity が得られる。

注意：因子化 L_λ→小さい対象を得ても、小さい null 対象→L_λ を得たことにはならない。以下ではこの向きの差が実際に大きいことを示す。

## 2. 局所座標評価の相対版と purity

**補題1（ZFC）。** κ は正則で κ>max(|M|,ρ)、F は非空集合 I 上の proper κ-complete filter とする。L_F=Ω^I/~F。濃度 <κ の部分 M-set Y⊆L_F が対角 δ_F[Ω] を含むなら、δ_F の左逆となる同変写像 e:Y→Ω が存在する。

証明。各 y∈Y に代表 f_y:I→Ω を選ぶ。定数類 δ_F(a) の代表は実際の定数関数 c_a を選ぶ。これらは F が proper なので相異なる。

各 m∈M,y∈Y に対して

    E_(m,y)={i:f_(my)(i)=m(f_y(i))}∈F。

これらは |M|·|Y|<κ 個。κ-completeness と proper 性から、その共通部分に i_* を選べる。e(y)=f_y(i_*) は同変で、eδ_F(a)=a。□

**系2（ZFC）。** δ_F:Ω→L_F は κ-pure mono。

証明。|M|<κ のため κ-presentable な M-set は濃度 <κ のものとして取れる（<κ 個の生成元・関係式の表示とその retract）。κ-presentable な A,B による可換四角

    A → Ω
    ↓   ↓δ_F
    B → L_F

を考える。下辺の像と δ_F[Ω] の合併は濃度 <κ の部分 M-set Y である。補題1の e と B→Y を合成すると、上辺を A→B に沿って延長できる。purity が要求するのはこの三角の可換性であり、下辺の完全な分解ではない。□

従って H(L_F)=∅ の場合にも、対角は非常に pure だが Ω への retraction はない。この系は、任意の対象が十分強い purity に対して injective と仮定してはならないことを具体化する。

## 3. 本質的値域による固定サイズの商

S=P^+(Ω) を Ω の非空部分集合全体とし、M は直接像 m·A=m[A] で作用する。

λ>ρ が正則のとき、

    ess_λ([f])={a∈Ω:|f^{-1}(a)|=λ}

と置く。

**補題3（ZFC）。** ess_λ:L_λ↠S は同変な全射であり、定数類を singleton に送る。

証明。

- 非空性：λ を ρ<λ 個の λ 未満の集合で覆うことは正則性に反する。したがって f の fibre の少なくとも一つは濃度 λ。
- well-definedness：<λ 個の値の変更は、fibre の濃度が λ かどうかを変えない。
- 同変性：m(f) の b-fibre は、m(a)=b となる高々 ρ 個の f-fibre の合併。その合併の濃度が λ となることと、少なくとも一つの fibre が濃度 λ となることは同値。従って ess_λ(mf)=m[ess_λ(f)]。
- 全射性：非空 A⊆Ω に対し、λ を |A| 個の濃度 λ の部分集合に分割して f の値を指定する。
- ess_λ([c_a])={a}。□

S は小さい：|S|=2^ρ。しかも H(S)=∅。実際、仮に h:S→Ω が同変なら h({0,1}) は {0,1} に属する（この有限集合を固定する全変換による支持）。0と1の交換は {0,1} を固定するがそのどちらの値も固定しないので矛盾する。

特に、λ が |M|,2^ρ より大きい正則基数なら

    Hom_M(S,L_λ)=∅。

なぜなら、その射の像は非空・サイズ≤2^ρ の null 部分 M-set となるが、先の小部分対象評価の補題に反するからである。

よってこの場合、L_λ↠S は全射で、対角 Ω を singleton として区別したまま保つにもかかわらず、逆向きの射は一本もない。小さい null な商を得ることは、小さい null 証人を L_λ の中に得ることと全く異なる。

## 4. 固定界面をすべて記憶した対称商

固定した M-set D、同変写像 a:D→L_λ を取る。μ≥max(ρ,|D|,ℵ₀) とし、λ>ρ^μ を正則とする。D が空でもよい。

各 d∈D について a(d) の代表 f_d:λ→Ω を選ぶ。これらを同時に読むパターン写像

    t:λ→Ω^D,  t(i)(d)=f_d(i)

を作る。パターンの個数は高々 ρ^|D|≤ρ^μ<λ。

J={v∈Ω^D:|t^{-1}(v)|=λ} と置き、C_v=t^{-1}(v) (v∈J) と書く。残り E=λ\⋃_(v∈J)C_v は、<λ 個のサイズ <λ のセルの合併なので |E|<λ。特に J は非空。

各 C_v を任意に置換し、E を各点で固定する置換群

    Γ_a=∏_(v∈J) Sym(C_v)

を取る。添字の置換による前合成は L_λ の M-自己同型を与える。各 f_d は C_v 上一定であり E 上は置換しないので、Γ_a は a:D→L_λ を固定する。

写像

    Ψ_a:L_λ→S^J,
    Ψ_a([f])(v)={b∈Ω:|C_v∩f^{-1}(b)|=λ}

を定める。

**定理4（ZFC、固定界面つき軌道商）。**

(1) Ψ_a は同変な全射。
(2) Ψ_a の fibres は Γ_a の軌道と正確に一致する。従って Ψ_a は M-Set および D↓M-Set における全 Γ_a 作用と恒等射の coequalizer。
(3) |S^J|≤2^(ρ^μ)。この上界は λ に依存しない。
(4) Ψ_a a(d)(v)={v(d)}。さらに ker(Ψ_a a)=ker(a)。特に a が mono なら Ψ_a は界面 a[D] 上で単射。

証明。

(1) 補題3を各濃度 λ のセル C_v に適用する。同変性と非空性が得られる。全射性は、与えられた (A_v)∈S^J ごとに、C_v を |A_v| 個の濃度 λ の fibre に分割することで得る。

(2) 同じ Γ_a 軌道にあるものは各セルの fibre の濃度を保つので Ψ_a の値が等しい。

逆に Ψ_a([f])=Ψ_a([g]) とする。各セルでサイズ <λ の fibre の合併は <λ。セル数 |J|<λ、値数 ρ<λ なので、全セルにわたるその例外集合も <λ である。f,g を例外集合上だけ変更し、各セル C_v で共通の本質的値域 A_v の値だけを取り、その各 fibre が濃度 λ となる代表 f',g' を選べる。E 上も変更してよい（E 自体 <λ）。各セルと各 b∈A_v の二つの fibre 間に全単射を選び、まとめれば Γ_a の置換で [f] と [g] を移せる。

したがって fibres=軌道。作用は同変写像なので軌道同値関係は M-合同関係であり、その商が coequalizer。

(3) |J|≤ρ^μ と μ≥ρ より

    |S^J|=(2^ρ)^|J|≤2^(ρ·ρ^μ)=2^(ρ^μ)。

(4) f_d は C_v 上で値 v(d) を取るので singleton の式が成立。Ψ_a a(d)=Ψ_a a(e) なら全ての大きいセルで f_d=f_e であり、差は E⊆λ の <λ 個の点だけ。従って a(d)=a(e)。逆は自明。□

また S^J は null である。対角 S→S^J があり、S^J→Ω があれば S→Ω ができてしまう。λ>max(|M|,2^(ρ^μ)) なら Hom_M(S^J,L_λ)=∅ も同じ小部分対象の評価から従う。

**意味。** 一つの Ω の根だけでなく、任意の固定された集合サイズの界面を全て区別して残しても、一様に小さい null 商が残る。界面を忠実に保つという条件だけで商を禁止することはできない。

## 5. 対称性を保つ貼合せに対する解集合障害の排除

K を局所小な余完備圏、A⊆K を小余極限に閉じた full replete subcategory とする（coorthogonality class はこの条件を満たす）。D、M、ρ、μ は前節の固定データ。局所小性は最後に固定 B への射が集合個であることに使う。

G:(D↓M-Set)→K を Γ_a の軌道商に関する coequalizer を保存する固定関手とする。すべての小余極限を保存する関手なら十分。K 内での固定された余積・pushout による自然な貼合せは、該当するこの条件を確認してから適用する。

各大きい正則 λ について a_λ:D→L_λ を選び、Z_λ=G(a_λ)∈A とする。固定標的 B への射 b_λ:Z_λ→B が、誘導される Γ_(a_λ) 作用に不変、すなわち

    b_λ G(γ)=b_λ  (全 γ∈Γ_(a_λ))

であると仮定する。

**定理5。** この候補族 (Z_λ,b_λ) は、A↓B において集合個の A-対象を経由する。したがって、この候補族だけを用いて弱終集合の不存在を証明することはできない。

証明。定理4の coequalizer を G に適用すると、

    Z_λ→G(D→S^(J_λ))

は Γ 作用を潰す coequalizer。始域とすべての作用写像は A 内にあり、A は小余極限閉なので Q_λ=G(D→S^(J_λ))∈A。

b_λ の不変性から b_λ は Q_λ→B を経由する。S^(J_λ) のサイズは 2^(ρ^μ) 以下なので、M-作用と D からの射を含めた構造は同型を除いて集合個。その G による像と B への射も同型を除いて集合個。現れる合格対象とその B への射を集めれば、全候補 b_λ の集合サイズの因子化先が得られる。□

典型例：P_λ=A_0⊔_D L_λ、A_0 と D→A_0 が固定。この pushout は Γ 作用の coequalizer と交換し、P_λ/Γ≅A_0⊔_D S^(J_λ)。|P_λ/Γ|≤|A_0|+2^(ρ^μ)。ただし b_λ の不変性は別途必要。

**適用限界。**

- 任意の標的射 b_λ が自動的に不変とは主張しない。
- λ に依存する非対称な構造射を追加すると、Γ_a が図式の自己射でなくなることがある。この場合、本定理は適用しない。
- 界面 D_λ のサイズが λ とともに非有界なら、一つの μ による一様評価はない。
- coequalizer を保存しない構成へ自動移送しない。
- A 全体が coreflective であるという定理ではない。今回の候補族に限った、因子化サイズ障害の排除である。
- よって P1⇒ASC∞ の非含意も、全ての貼合せ戦略の不可能性も結論していない。

## 6. 元の平行二射の母圏での、もっと手前の障害

既存の A_ρ={Z:Z_0 は有限支持、H(p_Z) は全単射} と B_ρ=(Ω⇉1) に戻る。

Z∈A_ρ と b:Z→B_ρ があれば、b_0∈H(Z_0)。H(p_Z) の全単射性により H(Z_1) は非空。

従って H(L)=∅ である L から Z_1 への同変射は存在しない。存在すれば Z_1→Ω と合成して H(L) の元を得るからである。同じ理由で L→Z_0 も存在しない。

**系6。** null reduced power L_λ を直接受け取る pushout を Z_1 に入れる案は、この既存の A_ρ に属し、しかも B_ρ へ射を持つ候補にはならない。

これは、有限支持を課す母圏そのものの不可能性ではない。A_ρ の具体的な H(p) 条件と、この標的 B_ρ を同時に維持した直接挿入を排除する。

## 7. 一本の選択射による具体的符号化も試した

S=P^+(Ω)、E={(A,a):∅≠A⊆Ω, a∈A} と置き、M は直接像と選ばれた点に作用する。

    π:E↠S,  π(A,a)=A,
    c:E→Ω,  c(A,a)=a,
    j:Ω→S,  j(a)={a}

を取る。π は一本の固定 regular epi。

### 7.1 目的の Hom は ess の π に沿う lift と一致する

同変写像 h:L_λ→Ω は uniform な ρ^+-complete ultrafilter から来るため、h([f]) は ess_λ([f]) の元である。従って

    h↦(ess_λ,h):L_λ→E

は、H(L_λ) と π に沿う ess_λ の lifts の間の全単射を与える。

これは uniform ultrafilter 問題を一本の固定射の持上げ問題にする。ただし、全ての L_λ→S に沿う一意持上げを要求したこととは異なる。

### 7.2 reduced-power 商 q_F は π に一意左直交する

F を任意の proper filter とする。q_F:Ω^I↠L_F に対する π の lifting square

    Ω^I --u--> E
     |q_F       |π
     v          v
    L_F --v--> S

を取る。h=cu:Ω^I→Ω は採用済みの ultrafilter 表示により ρ^+-complete ultrafilter U に対応する。

A∈F について q_Fχ_A=q_Fc_1。v は定数類 c_1 を singleton {1} に送る。実際、定数1の作用がこの類を固定するため、その非空部分集合の像も {1} に一致しなければならない。

従って h(χ_A)∈πu(χ_A)=v(q_Fχ_A)={1}。よって A∈U。F⊆U が従うので h は h̄:L_F→Ω へ降りる。

各 x∈L_F の代表 f を取り、(v(x),h̄(x))=(πu(f),cu(f))∈E と確認できる。したがって d=(v,h̄):L_F→E が対角持上げであり、q_F が epi なので一意。つまり q_F ⊥_u π。

射の圏 Arr(M-Set) における一本のテスト

    ρ_π:(E --id--> E)→(E --π--> S),  成分(id_E,π)

の coorthogonality class A^π は、ちょうど π に一意左直交する射からなる。したがって q_F∈A^π。

### 7.3 しかし二つの自然な標的では障害にならない

標的 B_!=(Ω→1) を取ると、Hom_M(1,S)=Hom_M(1,E)=∅ なので B_! 自身が A^π に属する。全 q_F→B_! の受け皿は id_(B_!) であり、P1 の否定に使えない。

標的 B_j=(Ω --j--> S) は A^π に属さない。Ω→E, a↦({a},a) と id_S による square の lift は、S→Ω を与えるので存在しない。

しかし任意の q_F について

    Hom_Arr(q_F,B_j)≅H(L_F)

である。実際 j が mono、q_F が epi なので、可換 square j a=b q_F は a が L_F→Ω に降りることを強制し、b=jh となる。逆は h から構成できる。

従って H(L_F)=∅ のとき、q_F からこの不合格標的への射そのものがない。合格試験対象の構成と不合格標的の指定はできたが、反例に必要な両者を結ぶ射が失われる。

これは Arr(M-Set) の全テストや他の標的を排除するものではない。二つの具体的標的の正確な判定である。

## 8. 圧縮を破るために必要な変更

固定された小さい界面だけを増やすことでは、定理4の商は消えない。一方、全ての部分集合・分割の間の関係を可変の大きい incidence 対象として保持する方法は、定理5の仮定の外になる。

一つの診断：各大きいセル C_v を二つの濃度 λ の集合へ分け、A⊆λ を作ると、χ_A と χ_(λ\A) は Ψ_a の下で同じ ({0,1})_(v∈J) に送られる。M-作用だけでは、この自己補集合的な元は許される。

しかし P(λ)/[λ]^(<λ) の Boolean algebra 構造も保持し、標的の Boolean algebra が非自明であることを保つなら、x=¬x という同一視は不可能（これがあれば 0=1）。従って Boolean incidence を保つ構成では、今回の特定の圧縮を禁止できる。

ただし、これだけで P1 の反例は得られない。Boolean 2 への高完備 homomorphism を先に要求すれば、目的の ultrafilter 自体を入力に仮定することになり循環する。新しい合格対象と固定標的への射を、ultrafilter が存在しないときにも構成する必要がある。

有望な次の条件は、固定 signature のまま、λ に応じて増大する分割・incidence データと非対称な構造射を用い、標的射を先に選択写像にしてしまわずに、coreflector の普遍性からその選択を抽出することである。本稿でその実現補題を解決したわけではない。

## 10. 監査と現在地
