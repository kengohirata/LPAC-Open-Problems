# No.6　有向余極限で閉じる充満部分圏の解集合条件

Adámek–Rosický の No.6 は、正則基数 λ、局所 λ 可呈示圏 K、および K の λ 有向余極限で閉じる充満部分圏 A について、A が K で cone-reflective かを問う。**この主張は Vopěnka 原理（VP）と同値である。** 逆向きには、母圏を有向グラフの圏 Gra に、λ を ℵ₀ に固定した場合で足りる。原著 p.296 のコメントは VP による肯定と弱 Vopěnka 原理（WVP）の否定による反例を挙げている。以下の逆向きは、同書の系 6.7 直後の注意にある離散部分圏について、No.6 の閉性を確認して得られる。[原問題 p.296](https://doi.org/10.1017/CBO9780511600579.011)・[第6章 §6.A](https://doi.org/10.1017/CBO9780511600579.009)

## 問われている解集合

各 X ∈ K に対して、A の対象への射の集合族 (uᵢ ∶ X → Aᵢ) があり、任意の A ∈ A と任意の f ∶ X → A に対して、ある i と h ∶ Aᵢ → A が存在して f = h uᵢ となることをいう。つまりコンマ圏 (X ↓ A) が弱始集合を持つことが条件である。因子化が存在すればよく、i や h の一意性は要求されない。原著の定理 2.53 により、No.6 の閉性の下では、この条件は A がアクセス可能であることと同値になる。ここでアクセス可能性を与える正則基数は λ より大きくてもよい。[第2章 定義2.51・定理2.53](https://doi.org/10.1017/CBO9780511600579.005)

## VP との同値

**VP ⇒ No.6.** 系 6.7 によれば、VP の下でアクセス可能圏のすべての充満部分圏は cone-reflective である。局所 λ 可呈示圏 K はアクセス可能なので、この方向は A に余極限閉性を仮定する前から成り立つ。[第6章 系6.7](https://doi.org/10.1017/CBO9780511600579.009)

**¬VP の下での反例.** VP のグラフによる特徴づけから、恒等射しか持たない真クラス個のグラフの充満部分圏 D がある。局所有限可呈示圏 Gra の中で D を同型について閉じたものを A とする。[第6章 定義6.1・注意6.2(1)(a)・系6.7直後の注意](https://doi.org/10.1017/CBO9780511600579.009)

1. **A は有向余極限で閉じる。** 有向図式では任意の二つの段階から共通の後段への射がある。A では異なる同型類の間に射がないので、図式の値はすべて同じ同型類に属する。各代表の自己射は恒等射だけなので、その同型類の任意の二対象間にはちょうど一つの同型がある。従って図式は定値図式と自然同型であり、添字が非空かつ連結なので、Gra で取った余極限もその同型類に属する。
2. **空グラフ 0 に解集合がない。** 0 は Gra の始対象なので各 G ∈ D への射 0 → G がある。この射が 0 → Aᵢ を通じて因子化するには Aᵢ → G が必要であり、これは Aᵢ が G と同型の場合に限る。従って解集合は D のすべての同型類を代表する対象を含まねばならず、集合では足りない。

これで ¬VP ⇒ ¬No.6 が従う。特に Wilson の WVP と VP の分離を適用すると、WVP を仮定しても No.6 の反例が残りうる。[Wilson, *Weak Vopěnka’s Principle does not imply Vopěnka’s Principle*](https://doi.org/10.1016/j.aim.2020.106986)

## No.1〜5 との関係

- **No.5** では積で閉じているので、X に対する解集合があれば、その族を積にまとめて一本の弱反射 X → ∏ᵢ Aᵢ が得られる。さらに小極限で閉じていれば Freyd の随伴関手定理で反射が得られる。No.6 のグラフの例では、異なる同型類の二対象には A 内で共通の射源すらなく、その二対象の積に関する閉性は成立しない。No.5 の二問がともに WVP と同値であることと合わせると、No.5 が肯定されても No.6 が否定される場合がある。[No.5 の同値と出典](../No.5/README.md)
- **No.4** は小極限と有向合併で閉じる部分圏の反射性を問う。小極限閉性があるため、ここでも解集合が得られれば反射が従う。他方、合併の閉性が対象とするのは単射からなる有向図式で、No.6 の仮定は任意の遷移射を許す。上のグラフの例は積閉性を欠くので No.4 の反例には使えない。No.4 には WVP が十分である。[No.4 の問題と原典](../No.4/README.md)
- **No.3** と共通するのは、どの仮定からアクセス可能性が従うかという問いである。No.6 では母圏への充満埋め込みと λ 有向余極限閉性が与えられ、定理 2.53 を適用できる。No.3 の原文の出発点は余完備圏と λ 生成対象からなる強生成集合であり、この埋め込みはデータに含まれない。グラフの離散部分圏も異なる二対象の余積を持たず、No.3 の余完備性を満たさない。[No.3 の原文と前層圏への還元の検討](../No.3/README.md)
- **No.1・2** は K 内で書くと、集合個またはクラス個の射に対する左直交類について、余反射性または二つの余反射的部分圏の交わりとしての表示を問う。左直交類はすべての小余極限で閉じる。余反射で調べる射の向きは A → X で、No.6 が調べる向きは X → A である。また、上の離散部分圏は異なる二対象の余積で閉じないので、そのまま左直交類にはならない。[No.1・2 の定式化と WVP からの含意](../No.2/p1_p2_measurable_wvp_almost_compact_2026-11-17.md)
