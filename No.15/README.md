# No.15　有限アクセス可能圏の有限項スケッチによる表示

Adámek–Rosický の No.15 は、**すべての有限アクセス可能圏が有限項スケッチの集合値モデルの圏として表示できるか**を問う。後続論文により、この全称命題は ZFC 上で「非可算可測基数が存在しない」と同値である。原著 p.297 の用語は *finite sketch* で、後続論文は *finitary sketch* を用いる。指定する各極限・余極限の図式が有限であり、スケッチの対象、射、指定の個数には集合サイズの範囲で制限を置かない。表示は準同型を含めた圏同値を意味する。[原問題 p.297](https://doi.org/10.1017/CBO9780511600579.011)・[Adámek–Rosický (1995)](https://doi.org/10.1017/S0960129500000773)・[Adámek–Johnstone–Makowsky–Rosický (1997)](https://doi.org/10.2307/2275568)

## 可測基数が存在しない場合

有限アクセス可能圏は有向余極限を持ち、集合個の有限可呈示対象から有向余極限で生成される。有限可呈示対象の小さい充満代表部分圏を \(\mathcal A\) とすると、この圏は \(\operatorname{Ind}(\mathcal A)\)、すなわち \(\mathcal A\) 上の平坦前層の圏と同値である。平坦性は元の圏がフィルター圏であることを表す。例えば二つの元に共通の後段が存在するという条件では、共通の後段の対象とそこへの二本の射を、\(\mathcal A\) の候補すべてから選ぶ。この選択を論理式にすると、候補を添字とする集合サイズの選言が現れる。こうして有限極限と任意の小余極限を指定できる幾何スケッチによる表示が得られる。[Beke, *Theories of presheaf type*](https://faculty.uml.edu/tbeke/presheaf.pdf)・[1997年論文、系14の証明](https://citeseerx.ist.psu.edu/document?doi=74c4f00547e299ab5aca7fae3000135d7f6ce74b&repid=rep1&type=pdf)

1997年論文の定理12は、最初の非可算可測基数を \(\mu\) とすると、指定した余錐の図式がすべて濃度 \(\mu\) 未満である幾何スケッチを有限項スケッチに置き換える。証明ではまず自然数を有限極限・有限余極限で指定し、次に各 \(\beta<\mu\) について、\(\beta\) 個の定数がちょうど全要素を尽くす添字集合を補助ソートに実現する。そのソートへの写像と各点上のファイバーを使って、大きな余積を指定できる。非可算可測基数がなければ、任意の集合サイズの図式にこれを適用できる（系13・14）。また ZFC で、有限項スケッチによる表示は、有限連言・可算選言・有限個の変数の量化を許す \(\sigma\)-coherent 理論による表示と同値である。[1997年論文、定理12・系13–14とその直後の逆向き](https://citeseerx.ist.psu.edu/document?doi=74c4f00547e299ab5aca7fae3000135d7f6ce74b&repid=rep1&type=pdf)・[出版版](https://doi.org/10.2307/2275568)

## 可測基数が存在する場合の二段の半順序

1995年論文と1997年論文は可測基数からの反例を与える。以下は否定方向を確認するための別の導出である。添字集合 \(I\) に非主的な可算完備超フィルター \(U\) があるとする。例えば \(I\) を可測基数に取ればよい。[1995年論文](https://doi.org/10.1017/S0960129500000773)・[1997年論文](https://doi.org/10.2307/2275568)

小さい半順序 \(P\) に、下段の元 \(x_i\) と上段の元 \(y_i\) を各 \(i\in I\) に一つずつ置く。狭義の順序関係は
\[
x_i<y_j \quad\Longleftrightarrow\quad i\ne j
\]
だけとする。どの非空有向部分集合も最大元を持つ。上段の元を含めばそれが最大で、下段だけなら有向性により一点だからである。従って有向上限はすべて存在し、各対象は有限可呈示で、\(P\) は有限アクセス可能である。

仮に \(P\) が有限項スケッチのモデルの圏と同値だとする。上の論理的特徴づけにより、\(P\) と同値な \(\sigma\)-coherent 理論のモデル圏を選び、対応するモデルを \(X_i,Y_i\) と書く。可算完備な \(U\) には \(L_{\omega_1,\omega}\) の Łoś の定理が適用でき、\(X=\prod_U X_i\) と各超冪 \(Y_j^I/U\) はいずれもモデルである。多ソートで空ソートを許す場合、超積の各ソートの元は \(U\) に属する部分集合上の切断の同値類で定義できる。

各 \(j\) を固定すると、\(I\setminus\{j\}\in U\) 上では \(X_i\to Y_j\) がある。その超積から \(X\to Y_j^I/U\) を得る。また対角射 \(Y_j\to Y_j^I/U\) があり、\(y_j\) は \(P\) で極大だから、この対角射は同型である。よって \(X\to Y_j\) がすべての \(j\) で存在する。ところが \(P\) にすべての \(y_j\) の共通下界はない。各 \(x_i\) は同じ添字の \(y_i\) の下になく、各 \(y_i\) は他の上段の元と比較不能である。これで矛盾する。超積は仮定したモデル表示で取り、最後の矛盾は半順序自身の射だけで判定している。

## これまでの問題との関係

- **No.1・2** の Isbell の計算では、\(M=\operatorname{End}(\omega)\) としたとき、\(M\)-同変写像 \(\omega^I\to\omega\) が選ぶファイバーから \(I\) 上の可算完備超フィルターを得る。すべてが主的なら、写像は一つの座標での評価になる。No.15 の二段の半順序では、主超フィルターが選ぶ \(x_i\) は \(y_i\) の下に入らない。非主的になると、各 \(j\) に対する例外 \(\{j\}\) が個別に無視され、モデル圏での超積が全 \(y_j\) の下に入る。同じ集合論的条件がどこで効くかを両方の例で直接追える。[No.1 の計算、§1.1](../No.1/codex_sset_handoff/investigations/parallel_actions_counterexample_2026-11-16.md)・[No.2 での適用、§2.2](../No.2/sigma_coreflectivity_under_no_measurables_2026-11-16.md)
- **No.7** では、成分を指定した非交和上の超フィルターを添字集合に射影し、非主的になる最小の添字濃度を調べた。No.15 の二段の例にも同じ下限がある。最初の可測基数 \(\mu\) より小さい集合上の可算完備超フィルターは主的であり、\(\mu\) に達すると上の反例が動く。肯定方向の定理12でも、この同じ \(\mu\) が余錐を有限項化できる境界として現れる。[No.7 の最初の可測基数での計算](../No.7/first_measurable_index_size.md)
- **No.13** は、完備な圏に論理式の大きさを適宜選んだモデル表示を与え、そこから局所可呈示性を問う。No.15 は有限アクセス可能性を出発点に、表示に使う論理を \(\sigma\)-coherent まで制限できるかを問う。両方の条件を満たす領域、すなわち完備かつ有限アクセス可能な圏は局所有限可呈示であり、ZFC で有限極限スケッチによる表示を持つ。二段の例では異なる二つの極大元の積が存在しない。[No.13 の定式化と完備性](../No.13/README.md)・[原著第1章](https://doi.org/10.1017/CBO9780511600579.004)
- **No.14** の共通始域の構成では、複数のソートを一つの集合にまとめ、各元がいずれかのソートに属するという被覆公理に任意の集合サイズの選言を使った。No.15 の有限項化は、この形の選言の添字を補助ソートで表す方法を与える。適用には元の理論が幾何的であることが必要であり、No.14 で使う一般の basic theory は無限連言や無限長の量化も許す。[No.14 の被覆公理、§1](../No.14/common_sources_and_extendibility.md)

**用語上の別解釈。** もし「有限」を、台のグラフも指定の総数も含めてスケッチ全体が有限データで書けるという意味に強めると、問いは ZFC で否定される。有限データのスケッチは記号の改名を除いて高々可算個しかないが、各基数 \(\lambda\) 上の離散圏は有限アクセス可能であり、異なる基数は同値でない圏を与える。この数え上げと、各図式の有限性を扱う上記の可測基数による判定は区別される。
