# No.12　アクセス可能圏の pure 射は正則モノ射か

Adámek–Rosický の No.12 は、正則基数 \(\lambda\) と \(\lambda\)-アクセス可能圏 \(\mathcal K\) に対し、すべての \(\lambda\)-pure 射が \(\mathcal K\) 内の正則モノ射になるかを問う。**一般の場合は ZFC で否定される。** Adámek–Hu–Tholen は1996年に、小さい有限アクセス可能圏と、その中の \(\aleph_0\)-pure かつエピである非同型射を構成した。[原著 *Open Problems*, p.297](https://doi.org/10.1017/CBO9780511600579.011)・[Adámek–Hu–Tholen, pp.6–8](https://doi.org/10.1016/0022-4049%2895%2900037-2)

## 問題の二つの条件

\(m:X\to Y\) が \(\lambda\)-pure であるとは、\(\lambda\)-可呈示対象間の任意の射 \(g:P\to Q\) と、\(mu=vg\) を満たす \(u:P\to X,\ v:Q\to Y\) に対し、\(u=tg\) となる \(t:Q\to X\) が存在することをいう。指定された \(v\) は下側の三角形に現れるが、\(t\) に課す等式は上側の \(tg=u\) だけである。原著の命題 2.29 により、この条件から \(m\) のモノ性はすべての \(\lambda\)-アクセス可能圏で従う。[原著第2章、§2.D](https://doi.org/10.1017/CBO9780511600579.005)

正則モノ性には、ある対象 \(Z\) と平行射 \(r,s:Y\rightrightarrows Z\) があり、\(m\) がその等化子になることが要る。反例では二つの可算列 \((A_n)\), \((B_n)\) の余極限の間の射 \(f_\omega:A_\omega\to B_\omega\) が上の有限可呈示テストをすべて満たす。同時に \(f_\omega\) はエピで、同型ではない。もし \(f_\omega\) が \(r,s\) の等化子なら、\(rf_\omega=sf_\omega\) とエピ性から \(r=s\) になる。その等化子は \(1_{B_\omega}\) と同型なので、矛盾する。これが論文の反例から直ちに否定が出る理由である。[Adámek–Hu–Tholen, Fig. 2 と Example](https://doi.org/10.1016/0022-4049%2895%2900037-2)

## 同じランクで肯定が成立する場合

- \(\mathcal K\) が局所 \(\lambda\)-可呈示なら肯定。原著が問題に添えた命題 2.31 である。[原著第2章](https://doi.org/10.1017/CBO9780511600579.005)
- \(\mathcal K\) が \(\lambda\)-アクセス可能で押し出しを持てば肯定。射の圏で pure 射を分裂モノ射の \(\lambda\)-有向余極限として表し、正則モノ射がこの余極限で閉じることを使う。[Adámek–Hu–Tholen, Propositions 1–2, Corollary 1](https://doi.org/10.1016/0022-4049%2895%2900037-2)
- \(\mathcal K\) が \(\lambda\)-アクセス可能で任意の小積を持つ場合も肯定。アクセス可能な加法圏でも肯定が成立する。従って No.5・9 で扱った \(\mathbf{Ab}\) の部分圏に適用する際は、その部分圏自身のアクセス可能性と、使う積や加法構造を確かめる必要がある。[Hu–Pelletier](https://doi.org/10.1016/S0022-4049%2896%2900095-3)・[加法圏の場合、Example 12.3](https://arxiv.org/pdf/2506.13374)・[No.5・9](../No.5/README.md)

## No.11 のエピ商との関係

No.11 では始域 \(A\) を固定し、エピ射 \(e:A\to B\) を \(A\xrightarrow{u}C\xrightarrow{m}B\) と分解する。ここで \(C\) の可呈示ランクは \(A\) から一様に抑えられ、\(m\) は \(\lambda\)-pure である。\(e\) が強エピなら \(m\) のモノ性だけで \(m\) は同型になる。通常のエピなら \(m\) のエピ性までは従う。No.12 の反例は、この最後の \(m\) に残る二条件を同時に満たす非同型射を実現する。一方、反例の圏は小さいので各始域のエピ商は集合個である。No.11(b) の反例には、一つの始域から真クラス個の相異なる商が必要になる。[No.11 の因子化と還元](../No.11/README.md)

**ランクを上げる変種には、No.11(b) の下界が移る。** Kanalas の定理 24 は、強コンパクト基数が任意に大きく存在すれば、各 \(\lambda\)-アクセス可能圏について、より大きいアクセス可能性ランク \(\mu\) を選び、すべての \(\mu\)-pure 射を strict mono にできるという定理である。アクセス可能圏での strict mono は、集合個の平行射対の同時等化子である。No.12 は元の \(\lambda\) と一対の平行射を指定している。[Kanalas, Remarks 20–21, Theorem 24, Question 26](https://arxiv.org/pdf/2407.13448)

今回の照合から次の含意が得られる。ある \(\mu\)-アクセス可能圏で全 \(\mu\)-pure 射が strict mono になるとする。エピでもある strict mono は同型である。実際、同時に等化する各対がエピ性ですでに等しい。従って No.11 の因子化をランク \(\mu\) で使うと \(B\cong C\) となり、固定始域 \(A\) のエピ商は集合個に限られる。よって「各アクセス可能圏でそのようなランクを選べる」という全称命題は No.11(b) を含意し、原著の例 A.19 により**可測基数が任意に大きく存在すること**を含意する。これは既知の因子化と下界を組み合わせた帰結であり、この変種の正確な集合論的強さはここでは決定していない。[No.11 の証明](../No.11/README.md)・[Bagaria–Casacuberta–Mathias–Rosický、系 7.6 直後](https://www.ub.edu/topologia/casacuberta/articles/bcmr.pdf)

## No.1 と No.3 で使った purity

- **No.1** では前層圏内の \(\lambda\)-pure 部分対象に沿って、固定した標的への射を延長した。この延長性は標的の pure-injectivity という追加仮定である。前層圏は局所可呈示で、そこでの pure モノ射の正則性と、標的への延長の可否は両立して別々に判定できる。[No.1 の pure 部分対象による十分条件、§§1–2](../No.1/codex_sset_handoff/investigations/positive_purity_2026-11-16.md)
- **No.3** では前層圏で pure 包含を固定始域の分裂モノ射の有向余極限として表し、反射後にもモノ性が保たれる条件を調べた。分裂モノ射による表示は No.12 の押し出しを使う証明と共通する。No.3 で別途必要なのは、反射によって圏を移った後のモノ性である。反射的前層表示を仮定する範囲については No.3 の冒頭の注意が適用される。[No.3 の分裂モノ射による表示](../No.3/rp_equivalence_split_colimits_and_compactness_gap_2026-11-17.md)・[No.3 の仮定](../No.3/README.md)
