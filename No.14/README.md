# No.14　すべての大きいアクセス可能圏への忠実関手を持つ始域

Adámek–Rosický の No.14 は、一つの大きいアクセス可能圏 \(\mathcal T\) を選び、任意の大きいアクセス可能圏 \(\mathcal K\) に対して忠実なアクセス可能関手 \(F_{\mathcal K}\colon\mathcal T\to\mathcal K\) を与えられるか、という問題として扱う。大きいとは本質的に小さくないことをいう。忠実性は各 Hom 集合上での単射性であり、対象上の単射性も充満性も要求しない。関手が保存する \(\lambda\)-有向余極限の正則基数 \(\lambda\) は、終域と関手に応じて選べる。[原著 *Open Problems*, p.297](https://doi.org/10.1017/CBO9780511600579.011)

**2026年11月19日の進展。** 集合個の大きいアクセス可能圏を指定した場合、ZFC で一つの大きい共通の始域を構成できる。さらに、extendible cardinal が一つあれば、すべての大きいアクセス可能圏に通用する一つの始域が存在するという証明案を得た。各終域を basic theory として表示し、初等埋め込みを小さい可呈示対象の圏に適用した後、忠実性を保って延長する。順序数を使う既出の Ind 完備化についても、全非可算正則ランクで整列集合の圏と相互に忠実なアクセス可能関手を持つことが分かる。これらは今回の導出で、一般の ZFC での結論と独立検証は未確定である。[構成と証明](common_sources_and_extendibility.md)

**否定側の検討。** 可測基数が有界な場合の例 A.19 と、さらに \(V=L\) で強到達不能基数がない場合を調べた。後者では候補の始域のアクセス可能ランク \(\mu\) に応じて終域を構成できる。仮に忠実関手があれば、共終数 \(\mu\) の任意に大きい特異強極限基数 \(\nu\) で、\(\nu\) を固定し \(\nu^+\) より下の順序数を動かす比較埋め込みが必要になる。この条件は単独の埋め込みとして実現でき、否定モデルはまだ得ていない。[構成可能宇宙での否定側の検討](independence_negative_side_L.md)・[可測基数が有界な場合の検討](absence_of_large_cardinals.md)

**Supercompact 一つに弱める試み。** 強コンパクトな \(\kappa\) 一つで、各公理が \(L_{\kappa,\kappa}\) に属し各記号の項数が \(\kappa\) 未満の basic theory で表示できるすべての大きい終域には、同じ始域から忠実なアクセス可能関手が入るという証明案を得た。公理数・署名の大きさは任意でよい。一般の終域については、supercompactness 埋め込みの列閉性の範囲に、内部で計算したモデル濃度の閾値が収まることが十分である。この条件を通常の supercompactness から導く部分は未解決である。[小さい図式のコンパクト性と一般の場合の十分条件](supercompact_and_bounded_logic.md)

**構成可能宇宙の終域に向かう図式。** 固定した有限段数までの有限順序と全順序埋め込みについて、平行射、合成、特異基数での比較埋め込みを同時に実現する忠実関手を構成した。一方、全有限段数で両立し、標準包含の鎖が一つの対象に写り込む図式は、この終域では実現できない。有限段数の構成は本質的に小さい始域での試験であり、一般の No.14 は未決である。[有限図式の構成と可算鎖の障害](coherent_diagrams_in_K_mu.md)

**直極限で初めて現れる枝。** \(V=L\) で強到達不能基数がない宇宙において、\(\mathcal K_{\omega_1}\) の小さい対象からなる \(\omega_1\)-鎖を構成した。各段階の木には枝がなく、一階構造の直極限に外部の共終枝が現れる。この鎖は \(\mathcal K_{\omega_1}\) に余錐を持たず、小さい対象の包含を \(\operatorname{Ind}_{\omega_1}\) 全体に延長する関手は存在しない。証明は任意の非可算正則 \(\mu\) に共通で、\(\mathcal K_\mu\) の最小アクセス可能ランクも \(\mu^+\) と決まる。No.14 で許される他の関手は引き続き候補である。[印付き閉包の木と Kurepa の対角化](branch_at_direct_limit.md)

**包含を変えた肯定側の検討。** 元の鎖から有限個の試験対象を選び、そこから共終な尾部と頂点 \(X\) に入る射をすべて保った部分圏では、忠実関手と余錐を同時に構成できる。尾部の全遷移射を非エピな包含に写すこともできる。充満部分圏 \(\mathcal C\cup\{X\}\) 全体については、小対象上の一つの忠実関手が鎖の像に余錐を許せば十分かつ必要である。その存在は未決である。[試験対象による構成と充満部分圏での判定](reinterpreting_the_branch_diagram.md)

**鎖の全段階での平行射。** 枝の鎖を選び直すと、各段階 \(P_i\) から二段先以降の各 \(P_j\) に少なくとも \(\omega_1\) 本の異なる射を残し、それらの合成と頂点への脚を一つの忠実関手で保てる。元の鎖は余錐を持たず、写した鎖は余錐を持つ。一般の枝でも、段階を有限区間に分け、以前の区間上で標準脚と一致する脚をすべて保てる。区間をまたぐ射は、それに前合成すると採用した後続脚がすべて一致するものに限る。この制限を外した充満部分圏での構成は未決である。[全段階での構成と枝の選び方](all_stages_and_parallel_arrows.md)

**後段の選択を最初の段階まで区別する。** 枝を選び直すと、どの \(i<j<\omega_1\) についても、\(P_i\) で選ぶ射 \(a_i^\eta\) と \(P_j\) で選ぶ射 \(b_j^\xi\) を標準遷移でつなぎ、二つの選択 \((\eta,\xi)\) をすべて区別したまま \(X\) に送れる。これらの射が生成する部分圏には、元の無余錐の鎖を有余錐の鎖に写す一つの忠実関手がある。どれだけ離れた後段の選択も検出できるが、一度 \(b\) を使った像の上では、それ以降の選択が消える。[二つの印による構成と合成の計算](nonconstant_composition_along_the_branch.md)

**任意の有限回の選択と Ind 完備化（11月20日）。** 一つの枝と一つの忠実関手を固定し、どの有限個の段階でどの非標準射を使ったかを、常に同じ \(P_0\) から区別できる。段階間の射はちょうど有限語で、合成は連結になる。この段階部分圏の \(\omega_1\)-Ind 完備化で加わる同型類は標準鎖の頂点一つだけであり、本質的に小さい。どの \(\omega_1\)-フィルター図式でも、固定した対象の先で語の長さが最大になるところを選ぶと、その先はすべて標準射になるためである。[有限語を実現する埋め込みと完備化の計算](finite_words_and_ind_completion.md)

**\(V=L\) での否定の証明案（11月20日）。** \(V=L\) では、任意の大きいアクセス可能圏 \(\mathcal T\) に対し、そのランクに応じた \(\mu\) で \(\mathcal T\to\mathcal K_\mu\) となる忠実なアクセス可能関手が存在しないという証明案を得た。\(\mathcal T\) には共終数 \(\mu\) の特異基数 \(\rho\) の濃度の対象 \(X\) があり、\(\mu\)-列で閉じた \(F(X)\) は濃度 \(\rho\) を取れない。忠実性から \(|F(X)|\ge\rho^+\) となるが、そのとき \(F(X)=L_{\beta^*}\) は \(L_{\rho^+}\) を元に持ち、\(X\) の標準図式から自分自身を元として再構成してしまう。これが正しければ ZFC \(+\neg P\) は ZFC と相対無矛盾で、extendible の証明案と合わせて No.14 は ZFC から独立になる。独立検証は未了。[証明案と確認すべき点](negation_in_L.md)

**否定が成り立つ宇宙の範囲（11月20日）。** 同じ議論は \(V=L[A]\)（\(A\) は任意の集合）でも通り、\(L[0^\#]\) や可測基数一つの \(L[U]\) でも No.14 は偽になる。\(L\) に全正則基数で Cohen 部分集合を加える Easton 積の拡大でも偽で、この形のクラス強制では肯定のモデルを作れない。鍵は「\(F(X)\) と同じ高さで \(X\) の標準図式を含む推移的 \(\mathrm{ZFC}^-\) モデルがあれば矛盾する」という ZFC の補題である。一方、No.14 からシャープや巨大基数を導く議論は得られておらず、無矛盾性の強さとしての下界は ZFC のままである。別セッションの査読で定理に欠陥は見つかっていないが、人による検証は未了。[定理と方法の限界](negation_beyond_L.md)

**\(V=L\) での還元（11月20日）。** \(V=L\) では、\(\mu\)-列で閉じ、最大基数の共終数が \(\mu^+\) の \(L_\beta\) と初等埋め込みからなる大きいアクセス可能圏 \(\mathcal C_\mu\) が、コードが \(H_{\mu^+}\) に入るすべての大きいアクセス可能圏に忠実なアクセス可能関手を持つ。関手は \(<_L\)-最小のモデルを取る。従って \(V=L\) での No.14 の肯定は「ある \(\mu\) があり、すべての \(\mu'>\mu\) で \(\mathcal C_\mu\to\mathcal C_{\mu'}\) が存在する」と同値になり、任意の始域に関する量化が消える。各 \(\mathcal C_\mu\to\mathcal C_{\mu'}\) の成否は未決である。独立検証は未実施。[還元の証明と射の形](reduction_to_L_beta_categories.md)

## 有限アクセス可能な場合と、その限界

Makkai–Paré §3.4.1 と Rosický の定理 3.1 により、任意の大きい有限アクセス可能圏には、線形順序と順序埋め込みの圏 \(\mathbf{Lin}\) から、有向余極限を保存する忠実関手が入る。証明では、有限増加列の生成する構造が列の長さだけで決まるような識別不能列を用いて、まず有限線形順序とその埋め込みの像を定める。任意の線形順序は有限部分集合に誘導された全順序の有向合併なので、そこから関手を延長できる。[Rosický, 定理 3.1](https://tac.mta.ca/tac/volumes/36/10/36-10.pdf)

整列集合と順序埋め込みの圏 \(\mathbf W\) は大きい \(\aleph_1\)-アクセス可能圏である。可算部分整列集合が \(\aleph_1\)-有向な表示を与え、\(\aleph_1\)-有向余極限で仮に無限降下列が生じれば、その可算個の元を一段階に集められる。ところが、整数の順序の平行移動 \(n\mapsto n+1\) は非自明な自己同型であり、整列集合の自己同型はすべて恒等射である。従って \(\mathbf{Lin}\to\mathbf W\) には忠実関手が存在しない。さらに、任意の大きい有限アクセス可能な \(\mathcal T\) に対して \(\mathbf{Lin}\to\mathcal T\) があるので、合成を考えると**有限アクセス可能な始域はすべて No.14 の候補から外れる**。[Rosický, 定理 3.1・例 4.1](https://tac.mta.ca/tac/volumes/36/10/36-10.pdf)

同論文の例 4.2 は、全対象の自己射が恒等射だけである大きい \(\aleph_1\)-アクセス可能圏 \(\mathcal L\) を与える。従って共通の始域 \(\mathcal T\) の自己射もすべて恒等射でなければならない。また \(\mathbf W\) の射はすべてモノ射なので、\(\mathcal T\to\mathbf W\) の忠実性から \(\mathcal T\) のすべての射もモノ射である。一方、末尾の注の薄さの議論から、\(\mathcal T\) はどこかに異なる平行射を持つ必要がある。整列集合の圏 \(\mathbf W\) 自身は、\(\omega\) のシフトという非恒等自己射があるため候補から外れる。[Rosický, 例 4.1–4.2](https://tac.mta.ca/tac/volumes/36/10/36-10.pdf)

## 固定したランクにおける候補の読み方

Rosický の Problem 4.4 は、\(\aleph_1\) を固定し、すべての大きい \(\aleph_1\)-アクセス可能圏に向かう忠実な \(\aleph_1\)-有向余極限保存関手を問う。高いランクについても同様の問いを挙げている。ランクごとに始域を取り替えられる定式化なので、各ランクについて解があるとしても、No.14 に使うには一つの始域からそれらに忠実なアクセス可能関手を与えるなどの追加の議論が要る。[Rosický, 注意 4.3・問題 4.4, p.286](https://tac.mta.ca/tac/volumes/36/10/36-10.pdf)

**注意 4.3 の二つの記述には照合が必要である。** 論文は \(\mathcal L_1\) を例 4.2 の剛直な圏の充満部分圏として導入し、同時に \(\operatorname{Ind}_{\aleph_1}(C_1)\) と表示する。出版版 p.286 の \(C_1\) の明示的記述を使うと、後者には次の非恒等自己射が生じる。これは今回の直接計算である。

- \(C_1\) の対象は可算順序数で、\(\alpha<\beta\) のときすべての順序埋め込み \(\alpha\to\beta\) を許す。標準包含でつないだ \(\alpha<\omega_1\) 全体は \(\aleph_1\)-有向図式である。その米田像の余極限を \(X\) とする。
- 各段階で \(s_\alpha\colon\alpha\to\alpha+1,\ \xi\mapsto\xi+1\) を取る。これらは標準包含と可換なので \(s\colon X\to X\) を誘導する。
- \(X(1)=\operatorname{colim}_{\alpha<\omega_1}C_1(1,\alpha)\) で判定する。段階 \(2\) の \(0\) を選ぶ射は、\(s\) により段階 \(3\) の \(1\) を選ぶ射へ移る。標準包含はこの二点を区別し続けるので \(s\ne 1_X\) である。

従って、印刷された \(C_1\) から自由に作った Ind 完備化は、例 4.2 の圏へ忠実に写らず、記載された剛直な充満部分圏と同値にもなれない。この計算は、充満部分圏による構成自体の最小性や、別の始域の存在を判定しない。今回調べた文献では、一般の No.14 の公刊された解決を確認していない。
