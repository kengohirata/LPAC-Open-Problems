# No.14　\(\mathcal K_\mu\) に向かう平行射と合成

2026年11月19日。前稿と同じく \(V=L\) で強到達不能基数がないとし、非可算正則基数 \(\mu\) を一つ固定する。終域 \(\mathcal K_\mu\) の対象は、外部の \(\mu\)-列に閉じた前稿の推移的モデルであり、射は \(\mu+1\) を点ごとに固定する初等埋め込みである。以下は今回の導出で、独立検証は未実施である。[終域と比較埋め込みの定義](independence_negative_side_L.md)

## 有限段数ではすべての順序埋め込みと比較写像を一度に作れる

\(N\ge2\) を任意の自然数とし、\(\mathcal D_N\) を \(0,1,\ldots,N\) を有限順序と見て、それらの間のすべての狭義順序埋め込みを射とする圏とする。また \(\nu>2^\mu\) を共終数 \(\mu\) の特異強極限基数、\(D=L_\nu\) とする。包含順序を入れた冪集合を \(\mathcal P(D)\) と書く。次を満たす忠実なアクセス可能関手を構成できる。

\[
 F:\mathcal D_N\times\mathcal P(D)\longrightarrow\mathcal K_\mu .
\]

- 各 \((k,A)\), \(|A|<\mu\) で像の濃度は一様に \(2^\mu\) 以下である。
- 各 \((k,D)\) で、小さい段階の像の合併の崩壊から \(F(k,D)\) への比較埋め込みは、前稿と同じ \(\nu<\operatorname{crit}(m_k)<\nu^+\) を満たす。
- すべての \(u:k\to l\) がこの比較埋め込みの自然性の四角形を与える。異なる平行射は合成後にも区別される。

### 閉包と有限個のパラメータ

十分大きい後続基数 \(\vartheta\) に対し \(H=H_{\vartheta^+}=L_{\vartheta^+}\) を取る。\(S\subset H\) に対し、\(S\)、\(\nu\)、および \(\xi\le\mu\) のすべてを含む最小の閉包を \(Q(S)\) とする。閉包操作は \(L\) の標準整列による一階 Skolem 関数と、外部の \(\mu\)-列をその集合コードに送る操作である。後者は \(H\) に値を持つ。これらの操作を \(\mu^+\) 段反復すれば閉包になり、\(|S|\le\mu\) なら \(|Q(S)|\le 2^\mu\)、\(|S|\le\nu\) なら \(|Q(S)|\le 2^\nu\) である。各閉包は \(H\) の初等部分構造で、その推移的崩壊は \(\mathcal K_\mu\) の対象である。実際、列を崩壊に沿って点ごとに戻し、その列コードを取ってから再び崩壊すればよい。添字はすべて固定される。

有限増加組 \(s\) を \(H\) の順序数から選び、\(Q(D\cup s)\) を、\(D\) の全元、\(\nu\)、および \(s\) の各位置の元を指定した構造と見る。ここで組を集合と合併するときはその値域を使う。この印付き構造の同型型を \(s\) の色とする。固定した長さで色数は高々 \(2^{2^\nu}\) で、\(\vartheta\) に依存しない。有限個の長さ \(1,\ldots,N\) について有限指数の Erdős–Rado 定理を順に適用できるよう、初めに \(\vartheta\) を十分大きく取る。すると \(D\) より高い順序数の \(N\) 元集合 \(I\) を選び、同じ長さの \(I\) の部分組は常に同じ色にできる。例えば最大の長さから順に集合を細め、次の長さに必要な濃度を各段で残せばよい。[Erdős–Rado, *A partition calculus in set theory*](https://www.renyi.hu/~p_erdos/1956-02.pdf)

同じ長さの組の間の印を保つ同型は一意である。両側を崩壊すれば推移的な整礎外延構造であり、同型は崩壊を介するものに限られる。この同型は各 Skolem 関数を保ち、添字を固定するので外部の \(\mu\)-列のコードを保つ。従って、各 \(A\subseteq D\) と部分組 \(r\subseteq s\) について、\(Q(A\cup r)\) を対応する部分閉包にちょうど写す。逆の包含は逆同型に同じ議論を適用して得る。

### 関手とそのランク

各 \(k\) の代表 \(s_k\) を \(I\) の最初の \(k\) 個とする。\(F(k,A)\) は \(Q(A\cup s_k)\) の崩壊とする。\(u:k\to l,\ A\subseteq B\) には、まず \(s_k\) を \(s_l\) の \(u\) が選ぶ部分組に写す上の同型を制限し、次に \(Q(B\cup s_l)\) に包含して、両端を崩壊した射を対応させる。部分組への制限と印付き同型の一意性から、合成の二通りの計算が一致する。\(u\ne v\) なら、値の異なる位置の印が別々の順序数に送られるので忠実である。例えば \(N\ge3\) では \(1\rightrightarrows2\) の二射は \(2\to3\) で後ろから合成しても区別され、一方、同じ位置を選ぶ二通りの \(1\to2\to3\) は同じ射になる。

始域は本質的に小さい \(\mu\)-アクセス可能圏で、その \(\mu\)-可呈示対象はちょうど \(|A|<\mu\) の \((k,A)\) である。冪集合の有向余極限は合併であり、有限順序成分は有向図式の共終な部分で一定になる。実際、図式で実現した最大の有限長を一度取れば、その後の射のその成分は恒等射である。\(F\) は \(\mu^+\)-有向余極限を保存する。有限順序成分を固定した後は、\(\mu^+\)-有向合併で \(\mu\) 個の引数が同一段階に入るので、閉包の合併が合併の閉包になる。終域のこのランクの余極限は初等部分構造の合併の崩壊で計算される。

頂点 \((k,D)\) での小さい段階の合併は、崩壊前には
\[
 U_k=\bigcup_{A\in[D]^{<\mu}} Q(A\cup s_k)\ \prec\ Q(D\cup s_k)
\]
である。これは全可呈示段階の像の合併でもある。他の有限順序成分からの各射は同じ \(k\) の小さい段階を経由する。\(D\subseteq U_k\)、\(\nu^{<\mu}=\nu\)、各段階の濃度は \(\le 2^\mu\) なので \(|U_k|=\nu\) である。一方 \(Q(D\cup s_k)\) は \(\mu\)-列に閉じ、König の定理で濃度は \(\nu\) を超える。両側は前稿の一階公理を満たし、左側の崩壊は \(L_\nu\) を含み \(\nu\) も元として持つ。前稿の臨界点の議論が適用され、包含を両側で崩壊した \(m_k\) は \(\nu\) を固定し、\(\nu^+\) 未満の順序数を動かす。構成した各射は \(U_k\) を \(U_l\) に写すので、この比較はすべての \(u\) について自然である。

## 全有限段数を両立させる際の障害

\(\mathcal D_{\mathrm{fin}}\) を全有限順序とすべての順序埋め込みの圏とする。忠実関手 \(G:\mathcal D_{\mathrm{fin}}\to\mathcal K_\mu\) があり、さらに**標準包含だけの鎖** \(G(1)\to G(2)\to\cdots\) が一つの \(B\in\mathcal K_\mu\) に余錐を持つことは不可能である。この主張に余錐の普遍性や \(G\) の余極限保存は要らない。

**自己埋め込みについての補題。** 前稿の一階公理を満たす推移的集合 \(P\) では、初等自己埋め込みは恒等射だけである。ここで \(P\) の外部列閉性は仮定しない。\(P\models V=L\) により、すべての元は順序数パラメータから定義できる。非自明な自己埋め込み \(e\) があれば最初に動く順序数 \(\gamma\) が存在する。\(P\) 内に \(\eta<\gamma\) から \(\gamma\) への共終写像があれば、それを \(e\) で移しても各添字と各値は同じで、\(e(\gamma)>\gamma\) に共終にはなれない。ゆえに \(\gamma\) は内部で正則な非可算基数である。さらに後続基数なら前者の基数から定義され、**同じ** \(P\) への自己埋め込みで固定される。従って内部で正則な非可算極限基数である。

この \(P\) ではそのような基数は強極限でもある。冪集合公理を外している点に注意して確認する。内部の無限基数 \(\eta<\gamma\) では \(\eta^+<\gamma\) が存在する。任意の内部の \(x\subseteq\eta\) は内部の \(L_{\eta^+}\) に属する。十分高い集合レベル \(L_\xi\) を取り、\(\eta\) の全元と \(x,\eta\) を含むサイズ \(\eta\) の初等 Skolem 閉包を作り、凝縮を適用すればよい。崩壊は \(x\) を固定する。この構成は集合上の操作で、Collection を含む \(\mathrm{ZFC}^-\) の内部で行える。従って分出で内部の冪集合が得られ、\(|L_{\eta^+}|=\eta^+\) からその大きさは \(\eta^+<\gamma\) 以下である。これで \(\gamma\) は内部で強到達不能となり、公理に反する。[構成可能階層と凝縮](https://www.math.uni-bonn.de/~raesch/jensen/jensen/pdf/book_sec_1_1.pdf)

**余錐から自己埋め込みを作る。** \(1\rightrightarrows2\) の二射の像が異なるので、値が異なる \(x\in G(1)\) を選ぶ。有限順序の各位置を選ぶ射で \(x\) を送り、余錐を通じて \(B\) に移すと \(x_0,x_1,\ldots\) が得られる。標準包含との可換性により段階の選択に依存しない。任意の二位置は \(2\) からの順序埋め込みで選べ、余錐の脚も単射なので、これらの元は相異なる。

任意の \(k\) 個の増加する位置に現れる組は、\(G(k)\) での同じ標準の組の初等像である。従ってこの列は \(B\) の一階言語で順序識別不能である。\(B\) 内に、列の**各元**から定義可能 Skolem 関数で生成される初等部分構造を取る。各元を \(x_i\mapsto x_{i+1}\) と移して Skolem 項に適用すると、その部分構造の初等自己埋め込みになる。有限個の位置についての型が一致するので、項の等式にも一階式の真偽にも依存関係の破れは起きない。この写像は \(x_0\) を動かす。部分構造の推移的崩壊は \(B\) と同じ一階公理を満たすため、補題と矛盾する。

## 大きい始域の候補で何が残るか

例えば \(\theta=2^\mu\) とし、\(\mathcal K_\mu\) の濃度 \(\le\theta\) の対象の小さい充満代表部分圏 \(\mathcal C\) を固定できる。\(\mathcal A=\operatorname{Ind}_\mu(\mathcal C)\) は、実際に大きい \(\mu\)-アクセス可能圏である。各 \(B\in\mathcal K_\mu\) は、濃度 \(\le\theta\) の列閉な初等部分構造の \(\theta^+\)-有向合併になる（\(\theta^\mu=\theta\)）。その図式を \(\mathcal A\) に入れ、そこで余極限を取れる。さらに \(\mathcal C\) の包含を通常の一階構造と初等埋め込みの圏へ \(\mu\)-フィルター余極限で延長した \(E\) の下で、この対象の像は \(B\) と同型である。こうして像の濃度が非有界になり、\(\mathcal A\) は本質的に小さくない。

\(\mathcal C\) 上ではすべての射と合成がすでに与えられている。ところがこの \(E\) の値は一般には \(\mu\)-列に閉じない。実際、上の小さい \(Q(A\cup s_k)\) の崩壊はすべて \(\mathcal C\) に代表を持ち、その図式の \(\mathcal A\) 内の余極限に \(E\) を施すと、濃度 \(\nu\) の \(U_k\) の崩壊になる。有限段数の試験では \(F(k,D)\) を選ぶとこの欠落を自然に補えた。

一方、可算鎖の障害だけでは、この具体的な大きい \(\mathcal A\) を排除できない。\(E\) は小さい段階の射がすべて単射であることから忠実である。さらに各 \(E(X)\) は整礎である。降下する可算列があれば、元と関係の証人を \(\mu\)-フィルター性で一段階に集められてしまう。その崩壊は前稿の一階公理を満たすので、余錐からの自己埋め込みを禁じる上の証明は \(E(X)\) にも適用される。従って \(\mathcal A\) 自身が、全有限順序の忠実な図式と標準包含鎖の余錐を同時に含まない。\(\mathcal A\) 全体で各 \(E(X)\) を列閉なモデルに自然に埋められるか、あるいは別の忠実なアクセス可能関手 \(\mathcal A\to\mathcal K_\mu\) が存在するかは、ここでは決まっていない。

**追記。** 続稿で、\(\mathcal A\) の一対象 \(X\) について \(E(X)\) がどの列閉な対象にも所定の初等埋め込みを持たないことを示した。その図式自体が余錐を持たないため、小さい対象の包含をそのまま延長する方針も排除される。[直極限で初めて現れる枝](branch_at_direct_limit.md)
