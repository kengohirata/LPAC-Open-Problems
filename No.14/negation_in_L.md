# No.14　\(V=L\) では否定される（証明案）

2026年11月20日。\(P\) は No.14 の肯定、すなわち「すべての大きいアクセス可能圏に忠実なアクセス可能関手を持つ一つの大きいアクセス可能圏が存在する」を表す。以下はこのノートでの導出で、独立検証は未実施である。

**定理（\(V=L\)）。** 任意の大きいアクセス可能圏 \(\mathcal T\) に対し、ある正則基数 \(\mu\) があって、忠実なアクセス可能関手 \(\mathcal T\to\mathcal K_\mu\) は存在しない。従って \(V=L\) では \(P\) は偽である。

ここで \(\mathcal K_\mu\) は [構成可能宇宙での否定側の検討](independence_negative_side_L.md) の終域から「強到達不能基数がない」を除いたものである。

- **対象**は推移的集合 \(M\) で、\(\mathrm{ZFC}^-\)（Collection を含む）、\(V=L\)、「最大の基数が存在し、それは後続基数である」を満たし、\(\mu\in M\) で、長さ \(\mu\) の列で閉じるもの。対象は \(L_\beta\) の形である。
- **射**は各 \(\xi\le\mu\) を固定する初等埋め込み。

\(\mathcal K_\mu\) は大きいアクセス可能圏である。後続基数 \(\vartheta>\mu\) について \(H_{\vartheta^+}=L_{\vartheta^+}\) が対象になる。\(\lambda>\mu\) が正則なら、\(\lambda\)-フィルター余極限は初等埋め込みの直極限の推移的崩壊である。整礎性と \(\mu\)-列での閉性は、可算個・\(\mu\) 個の元が一段階に集まることから従う。可呈示対象による表示は、Skolem 関数と \(\mu\)-列で閉じた初等部分構造の崩壊で得られる。この定理には強到達不能基数の非存在は使わない。

**系。** ZFC が無矛盾なら ZFC \(+\neg P\) も無矛盾である。[extendible による肯定の証明案](common_sources_and_extendibility.md) が正しければ、extendible cardinal の無矛盾性の下で \(P\) は ZFC から独立である。

## 証明

以下 \(V=L\) とし、GCH と \(H_\tau=L_\tau\)（\(\tau\) は無限基数）を使う。

### 0. 準備

\(\mathcal T\) を basic theory \(c\) のモデル圏 \(\operatorname{Mod}(c)\) と同値に表示する（原著定理 5.35）。正則非可算基数 \(\mu\) を、\(c\) の記号の項数と式の大きさを上回るように取る。\(\mu\)-有向余極限は \(\operatorname{Mod}(c)\) でソートごとに計算できる。モデルの台は順序数の集合とする。この \(\mu\) について主張を示す。

忠実な関手 \(F\colon\operatorname{Mod}(c)\to\mathcal K_\mu\) が \(\lambda\)-有向余極限を保存すると仮定する。\(\lambda\) を大きく取り直して、\(\lambda\) は正則、\(\lambda>\mu\)、\(\operatorname{Mod}(c)\) は \(\lambda\)-アクセス可能としてよい。

- \(\mathcal A\) を \(\lambda\)-可呈示対象の代表からなる小さい充満部分圏とし、\(G=F|_{\mathcal A}\) と置く。\(N_a=G(a)\) と書く。
- 基数 \(g\) を、\(c\) とその署名、\(\mathcal A\)、\(G\)（対象 \(N_a\) と射 \(G(w)\) をすべて含む集合）の推移閉包の濃度、および \(\lambda\) より大きく取る。

### 1. 対象 \(X\) の選択

\(\rho\) を、\(\operatorname{cf}(\rho)=\mu\) かつ \(\rho>2^{g}\) である極限基数とする。GCH により \(\rho\) は強極限である。

**濃度がちょうど \(\rho\) のモデル \(X\) が存在する。** \(\rho\) に共終な後続基数の増加列 \((\rho_i)_{i<\mu}\)、\(\rho_i>g\) を取る。GCH から \(\rho_i^{<\mu}=\rho_i\)。濃度 \(\ge\rho\) の \(c\)-モデル \(Y\)（\(\mathcal T\) が大きいので存在する）の中に、増加鎖 \(Z_0\subseteq Z_1\subseteq\cdots\)（\(i<\mu\)、\(|Z_i|=\rho_i\)）を取る。各 \(Z_i\) は \(Y\) から誘導した構造を持つ部分構造で、関数記号と、公理に現れる存在部分式の証人の選択で閉じているとする。このとき \(Z_i\) は \(c\)-モデルである。前件の正の存在式は \(Y\) に持ち上がり、後件は選んだ証人で \(Z_i\) に戻るからである。長さ \(<\mu\) の組は一段階に入るので、合併 \(X=\bigcup_i Z_i\) も同じ閉性を持ち \(c\)-モデルになる。\(|X|=\rho\) である。台を \(\rho\) に移しておく。

### 2. \(F(X)\) は自分の表示を元として持てない

\(X\) は標準図式 \((\mathcal A\downarrow X)\to\operatorname{Mod}(c)\) の \(\lambda\)-フィルター余極限である。\(F\) はこれを保存するので、\(F(X)\) は図式
\[
D_X\colon(\mathcal A\downarrow X)\to\mathcal K_\mu,\qquad (a,u)\mapsto N_a,\quad w\mapsto G(w)
\]
の余極限、すなわち \(D_X\) の直極限の推移的崩壊である。推移的集合の間の全単射な初等埋め込みは恒等写像なので、\(F(X)\) は集合としてこの崩壊に等しい。

**主張 A。** \(D_X\notin F(X)\)。

\(D_X\in F(X)\) と仮定する。\(F(X)\) は \(\mathrm{ZFC}^-\) の推移的モデルなので、その内部で非交和 \(\bigsqcup_{(a,u)}N_a\) を同値関係で割った直極限 \((Q,E)\) を作れる。添字圏はフィルター圏で半順序とは限らないが、\(G(w)\) はすべて単射なので、同値関係は「ある共通の後段への二本の射で同じ元に移る」でよい。同値類は集合の部分集合なので冪集合公理は要らない。この構成は \(D_X\) から \(\Delta_0\) の操作と置換で得られ、外部で作ったものと一致する。\((Q,E)\) は整礎で外延的であり、\(\mathrm{ZFC}^-\) の推移的モデルは集合上の関係の整礎性を正しく判定し、Mostowski 崩壊を実行できる。得られる推移的集合は外部での崩壊 \(F(X)\) と同じである。従って \(F(X)\in F(X)\) となり矛盾する。

### 3. \(F(X)\) の濃度は \(\rho\) 以下

**主張 B。** \(|F(X)|\le\rho\)。

\(F(X)=L_{\beta^*}\) と書く。\(\kappa=|F(X)|>\rho\) と仮定する。\(|\beta^*|=\kappa\) なので \(\kappa\le\beta^*<\kappa^+\)。

- \(X\)、\(\mathcal A\)、\(G\) は遺伝的濃度が \(\rho\) 以下なので \(H_{\rho^+}=L_{\rho^+}\) の元である。
- \((\mathcal A\downarrow X)\) の対象 \((a,u)\) の \(u\) は \(a\) から \(X\) への準同型で、やはり \(L_{\rho^+}\) の元である。対象の全体と射の全体は \((L_{\rho^+},\in)\) 上で \(\mathcal A,X,c\) を助変数として定義可能なので、\(L_{\rho^++1}\) に属する。\(D_X\) はこれと \(G\) から定義でき、ある \(n<\omega\) で \(D_X\in L_{\rho^++n}\)。
- \(\beta^*>\rho^+\) である。\(\kappa>\rho^+\) なら明らか。\(\kappa=\rho^+\) かつ \(\beta^*=\rho^+\) なら \(F(X)=L_{\rho^+}\) の最大基数は極限基数 \(\rho\) となり、対象の公理「最大基数は後続基数」に反する。
- \(\beta^*\) は極限順序数なので \(\beta^*\ge\rho^++\omega\)、従って \(D_X\in F(X)\)。主張 A に反する。

### 4. 濃度の矛盾

\(F(X)\) は \(\mu\)-列で閉じるので \(|F(X)|^\mu=|F(X)|\)。König の定理から \(\operatorname{cf}|F(X)|>\mu=\operatorname{cf}(\rho)\)。主張 B と合わせて \(\sigma:=|F(X)|<\rho\)。

- **上から。** 各 \(a\in\mathcal A\) について \(|\mathcal K_\mu(N_a,F(X))|\le\sigma^{|N_a|}\le2^{\sigma\cdot g}\)。\(\rho\) は強極限で \(\sigma,g<\rho\) だから
  \[
  \sum_{a\in\mathcal A}|\mathcal K_\mu(N_a,F(X))|\le g\cdot2^{\sigma\cdot g}<\rho .
  \]
- **下から。** \(X\) は \(\lambda\)-可呈示対象からの射の像の合併である（\(\lambda\)-フィルター余極限はソートごとに計算される）。各 \(a\) の台は濃度 \(<g\) なので
  \[
  \rho=|X|\le g\cdot\sum_{a\in\mathcal A}|\operatorname{Mod}(c)(a,X)| ,
  \]
  従って \(\sum_a|\operatorname{Mod}(c)(a,X)|\ge\rho\)。
- \(F\) は忠実なので、各 \(a\) で \(\operatorname{Mod}(c)(a,X)\to\mathcal K_\mu(N_a,F(X))\) は単射である。二つの評価が矛盾する。∎

## 証明の要点

- \(\mathcal T\) には、アクセス可能ランク \(\mu\) と同じ共終数を持つ特異基数 \(\rho\) の濃度の対象がある（長さ \(\mu\) の鎖の合併）。終域 \(\mathcal K_\mu\) の対象は \(\mu\)-列で閉じるので、濃度 \(\rho\) を取れない。
- 忠実性から \(F(X)\) は \(\rho\) より小さくなれない。従って \(|F(X)|\ge\rho^+\) になるしかない。
- \(V=L\) では、濃度 \(\rho^+\) 以上の対象 \(L_{\beta^*}\) は \(L_{\rho^+}\) を元として含み、そこから \(X\) の標準図式と \(F(X)\) 自身を再構成してしまう。これが主張 A・B の矛盾である。

\(V=L\) を本質的に使うのは最後の点である。一般の宇宙では、濃度 \(\kappa\) の推移的モデルが \(H_\kappa\) を含むとは限らない。extendible による構成では \(F(X)\) は \(j\) の像から作られ、\(G\) を元として含まない。

[以前のノート](independence_negative_side_L.md) が得た比較埋め込み \(m_X\colon E(X)\to F(X)\)（臨界点が \((\nu,\nu^+)\) の中）は、\(\mu\)-Ind 延長 \(E\) と \(F\) の比較であった。今回は \(F\) 自身のランク \(\lambda\) での表示を使い、\(F(X)\) が \(L_{\nu^+}\) を元に持つことから直接矛盾を出している。

## 検証で特に確認すべき点

1. 主張 A の絶対性。\(F(X)\) の内部で作る直極限とその崩壊が、外部の余極限と一致すること。添字圏はフィルター圏で半順序とは限らない。
2. \(\mathcal K_\mu\) の \(\lambda\)-フィルター余極限が直極限の崩壊であること、および \(\mathcal K_\mu\) のアクセス可能性（「強到達不能基数がない」を除いた版）。
3. 主張 B で \(\kappa=\rho^+\) の場合の処理。\(F(X)=L_{\rho^+}\) を排除するのは「最大基数は後続基数」の公理だけである。
4. §1 の \(X\) の存在。証人で閉じた部分モデルの鎖の合併が \(c\)-モデルになること（\(\mu\) の取り方）。
5. \(D_X\in L_{\rho^++n}\) の評価。\(\mathcal A\) と \(G\) の代表の取り方に依存しないこと。

## 還元との関係

[\(L_\beta\) の圏への還元](reduction_to_L_beta_categories.md) の定理 D はこの証明には不要である。そこでの問い \(\mathcal C_\mu\preceq\mathcal C_{\mu'}\) にも同じ議論で否定の答えが出る見込みである。\(\mathcal C_\mu\) は共終数 \(\mu^+\) の特異基数 \(\rho\) の濃度の対象を持ち、\(\mathcal C_{\mu'}\) の対象 \(L_{\rho^+}\) は最大基数の共終数の公理で排除される。ただし §1 を \(\mathcal C_\mu\) の表示についてやり直す部分は書き下していない。

**問題文の読み方。** 系は、No.14 の終域を大きいアクセス可能圏に限る読み方（[README の注](README.md)）に依存する。
