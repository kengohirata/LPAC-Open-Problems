# No.14　否定が成り立つ宇宙の範囲：\(L[A]\) とその穏やかなクラス強制拡大

2026年11月20日。[\(V=L\) での否定](negation_in_L.md) を広げる。\(P\) は No.14 の肯定を表す。以下はこのノートでの導出で、独立検証は未実施である。

**結論。**
1. （ZFC）推移的な \(\mathrm{ZFC}^-\) モデルの圏へのアクセス可能関手 \(F\) について、\(F(X)\) の高さは、\(X\) の標準図式 \(D_X\) を元に持つどの推移的 \(\mathrm{ZFC}^-\) モデルの高さよりも真に小さい（補題 1）。
2. ある集合 \(A\) で \(V=L[A]\) なら \(P\) は偽（定理 2）。\(L[0^\#]\)、可測基数一つの \(L[U]\)、\(L\) の集合強制拡大はすべてここに入る。
3. \(L\) に全正則基数で Cohen 部分集合を加える Easton 積の拡大でも \(P\) は偽（定理 3）。同じ議論は、各 \(\mu\) で「集合強制 \(\ast\) \(\mu\) 以下の列を加えない尾部」に分解でき、尾部が \(H_{\rho^+}\) を集合強制の範囲で決める形のクラス強制に通用する。

従って、少なくともこの形のクラス強制では \(P\) のモデルは作れない。\(2^\kappa=\kappa^{++}\) にする Easton 強制のように、生成的対象が \(\mu\) の部分集合でコードできない場合は扱っていない。一方、\(P\) から巨大基数や \(0^\#\) を導く議論は得られておらず、無矛盾性の強さとしての下界は ZFC のままである。

## 1. 高さの補題（ZFC）

\(\mathcal K\) を次の形の圏とする。対象は \(\mathrm{ZFC}^-\)（Collection を含む）の推移的モデルで、射は初等埋め込み、ある正則 \(\lambda_0\) 以上の \(\lambda\) について \(\lambda\)-フィルター余極限が直極限の推移的崩壊で与えられる。

\(\mathcal T\) を \(\lambda\)-アクセス可能圏（\(\lambda\ge\lambda_0\)）、\(F\colon\mathcal T\to\mathcal K\) を \(\lambda\)-有向余極限を保存する関手、\(\mathcal A\) を \(\lambda\)-可呈示対象の代表の小さい充満部分圏とする。対象 \(X\) に対し \(D_X\colon(\mathcal A\downarrow X)\to\mathcal K\)、\((a,u)\mapsto F(a)\) と置く。

**補題 1。** \(M\) が \(\mathrm{ZFC}^-\) の推移的モデルで \(D_X\in M\) なら、\(F(X)\in M\)。特に \(F(X)\cap\mathrm{Ord}<M\cap\mathrm{Ord}\)。

証明は [\(V=L\) のノートの主張 A](negation_in_L.md) と同じである。\(M\) は \(D_X\) の直極限とその Mostowski 崩壊を内部で計算でき、結果は外部の崩壊 \(F(X)\) と一致する。主張 A は \(M=F(X)\) の場合にあたる。

この補題に \(V=L\) は要らない。\(V=L\) で矛盾になったのは、\(F(X)=L_{\beta^*}\) 自身が \(D_X\) を含む高さ \(\beta^*\) のモデルだったからである。以下の定理は、**\(F(X)\) と同じ高さで \(D_X\) を含む推移的 \(\mathrm{ZFC}^-\) モデルを見つける**ことで矛盾を出す。

## 2. \(V=L[A]\) の場合

**定理 2。** ある集合 \(A\) で \(V=L[A]\) なら、任意の大きいアクセス可能圏 \(\mathcal T\) に対し、ある \(\mu\) で忠実なアクセス可能関手 \(\mathcal T\to\mathcal K_\mu^A\) は存在しない。

\(A\subseteq\delta\) を順序数の集合としてよい。\(\mathcal K_\mu^A\)（\(\mu>\delta\) は正則）は次で定める。
- 対象は推移的集合 \(M\ni A\) で、\(\mathrm{ZFC}^-\)、\(V=L[A]\)、「最大基数が存在し後続基数である」を満たし、\(\mu\in M\)、\(\mu\)-列で閉じるもの。対象は \(L_\beta[A]\) の形である。
- 射は各 \(\xi\le\mu\) を固定する初等埋め込み。\(A\in H_{\mu^+}\) なので \(A\) も固定される。

\(V=L[A]\) では、\(\delta\) 以上の基数で GCH が成り立ち、基数 \(\tau>\delta\) について \(H_\tau=L_\tau[A]\) である。[\(V=L\) の証明](negation_in_L.md) の §0–§4 は、\(L_\beta\) を \(L_\beta[A]\) に、\(g\) を \(\delta\) より大きく取り直せば、そのまま通る。

- \(\mathcal K_\mu^A\) は大きいアクセス可能圏である（\(L_{\vartheta^+}[A]\)、\(\vartheta>\mu\) は後続基数）。
- 濃度 \(\rho\)（\(\operatorname{cf}\rho=\mu\)、\(\rho>2^g\) の極限基数）の \(X\) について、数え上げから \(|F(X)|\ge\rho^+\)。
- \(F(X)=L_{\beta^*}[A]\) で \(\beta^*\ge\rho^+\)。\(\beta^*=\rho^+\) は最大基数が極限基数 \(\rho\) になるので不可。
- \(D_X\) は \(L_{\rho^+}[A]=H_{\rho^+}\) 上で定義可能なので \(D_X\in L_{\rho^++n}[A]\subseteq F(X)\)。補題 1 を \(M=F(X)\) に適用して矛盾。

**系。** \(P\) が成り立てば、どの集合 \(A\) についても \(V\ne L[A]\)。

## 3. Easton 積による拡大

\(\mathbb P\) を、\(L\) で定義した、全正則基数 \(\kappa\) に対する \(\operatorname{Add}(\kappa,1)\) の Easton 台の積とし、\(G\) を \(L\) 上生成的、\(V=L[G]\) とする。\(V\) は ZFC と GCH を満たし、基数と共終数は \(L\) と一致する。

**定理 3。** \(V=L[G]\) で \(P\) は偽である。

**設定。** \(\mathcal T\simeq\operatorname{Mod}(c)\)、\(c\in H_\theta\) とし、正則 \(\mu>\theta\) を \(c\) の項数と式の大きさより大きく取る。\(\mathbb P=\mathbb P_{\le\mu}\times\mathbb P_{>\mu}\) と分ける。
- \(\mathbb P_{\le\mu}\) は濃度 \(\mu\) の集合強制で \(\mu^+\)-c.c.。\(G_{\le\mu}\) を \(A\subseteq\mu\) でコードし \(W=L[A]\) と置く。
- \(\mathbb P_{>\mu}\) は \(L\) で \(\mu^+\)-閉。Easton の補題により \(W\) 上で \(\mu^+\)-分配的で、\(V=W[G_{>\mu}]\) は \(W\) に長さ \(\mu\) 以下の順序数列を加えない。特に \(H_{\mu^+}^V=H_{\mu^+}^W\ni c\)。

終域は \(V\) で定義した \(\mathcal K_\mu^A\) とする。対象は \(L_\beta[A]\) で、\(V\) での \(\mu\)-閉性は \(W\) でのそれと一致する。射は \(V\) にある初等埋め込みすべてである。\(V\) で GCH が成り立つので、定理 2 と同じ理由で大きいアクセス可能圏になる。

**証明。** 忠実で \(\lambda\)-有向余極限を保存する \(F\colon\operatorname{Mod}(c)\to\mathcal K_\mu^A\) があるとし、\(\mathcal A,G_F=F|_{\mathcal A},g,\rho,X\) を \(V\) の中で [\(V=L\) の証明](negation_in_L.md) と同様に取る。

1. 数え上げ（\(V\) の濃度で行う）から \(|F(X)|\ge\rho^+\)。\(F(X)=L_{\beta^*}[A]\)、\(\beta^*\ge\rho^+\)。基数が保たれるので \(L_{\rho^+}[A]\) の最大基数は極限基数 \(\rho\) であり、\(\beta^*>\rho^+\)。
2. \(\rho\) は特異基数なので積に \(\rho\) の因子はなく、\(G_{\le\rho}=G_{<\rho}\) である。**\(V\) の \(\rho\) の部分集合はすべて \(L[G_{<\rho}]\) に属する。** \(\rho\) に共終な正則基数の列 \((\rho_i)_{i<\mu}\) を取る。\(x\subseteq\rho\) に対し、各 \(x\cap\rho_i\) は \(\rho_i\) での Easton の補題により \(L[G_{\le\rho_i}]\) に入る。\(L[G_{<\rho}]\) の整列順序で \(\langle x\cap\rho_i:i<\mu\rangle\) を長さ \(\mu\) の順序数列にコードすると、それは \(W=L[G_{\le\mu}]\) に入るので、\(x\in L[G_{<\rho}]\)。Cohen 部分集合の列をコードする \(B\subseteq\rho\) を取ると、\(G_{<\rho}\) は \(B\) と \(\mathbb P_{<\rho}\in L\) から定義でき、\(H_{\rho^+}^V=L_{\rho^+}[B]\)。
3. \(D_X\) は \(H_{\rho^+}^V\) 上で \(\mathcal A,X,c,G_F\) を助変数として定義可能なので、\(D_X\in L_{\rho^++n}[B]\)。
4. \(\mathbb Q=\mathbb P_{(\mu,\rho)}\) は \(L_{\rho^+}\) の部分集合で \(L_{\rho^+}\) 上定義可能だから \(\mathbb Q\in L_{\rho^++1}\subseteq F(X)\)（\(\beta^*\) は極限順序数で \(\beta^*\ge\rho^++\omega\)）。\(L\) での濃度は \(\rho^+\) で、\(L_{\rho^+}\) の元ではない。\(G_{(\mu,\rho)}\) は積の補題により \(L[A]\supseteq F(X)\) 上生成的である。\(N=F(X)[G_{(\mu,\rho)}]\) と置く。Collection を含む \(\mathrm{ZFC}^-\) は集合強制で保たれ、高さも変わらないので、\(N\) は高さ \(\beta^*\) の推移的 \(\mathrm{ZFC}^-\) モデルである。
5. \(B\in N\) なので \(L_{\rho^++n}[B]\subseteq N\)、従って \(D_X\in N\)。補題 1 から \(F(X)\in N\) となり、\(\beta^*<N\cap\mathrm{Ord}=\beta^*\)。矛盾。∎

**一般化できる形。** 証明が使ったのは次の三点である。
- 各 \(\mu\) について、\(V\) は集合 \(A\) による \(L[A]\) に長さ \(\mu\) 以下の順序数列を加えない拡大である（\(L_\beta[A]\) 型の対象が \(V\) でも \(\mu\)-閉になる）。
- 基数が保たれ、\(V\) で GCH 程度の濃度計算ができる。
- 大きい \(\rho\) について、\(L[A]\) 上生成的な \(h\) で \(H_{\rho^+}^V=L_{\rho^+}[A,h]\) となり、その強制はある \(k\) で \(L_{\rho^++k}[A]\) の元である。

逆 Easton 反復や、\(L\) の代わりに \(L[A_0]\) から始める場合もこの形になる見込みだが、個別には確かめていない。

## 4. この方法の限界

**\(P\Rightarrow\) シャープ、は出ていない。** シャープを持たない集合 \(A\) がある場合に同じ方法を試すと、二か所で止まる。

1. **終域が作れるかが未決。** \(L_\beta[A']\) 型の対象が \(V\) で \(\mu\)-閉になるには、長さ \(\mu\) の順序数列がすべて \(L[A']\) に入る必要がある。当初は「\(A'\supseteq A\) が \(H_{\mu^+}\) をコードすれば被覆補題から従う」と考えたが、これは誤りだった。
   - 相対化した被覆補題が与える被覆の濃度は \(|X|+|\sup A'|+\aleph_1\) で、\(\sup A'\ge\mu^+\) なので \(\mu\) に収まらない。
   - \(A\notin H_{\mu^+}\) なら反例がある。\(V=L[U][s]\)（\(s\) は \(\kappa\) の Prikry 列）、\(A=U\)、\(\mu=\omega_1<\kappa\) では、\(s\notin L[A']=L[U]\)。
   - \(A\in H_{\mu^+}\) の場合も証明がなく、未決である。
2. **仮に終域が作れても最後の段が出ない。** 補題 1 を使うには高さ \(\beta^*\) で \(D_X\) を含む \(\mathrm{ZFC}^-\) モデルが要るが、一般の \(V\) では \(D_X\) をコードする集合が \(\beta^*\) の崩壊をコードし得る。定理 3 では生成性がこれを排除していた。

なお、この場合の終域では射に \(A'\) の固定（臨界点が \(\sup A'\) より上）を課す必要がある。

**見通し（発見的）。** \(P\) のモデルは、\(L[A]\) 型の対象が閉じない宇宙か、\(H_{\rho^+}\) が定義可能な集合強制で捉えられない形で作られた宇宙のどちらかだろう、というのが現時点の推測である。1 が未決なので、これは定理ではない。前者の最小の候補は、すべての集合がシャープを持つという仮定を加えた Dodd–Jensen の \(K\) である（\(V=K\) だけでは \(K=L\) もあり得る）。そこでは終域を「\(\mu\)-列で閉じた \(V=K\) の推移的モデル」に取り替え、そのような対象が自分の濃度未満のマウスをすべて含むことを示せば、同じ証明が通る見込みがあるが、確かめていない。

## 検証の記録

11月20日、経緯を知らない別セッションの Claude に誤りを探させた。補題 1 と定理 2 は欠陥なし。定理 3 は結論は成立し、証明の記述に三点の不備があった（\(\rho\) の部分集合が \(L[G_{<\rho}]\) に入る理由の欠落、\(\mathbb Q\in L_{\rho^+}\) という誤記、不要で未証明の等式）。いずれも上に反映した。§4 の被覆補題の主張は誤りと指摘され、上のとおり書き直した。「一般化できる形」は概略の確認にとどまる。同じモデルによる一回の査読であり、人による検証の代わりにはならない。
