# No.14　共通の始域と extendible cardinal による上界

2026年11月19日。終域はすべて大きいアクセス可能圏とする。以下はこの研究ノートでの導出であり、独立検証・初出確認は未実施である。「大きい」は本質的に小さくないという意味で使う。

**結論。** ZFC では、あらかじめ集合個の終域を指定すれば、それらすべてに向かう忠実なアクセス可能関手を持つ一つの大きいアクセス可能圏がある。さらに extendible cardinal が一つ存在すれば、始域を一度選んで、任意の大きいアクセス可能圏に対して使える。後者では終域ごとに関手が保存する有向余極限のランクが変わる。

## 1. 集合個の終域を同じ台集合で表す

\((\mathcal K_i)_{i\in I}\) を集合で添字付けた大きいアクセス可能圏の族とする。原著の定理 5.35 により、それぞれを多ソートの basic theory \(c_i\) のモデルと全準同型の圏として、圏同値を除いて表示する。basic な公理の形は \(\forall\bar x\,(\varphi\Rightarrow\psi)\) で、前件・後件は正の原始式の選言でよい。空選言と空連言を許す。各理論・署名は集合である。[Adámek–Rosický, 定義 5.31・定理 5.35](https://doi.org/10.1017/CBO9780511600579.008)

以下の操作で一つの basic theory \(B\) を作る。

1. 署名を \(i\) でタグ付けし、すべての \(c_i\) の公理を取る。共通ソート \(S\) を一つ追加し、そこに狭義全順序を入れる。狭義全順序の公理は basic であり、準同型の \(S\) 成分は単射になる。
2. 各 \(i\) と各ソート \(s\) について \(e_{i,s}\colon M_{i,s}\to S\) を置く。固定した \(i\) ごとに、これらが単射で、異なるソートの像が互いに素で、その像全体が \(S\) を覆うと公理化する。被覆公理は \(\forall z\in S\,\bigvee_s\exists x\,(e_{i,s}(x)=z)\) である。単射性と像の互いの素性も、それぞれ等式と偽を後件に取る basic な公理で書ける。つまり、各座標の全ソートの非交和を同じ \(S\) と同一視する。

\(\mathcal T=\operatorname{Mod}(B)\) は定理 5.35 でアクセス可能である。座標射影 \(P_i\colon\mathcal T\to\operatorname{Mod}(c_i)\) は忠実である。二つの準同型が第 \(i\) 座標で一致すれば、被覆公理から \(S\) 上で一致する。各 \(e_{k,s}\) の単射性により、残りのすべてのソートで一致する。また、どの準同型もすべてのソートで単射である。全理論の式の長さと項数を上回る正則基数を取れば、そのランクの有向余極限は各モデル圏でソートごとに計算できるので、各射影はアクセス可能である。これは定理 5.35 の証明で用いる basic theory の余極限閉性でもある。

**\(\mathcal T\) の大きさ。** 各 \(c_i\) には任意に大きい総台濃度のモデルがある。濃度が有界なら、集合サイズの署名の構造は同型を除き集合個にとどまるからである。さらに、各 \(c_i\) のモデルを同じ濃度にそろえられる。全署名・理論を含む集合の遺伝的濃度より大きな無限基数 \(\rho\) を取り、\(\theta=2^\rho\) とする。各理論で十分大きなモデルに \(\theta\) 個の元を取り、その理論の部分式からなる断片について下方 Löwenheim–Skolem を適用する。必要な証人関数は高々 \(\rho\) 個、項数は高々 \(\rho\) で、\(\theta^\rho=\theta\) だから、閉包の大きさは \(\theta\) である。閉包は、証人関数による段階を \(\rho^+\) 回反復して取れる。こうして得た各モデルの総台を同じ整列集合 \(S=\theta\) に全単射で移せば \(B\) のモデルを得る。\(\rho\) はいくらでも大きくできる。これで集合個の終域についての主張が従う。

**一般問題の同値な形。** 大きいアクセス可能圏 \(\mathcal K\) に対し、忠実なアクセス可能関手 \(\operatorname{Mod}(c)\to\mathcal K\) があり、\(\operatorname{Mod}(c)\) が大きくなる basic theory \(c\) のうち、そのコードの遺伝的濃度の最小値を \(b(\mathcal K)\) とする。対象自身の表示があるので最小値は存在する。No.14 の肯定は \(b(\mathcal K)\) 全体に共通の基数上界があることと同値である。一方向は共通の始域を表示すればよい。逆向きは、コードを改名してその上界以下のものを集合個の代表にまとめ、上の構成を大きいモデル圏を与える代表すべてに適用し、得た関手を合成すればよい。したがって否定には、任意に大きなコードの下界が必要になる。

## 2. 小さい部分圏上の忠実性を保って延長する

\(\mathcal A\) を \(\mu\)-アクセス可能とし、\(\mathcal A_\mu\) を \(\mu\)-可呈示対象の小さい充満代表部分圏とする。終域 \(\mathcal K=\operatorname{Mod}(c)\) で \(\mu\)-フィルター余極限がソートごとに計算できるとする。忠実関手
\[
G\colon\mathcal A_\mu\longrightarrow\mathcal K
\]
が各射をソートごとの単射に送るとき、\(\mathcal A\simeq\operatorname{Ind}_\mu(\mathcal A_\mu)\) による \(\mu\)-フィルター余極限保存延長 \(F\colon\mathcal A\to\mathcal K\) は忠実である。[原著第2章、アクセス可能圏の標準表示](https://doi.org/10.1017/CBO9780511600579.005)

実際、異なる \(f,g\colon X\rightrightarrows Y\) に対し、\(a\in\mathcal A_\mu\) と \(t\colon a\to X\) で \(ft\ne gt\) となるものがある。\(Y\) の \(\mu\)-フィルター表示の同じ段階 \(q\colon b\to Y\) に \(ft,gt\) を通し、\(ft=qu,\ gt=qv\) と書く。\(u\ne v\) なので \(Gu\ne Gv\)。他方 \(Fq\) はソートごとに単射である。集合のフィルター余極限では、遷移写像がすべて単射なら各標準写像も単射になるからである。従って \(Fq\,Gu\ne Fq\,Gv\) で、\(Ff\ne Fg\) を得る。ここでは \(G\) の小さい定義域に内部的に存在する余極限の保存を仮定しない。

## 3. 一つの extendible cardinal から共通の始域を得る

\(\kappa\) を extendible cardinal とする。必要な性質は、任意に大きく指定したランク \(\alpha>\kappa\) に対し、ある \(\beta\) と初等埋め込み \(j\colon V_\alpha\to V_\beta\) があり、臨界点が \(\kappa\)、\(j(\kappa)>\alpha\) となることである。\(\kappa\) は強到達不能である。以下では \(\alpha\) を十分大きい極限順序数に取り、\(V_\kappa\) や必要なコードと集合をすべて \(V_\alpha\) に含める。[Bagaria, *\(C^{(n)}\)-cardinals*](https://arxiv.org/abs/1908.09664)

**始域の固定。** \(I_\kappa\) を、\(V_\kappa\) に属する basic theory のコード \(d\) のうち、\(V_\kappa\) 内で任意に大きい総台濃度のモデルを持つもの全体とする。この定義は集合構造 \(V_\kappa\) に相対化してある。すべての \(d\in I_\kappa\) は外部でも任意に大きいモデルを持つ。実際、任意の濃度上界 \(\zeta\) を越える \(\alpha\) で上の \(j\) を取ると、\(j(d)=d\) であり、\(V_{j(\kappa)}\) は \(d\) に任意に大きいモデルがあると判定する。特に濃度が \(\zeta\) を越えるモデルがある。\(j(\kappa)\) は外部でも強到達不能である。これは \(V_\beta\) がその到達不能性を満たし、\(\beta\) が \(j(\kappa)+\omega\) を越えていて、反例となる冪集合や列をすべて含むためである。このランク内のモデルの充足と濃度の判定は外部と一致する。

従って §1 を \(I_\kappa\) の全コードに適用できる。署名はタグ付けして複製し、コード \(d\) 自身をその座標の添字とする。得られる一つの理論を \(B_\kappa\)、その大きいアクセス可能モデル圏を \(\mathcal T_\kappa\) とする。この選択は終域に依存しない。

**任意の終域への関手。** 大きいアクセス可能圏を \(\mathcal K\simeq\operatorname{Mod}(c)\) と表示する。次の順序でデータを選ぶ。

1. \(\mathcal T_\kappa\) と \(\operatorname{Mod}(c)\) がともに \(\mu\)-アクセス可能で、後者が \(\mu\)-フィルター余極限をソートごとに計算する正則基数 \(\mu\) を選ぶ。後者には \(c\) の論理のランク以上で足りる。二つの圏に共通するランクは、それぞれのアクセス可能性のランクより sharply larger な正則基数を取ればよく、そのようなものは任意に大きく取れる。小さい充満代表 \(\mathcal A=(\mathcal T_\kappa)_\mu\) は実際の \(B_\kappa\)-モデルとその準同型で選ぶ。
2. \(c,B_\kappa,I_\kappa,\mathcal A\) とその対象・射のコードをすべて含む十分大きい \(V_\alpha\) を取り、extendibility を適用する。すると
   \[
   j(I_\kappa)=
   \{d\in V_{j(\kappa)}:V_{j(\kappa)}\text{ で }d\text{ は任意に大きいモデルを持つ basic theory}\}.
   \]
   **元の \(c\) 自身が \(j(I_\kappa)\) の元である。** 実際、\(c\in V_{j(\kappa)}\) であり、任意の \(\xi<j(\kappa)\) に対し、外部で \(c\) の大きなモデルを取る。§1 の下方 Löwenheim–Skolem により、\(\xi\) と \(c\) のコードの濃度を越え、なお \(j(\kappa)\) 未満の濃度のモデルを取れる。ここで強到達不能性を使う。台を順序数に移してコードすれば、そのモデルは \(V_{j(\kappa)}\) に属する。これは \(c=j(d)\) となる \(d\in I_\kappa\) の存在を必要としない。
3. \(M\in\mathcal A\) に対し、\(j(M)\) は \(j(B_\kappa)\) のモデルである。この理論は \(j(I_\kappa)\) を座標集合とする §1 の構成なので、第 \(c\) 座標を読める。射にも同じ操作をして
   \[
   G(M)=j(M)|_c,\qquad G(h)=j(h)|_c
   \]
   と置く。これは集合サイズの圏 \(\mathcal A\) 上の真正な関手である。コードのタグを解けば値は \(\operatorname{Mod}(c)\) に属する。\(j\) は異なる射を区別し、一つの座標への射影も §1 の議論で忠実である。しかも \(S\) 上の線形順序により \(G(h)\) はソートごとの単射になる。ここで用いる充足や関数の等式は推移的なランク \(V_\beta\) の外でも成り立つ。式の変数への代入はすべて集合サイズで、式とモデルを含むこの極限ランク内に属する。
4. §2 により \(G\) は忠実な \(\mu\)-フィルター余極限保存関手 \(\mathcal T_\kappa\to\operatorname{Mod}(c)\) に延びる。\(\mathcal K\) との圏同値を合成して結論を得る。

使用した初等埋め込みは、小さい部分圏 \(\mathcal A\) を含む一つのランクにだけ定義されている。全始域への延長を可能にしているのは、座標での単射性と \(\mathcal T_\kappa\) の可呈示対象による表示である。この証明は No.14 の集合論的な十分条件を与える。ZFC 単独での存在・非存在や、この十分条件の必要性は未確定である。

## 4. 順序数による既出の候補との比較

\(\delta\) を非可算正則基数とする。出版版の注意 4.3 に従い、\(C_\delta\) の対象を \(\alpha<\delta\)、非恒等射を \(\alpha<\beta\) の間のすべての順序埋め込みとする。\(D_\delta=\operatorname{Ind}_\delta C_\delta\) と、整列集合と順序埋め込みの圏 \(\mathbf W\) は、互いに向かう忠実なアクセス可能関手を持つ。[Rosický, 注意 4.3・問題 4.4](https://tac.mta.ca/tac/volumes/36/10/36-10.pdf)

一方向には標準関手 \(C_\delta\to\mathbf W\) を \(\delta\)-フィルター余極限で延長する。\(\delta\) が非可算なので、集合で取った余極限の順序に可算降下列があれば、その元と比較を同じ段階に集められる。従って余極限は整列集合で、段階からの写像は単射である。§2 と同じ判定により延長は忠実になる。

逆向きには濃度 \(\ge\delta\) の整列集合 \(X\) に前層 \(P_X(\alpha)=\operatorname{Emb}(\alpha,X)\) を対応させる。これは \(D_\delta\) の対象である。実際、\(X\) の濃度 \(<\delta\) の部分集合を、等号のほか「包含かつ順序型が真に増加すること」で順序付ける。この添字は \(\delta\)-有向である。少数の部分集合の合併に、それらすべての順序型を越える長さ \(<\delta\) の部分整列集合を追加すればよい。各部分集合の順序型の米田像を標準包含でつなぐと余極限は \(P_X\) になる。任意の \(\alpha\to X\) は像を十分大きな順序型の部分集合に含めればその段階から来る。同じ埋め込みを表す二つの段階は共通の後段で一致する。

\(X\mapsto P_X\) は後合成で関手になり、\(\alpha=1\) で評価すれば忠実である。各 \(|\alpha|<\delta\) なので、\(\delta\)-フィルター余極限も保存する。任意の整列集合 \(Y\) には先頭に固定した \(\delta\) を付けた順序和 \(\delta+Y\) を割り当て、射は先頭で恒等とする。この操作も忠実で \(\delta\)-フィルター余極限を保存するので、合成が \(\mathbf W\to D_\delta\) を与える。

特に、これらの Ind 完備化から忠実なアクセス可能関手で到達できる終域は、非可算正則 \(\delta\) の選び方によらず、\(\mathbf W\) から到達できる終域と一致する。Rosický の例 4.2 のように全自己射が恒等射になる大きい終域はこの範囲から外れる。§1・§3 の構成では、始域の射に、すべての座標の構造を同時に保つという条件を課している。
