# 段階では枝がなく、直極限で初めて外部の枝を持つ木

2026年11月19日。前稿と同じ \(V=L\) で強到達不能基数がない宇宙で考える。まず \(\mu=\omega_1\) として読める。証明は任意の非可算正則基数 \(\mu\) に共通である。以下は今回の証明案であり、独立検証は未実施である。[終域 \(\mathcal K_\mu\) の公理と既知の余極限](independence_negative_side_L.md)

## 結果

\(\theta=2^\mu\) とする。\(\mathcal K_\mu\) に、大きさ \(\le\theta\) の対象からなる長さ \(\mu\) の鎖 \((P_\alpha,j_{\alpha\beta})\) と、各 \(P_\alpha\) の中の木 \(T_\alpha\)、その高さ \(\alpha\) の節点 \(t_\alpha\) が存在し、次を満たす。

1. 各段階は \(T_\alpha\) に共終する長さ \(\mu\) の枝がないと判定する。各 \(P_\alpha\) は外部の \(\mu\)-列に閉じているので、外部にもそのような枝はない。
2. \(\alpha<\beta\) なら \(j_{\alpha\beta}(T_\alpha)=T_\beta\) であり、\(j_{\alpha\beta}(t_\alpha)\) は \(t_\beta\) の高さ \(\alpha\) の先祖である。遷移射はすべての三段階で合成と一致する。
3. 一階構造として直極限を取って崩壊した \(P\) は、像の木 \(T\) に枝がないと判定する。しかし外部では各 \(t_\alpha\) の像が \(T\) の共終枝をなす。さらに、この鎖は \(\mathcal K_\mu\) に余錐を一つも持たない。

この証明では木の幅に上限を課さない。「共終枝」は高さ \(\mu\) の木では各レベルを通る枝を意味する。途中で高さ \(<\mu\) の木を含める際にも、排除するのは長さ \(\mu\) の枝である。木には各節点の真の先祖が整列されるという規約を使い、根の一意性は要求しない。

## 木と一節点から作る閉包

\(B\in\mathcal K_\mu\) と \(B\) 内の木 \(S\)、節点 \(s\) を取る。\(Q_B(S,s)\) を、\(S,s\) と \(\xi\le\mu\) を含み、次の操作について閉じた最小の部分構造とする。

- \(V=L\) の標準整列で証人を選ぶ、各一階存在式の Skolem 関数。
- 外部の \(\mu\)-列の各項を、その列の集合コードに送る \(\mu\) 項演算。

後者は \(B\) の列閉性により定義される。これらの操作を \(\mu^+\) 段反復すれば閉包になり、\((2^\mu)^\mu=2^\mu\) より濃度は \(\le\theta\) である。Skolem 閉包なので \(Q_B(S,s)\prec B\) である。推移的崩壊は \(\mathcal K_\mu\) の対象になる。崩壊は列の添字 \(\xi\le\mu\) を固定するので、列コードを点ごとに移すからである。

射 \(e:B\to B'\) は上の両操作と可換である。特に \(e\) の像の元からなる任意の外部 \(\mu\)-列は、元を点ごとに戻してから列コードを移せる。このため \(e[Q_B(S,s)]=Q_{B'}(e(S),e(s))\) となる。\(r\) が \(s\) の高さ \(\beta<\mu\) の先祖なら、\(r\) は \(S,s,\beta\) から一意に定まり、\(Q_B(S,r)\subseteq Q_B(S,s)\) である。この小さい方の閉包は大きい方の中で同じ操作をしても一致する。以下で「中で閉包を取る」は上記の外部操作をその部分構造で用いる意味であり、自己の全真理述語を内部に持つことは仮定しない。

## 印付き閉包の同型型を節点とする木 \(U\)

高さ \(\alpha<\mu\) の節点を次の三つ組の同型型とする。

\[
 (P,T,t),\qquad P\in\mathcal K_\mu,\quad |P|\le\theta,\quad
 P=Q_P(T,t).
\]

\(P\) は「\(T\) は高さ \(\le\mu\) の木で、長さ \(\mu\) の枝を持たず、\(t\) の高さは \(\alpha\) である」と満たすものに限る。三つ組は集合サイズの台に載せてコードでき、型全体は集合である。\(t\) の \(\beta\) 段目の先祖を \(r\) として、\((Q_P(T,r),T,r)\) を崩壊した型を、この型の \(\beta\) 段目の先祖と定める。閉包の包含とその可換性により、先祖の先祖は直接取った先祖と一致する。従ってこれは本当に木であり、指定した \(\alpha\) はその節点の高さに等しい。推移的な整礎外延構造の間の全射同型は、存在すれば一意である。

**任意の集合サイズの、高さ \(\le\mu\) で長さ \(\mu\) の枝を持たない木 \(S\) から \(U\) に、狭義順序を保つ写像がある。** 実際、\(S\) を元として含むほど大きい後続基数 \(\vartheta>\mu\) を取り、\(B=H_{\vartheta^+}=L_{\vartheta^+}\) とする。前稿の通りこれは \(\mathcal K_\mu\) の対象であり、\(S\) の高さと枝の非存在を正しく判定する。各 \(s\in S\) を \((Q_B(S,s),S,s)\) の崩壊の型に写せばよい。先祖は上で定めた先祖に写り、厳密な高さの増加は保たれる。比較できない節点が同じ型に写っても差し支えない。

## Kurepa の対角化

もし \(U\) に長さ \(\mu\) の枝がなければ、\(\sigma_{<\mu}U\) を、\(U\) 内の長さ \(<\mu\) の狭義増加列すべて（空列を含む）を真の始切片関係で並べた木とする。これにも長さ \(\mu\) の枝はない。そのような枝があれば列の合併が \(U\) 内の長さ \(\mu\) の増加列になる。ところが直前の性質により、狭義順序を保つ写像 \(f:\sigma_{<\mu}U\to U\) が存在する。そこで

\[
 u_\alpha=f(\langle u_\xi:\xi<\alpha\rangle)\qquad(\alpha<\mu)
\]

と再帰する。各段で以前の引数は今の引数の真の始切片なので、帰納的に \(u_\xi<_U u_\alpha\) がすべての \(\xi<\alpha\) で成立する。極限段でも引数自体が添字木の節点である。従って \(U\) には長さ \(\mu\) の増加列があり、仮定に反する。これで \(U\) の共終枝が得られた。この対角化は Kurepa の \(\sigma\) 操作であり、新しく用いた部分は、\(\mathcal K_\mu\) の列閉な印付き初等部分構造で上の \(U\) を構成したことである。[Džamonja–Shelah による \(\sigma\) 操作の説明](https://ueaeprints.uea.ac.uk/id/eprint/75460/1/wideAronszajntreesafterreferee2.pdf)

## 枝を実際の鎖に戻す

下向きに閉じて \(U\) の枝の各高さに一節点を取り、その推移的代表を \((P_\alpha,T_\alpha,t_\alpha)\) とする。\(\alpha<\beta\) のとき、\(P_\beta\) 内で \(t_\beta\) の高さ \(\alpha\) の先祖 \(r\) を取り、\(Q_{P_\beta}(T_\beta,r)\) を作る。その崩壊は印も含めて \(P_\alpha\) と一致する。逆崩壊と包含を合成したものが \(j_{\alpha\beta}\) である。入れ子の閉包の一意な同型を使っているので \(j_{\beta\gamma}j_{\alpha\beta}=j_{\alpha\gamma}\) が成り立つ。この段階で独立な埋め込みの選択を両立させる仮定は要らない。各段階の木の高さは実は \(\mu\) である。もしある段階で高さが \(\eta<\mu\) なら、\(\eta\) は固定されるので、後段の \(t_\beta\) の高さが非有界であることに反する。

この鎖の一階構造としての直極限は整礎である。もし可算降下列があれば、可算個の元と関係の証人が同じ段階に集まる。初等直極限を推移的に崩壊した \(P\) は全段階と同じ一階公理を満たし、木 \(T\) に枝がないと判定する。一方、\(t_\alpha\) の像は外部で各レベルを通る。もし鎖から \(B\in\mathcal K_\mu\) へ余錐があれば、そこでも同じ木の各レベルを通る列が得られる。\(B\) の \(\mu\)-列閉性からその列は \(B\) の元であり、余錐の脚の初等性に反する。全く同じ理由で、\(P\) から \(B\) への \(\mu+1\) を点ごとに固定する初等埋め込みも存在しない。

## どの関手を排除するか

\(\mathcal C\) を前稿の大きさ \(\le 2^\mu\) の対象の小さい充満代表部分圏とし、鎖を代表に移す。\(X=\operatorname{colim}_{\alpha<\mu}yP_\alpha\) は \(\mathcal A=\operatorname{Ind}_\mu(\mathcal C)\) 内で存在する。前稿の一階構造への延長 \(E\) について \(E(X)\cong P\) である。もし \(F:\mathcal A\to\mathcal K_\mu\) の \(\mathcal C\) への制限がもとの包含と自然同型なら、標準射 \(yP_\alpha\to X\) の像が禁止した余錐になる。従って**包含を延長する関手は一つもない**。この結論に \(F\) の忠実性もアクセス可能性も仮定しない。\(\mathcal C\) 上で別の値を取る関手、および No.14 の他の始域候補については決まらない。[始域候補 \(\mathcal A\)](coherent_diagrams_in_K_mu.md)

## 終域の最小アクセス可能ランク

上の \(\mu\)-鎖はすべての無限正則 \(\lambda\le\mu\) に対して \(\lambda\)-有向であり、余錐を持たない。従って \(\mathcal K_\mu\) はそのどのランクでもアクセス可能ではない。一方、\(\mathcal K_\mu\) は \(\mu^+\)-アクセス可能である。前稿の通り \(\mu^+\)-フィルター余極限は、一階構造の直極限を崩壊して計算できる。任意の対象は、\(\le\mu\) 個の元と名前付き順序数から上の二種類の操作で生成した部分構造の \(\mu^+\)-有向合併である。それらの崩壊は濃度 \(\le2^\mu\) なので、同型を除いて集合個である。

これらの生成された対象は \(\mu^+\)-可呈示である。直極限への射を与えると、生成元の像は共通の一段階に入り、その段階の像が両操作で閉じているから射全体もそこを経由する。因子の初等性は、その合成と段階からの脚の初等性から従う。二つの因子化は共通の後段で比較でき、そこから直極限への脚が単射なので一致する。よって **\(\mathcal K_\mu\) の最小アクセス可能ランクは \(\mu^+\)** であり、\(\mu=\omega_1\) なら \(\omega_2\) である。
