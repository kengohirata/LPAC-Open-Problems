# No.14　包含を変えて枝の図式に余錐を与える

前稿と同じ \(V=L\)、強到達不能基数なし、\(\mu=\omega_1\) とする。\(\theta=2^\mu\)、\(\mathcal C\) は \(\mathcal K_\mu\) の濃度 \(\le\theta\) の対象の小さい充満代表部分圏である。\(X=\operatorname{colim}_{i<\mu} yP_i\) は前稿で得た枝の鎖の \(\operatorname{Ind}_\mu(\mathcal C)\) 内の余極限、\(q_i:yP_i\to X\) はその脚とする。以下で \(c\) とその米田像を適宜同一視する。目標とする小さい充満部分圏は \(\mathcal B=\mathcal C\cup\{X\}\) である。以下は今回の導出で、独立検証は未実施である。[枝と鎖の構成](branch_at_direct_limit.md)

## 充満部分圏での必要十分条件

\(\mathcal B\) 上の忠実関手の存在は、次の二つを同時に選べることと同値である。

1. 忠実関手 \(H:\mathcal C\to\mathcal K_\mu\)。
2. 鎖 \(H(P_i)\) の \(\mathcal K_\mu\) 内の余錐 \(p_i:H(P_i)\to B\)。

理由は三方向の Hom を計算すると分かる。

- \(X\to c\) は存在しない。そのような射に前稿の一階構造への延長 \(E\) を適用すると、禁止された \(E(X)\to c\) が生じる。
- \(X\) の自己射は恒等射だけである。\(E\) は忠実で、推移的モデル \(E(X)\) は前々稿の自己埋め込み補題の一階公理を満たす。ここで \(E(X)\) の \(\mu\)-列閉性は不要である。[自己埋め込み補題](coherent_diagrams_in_K_mu.md)
- \(u:c\to X\) は \(q_i h\) と書ける。\(c\) が \(\mu\)-可呈示であるためである。そこで \(G(u)=p_i H(h)\) と定める。異なる表示は共通の後段で一致し、これで定義が表示に依存せず合成を保つ。異なる \(u,v:c\to X\) は共通段階で異なる二射により表され、\(H\) の忠実性と \(p_i\) の単射性により区別される。

逆向きは \(H=G|_{\mathcal C}\)、\(p_i=G(q_i)\) とすればよい。特に、\(H\) が忠実なら \(X\) に入る射の忠実性をもう一度課す必要はない。

したがって、\(X\) と任意の一つの小対象 \(c\) だけが張る**充満**部分圏では常に肯定である。実際、\(c\) の自己射も恒等射だけなので、任意の集合 \(\mathcal B(c,X)\) の要素を区別するだけでよい。十分大きい \(B=H_{\vartheta^+}\) の中で一個の順序数と名前付き順序数から生成する列閉 Skolem 閉包の印付き同型型は、高々 \(2^\theta\) 種類である。必要な本数より大きい基数と \(2^\theta\) の積を超えて順序数を用意すれば、同じ型を持つ異なる印を必要数だけ取れる。同じ崩壊から \(B\) に向かう逆崩壊たちは印の像で相異なる。これを各 \(c\to X\) の像に使える。同じ議論は相異なる対象間に射がない小対象の任意の集合と \(X\) が張る充満部分圏にも通用する。この場合には生成元に関する仮定は必要ない。

## 肯定的な構成　有限個の生成された試験対象と鎖全体

次の部分圏では実際に、包含を変えた忠実関手を作れる。

- 枝から有限個の段階を試験対象として選び、それらの間の有限個の射を選ぶ。恒等射と合成をすべて加える。
- 試験対象より後の共終な尾部を取り、尾部の段階間には鎖の標準遷移射を、各段階から \(X\) には \(q_i\) を入れる。
- **各試験対象から、各尾部段階および \(X\) に向かう元の圏の射はすべて入れる。** これらの射の本数や、\(X\) に入る射が最初に現れる段階には一様な上限を仮定しない。

代表は重複を除く。非恒等射は \(L\)-レベルの順序数の高さを狭義に増やす。順序数上の単射から高さは非減少で、等しい高さなら自己埋め込み補題が適用できるからである。従って有限個選んだ射の合成閉包は有限である。鎖の高さはどの尾部でも一定にはなれない。一定ならその尾部の射は恒等射になり、もとの禁止された余錐ができる。従って必要なら共終部分鎖に薄めて、試験対象との重複を避けられる。

**有限個の印で全射を区別する。** 試験対象 \(a=P_i\) は、その木 \(T_i\)、節点 \(t_i\)、共通の定数 \(\xi\le\mu\) から、一階の定義可能 Skolem 関数と外部の \(\mu\)-列の符号化で生成される。よって \(a\) からの二つの初等埋め込みは、\(T_i,t_i\) の像が同じなら等しい。列コードの各値は、像の関数を固定された添字で評価して得られる。これは行き先が \(E(X)\) でも成り立つ。したがってこの二つの印は、選んだ少数の射だけでなく、\(a\) から \(X\) への**すべての射**を区別する。

各 \(a\) に有限集合 \(W_a\) を付ける。初めに各対象の二つの印を置き、選んだ試験対象間の全射の像で閉じる。合成閉包が有限なので各 \(W_a\) は有限のままである。各モデルの定義可能な標準 \(L\)-整列で並べると、試験対象間の射 \(g:a\to a'\) は位置の順序埋め込み \(W_a\to W_{a'}\) を定める。\(n=\max_a|W_a|\) とする（試験対象が空の場合は鎖を定値に写せば足りる）。

**余錐の行き先を選ぶ。** \(E(X)\) の台の標準 \(L\)-整列を添字とする順序集合 \(I\) を取る。十分大きな \(B=H_{\vartheta^+}\in\mathcal K_\mu\) に、\(I\) のコピーとなる順序数の列を置けるようにする。その列では長さ \(k\le n\) のどの増加組も、名前付き順序数を含む \(\mu\)-列閉な Skolem 閉包の印付き同型型が同じになるよう選べる。実際、各有限組の閉包は濃度 \(\le2^\mu\) であり、色数は周囲の \(\vartheta\) に依存しない。有限指数の Erdős–Rado 定理を有限回用い、最後に \(|I|^+\) 個以上の斉一な順序数を残せば、必要な順序型をその中に入れられる。[有限組の閉包と制限の証明](coherent_diagrams_in_K_mu.md)・[Erdős–Rado, A partition calculus in set theory](https://www.renyi.hu/~p_erdos/1956-02.pdf)

試験対象 \(a\) の新しい像は、長さ \(|W_a|\) の代表組の閉包の推移的崩壊とする。試験対象間の射には、位置の順序埋め込みに従って部分組の閉包へ写す射を割り当てる。尾部の全対象と \(X\) の像は一つの \(B\)、標準遷移射と \(q_i\) の像はその恒等射とする。

試験対象から出る \(v:a\to P_j\) には、\(E(q_jv)[W_a]\) を順に読んで \(I\) 内の位置に変換し、対応する順序数の組の閉包へ写して \(B\) に含める。\(v:a\to X\) には \(E(v)[W_a]\) で同じ操作をする。標準遷移射を後ろから合成してもこの組は変わらない。試験対象側で前から \(g\) を合成すると、指定の部分組を取る操作になる。閉包同型の部分組への制限は対応する一意な同型なので、すべての合成関係が成り立つ。異なる平行射は元の二つの印のいずれかで異なり、同じ尾部段階から \(X\) への脚の像を **元の \(E\) で** 取るときも単射なので違いが残る。従って構成した関手は忠実である。

これは一本の \(\mu\)-鎖に沿って、試験対象からの全平行射の情報を同時に保持する。下で尾部の各遷移射を非エピな真の包含に写すようにも改良する。尾部の二対象の間に標準遷移射と異なる射も課すと、上の定値の割当てはその二射を区別できず、改良版も追加の任意の射の像までは指定しない。また有限組の長さの上限を外すと、ここで使った有限指数の分割定理では一つの \(B\) を供給できない。

## 充満部分圏全体で定義される、部分構造を使う候補

\(P=E(X)\) の中の、名前付き順序数を含み外部の \(\mu\)-列のコードで閉じた初等部分構造 \(R\) を一つ選ぶ。例えば \(E(q_i)[P_i]\) が使える。崩壊した \(R\) は \(\mathcal K_\mu\) の対象である。各 \(c\in\mathcal C\) に対し

\[
 S_R(c)=\bigcap_{u:c\to X} E(u)^{-1}[R]\ \subseteq c
\]

を取る。該当する \(u\) がない場合は \(c\) 全体を取る。この集合は名前付き順序数を含み、定義可能 Skolem 関数と外部の \(\mu\)-列のコードの下で閉じる。各逆像での閉性は \(E(u)\) の初等性と添字の固定による。従って崩壊は再び \(\mathcal C\) に代表を持つ。\(h:c\to d\) は \(S_R(c)\) を \(S_R(d)\) に写す。実際 \(u:d\to X\) ごとに \(uh\) が最初の共通部分で考慮されている。この制限と崩壊で小対象の射を写し、\(X\) を \(R\) の崩壊に、各 \(u:c\to X\) を \(E(u)|_{S_R(c)}\) の崩壊に送れば、\(\mathcal B\) 全体に関手 \(G_R\) が得られる。\(E\) の部分構造と制限で写し、頂点をこの \(R\) とする方式では、\(S_R(c)\) は選べる最大の部分構造である。

**忠実性の条件。** \(G_R\) が忠実であることと、すべての \(c\) で \(S_R(c)\hookrightarrow c\) が（崩壊を介して）\(\mathcal K_\mu\) のエピ射であることは同値である。実際、\(c\rightrightarrows d\) の二射の新しい像が一致することは、両者の \(S_R(c)\) への制限が一致することに等しい。まず小さい \(d\) に対するエピ性が得られる。大きい \(d\) で反例となる二射があれば、それらの像全体を含む \(\mu\)-列閉な Skolem 閉包を \(d\) 内で取る。濃度は \(\le\theta\) であり、崩壊すれば小さい終域での反例になる。最後に \(X\) に入る射の忠実性は冒頭の必要十分条件から従う。特に、一つの \(R\) についてこのエピ性がすべて成立すれば、求める充満部分圏の実験は肯定される。エピ性を同型性と仮定することはできない。

実は **\(R\) は一段階の像 \(R_i=E(q_i)[P_i]\) の中に必ず入る。** そうでなければ \(r_i\in R\setminus R_i\) を各 \(i<\mu\) で取る。列閉性からその列コードは \(R\subseteq P\) の元で、\(P=\bigcup_iR_i\) よりある \(R_j\) に属する。\(R_j\) はすべての添字を含む初等部分構造なので、列の \(j\) 番目の値も \(R_j\) に入り矛盾する。\(S_R(c)\subseteq S_{R_i}(c)\) より、大きい方の共通部分は小さい方で区別できた平行射をすべて区別する。従ってこの方式の成功は、一つの \(i\) で \(G_{R_i}\) が忠実となることと同値である。

元 \(x\in c\) が \(S_{R_i}(c)\) に残る必要十分条件は、集合 \(\{E(u)(x)\mid u:c\to X\}\) が丸ごと \(R_i\) に入ることである。この集合の濃度が \(\mu\) 未満なら、ある \(i\) で確実に残る。したがって、そのような元で区別できる \(\mu\) 個未満の平行射対は、一つの \(G_{R_i}\) で同時に区別できる。

さらに \(G_{R_i}\) が忠実なら、**すべての \(j>i\) について \(j_{ij}:P_i\to P_j\) はエピ射**である。実際、標準脚 \(q_j\) も共通部分の添字の一つなので、\(S_{R_i}(P_j)\) は \(j_{ij}[P_i]\) に含まれる。\(j_{ij}\) 上で一致する二射は \(S_{R_i}(P_j)\) 上でも一致し、エピ性の判定が適用できる。この必要条件はもとの鎖に関する性質であり、部分構造によらない新しい写し方に課される条件ではない。

## 非エピ射が全段階で続く場合の検査

**肯定例。** \(\mathcal K_\mu\) には、すべての非自明な遷移射が非エピで、かつ同時に余錐を持つ長さ \(\mu\) の鎖がある。大きい一つの \(B=H_{\vartheta^+}\) の中で、各 \(j<\mu\) までに選んだ順序数を含む \(\mu\)-列閉 Skolem 閉包を \(A_j\) としたい。各 \(j\) において以前の全閉包と名前付き順序数の合併 \(D_j\) の濃度は \(\le\theta\) である。新しい順序数 \(z\) を \(>2^\theta\) 通り試し、\(Q_B(D_j\cup\{z\})\) を \(D_j\) の全元と \(z\) を指定した同型型で色分けする。色数は \(\le 2^\theta\) なので二つの異なる選択が同じ色になる。一方を採用して \(A_j\) を作る。包含 \(A_j\to B\) と、もう一方の閉包との同型から得た \(A_j\to B\) は、すべての \(A_i\ (i<j)\) で一致し \(z\) で異なる。崩壊を介して各遷移射は非エピだが、すべての通常の包含が \(B\) への余錐である。つまり尾部を定値にせず、各段階で実際に新しい射の違いを残す有余錐の例も存在する。これは元の小圏全体の射を実現したという主張ではない。

この肯定例は先の有限試験対象の構成と**同時に**実現できる。\(|P|\le\mu\cdot\theta=\theta\) なので、\(I\) のコピーとして実際に使う順序数は \(\le\theta\) 個である。最初からその全ラベルを各 \(D_j\) に含めても色数の上界は変わらない。試験対象から \(P_j\) への射に割り当てた閉包の像は \(A_j\) に入るので、そこで値域を切り詰める。尾部の標準射を \(A_i\hookrightarrow A_j\)、頂点への脚を \(A_j\hookrightarrow B\) にする。崩壊後にも合成と既証の忠実性は保たれる。これで、どの二つの異なる段階の間でも非エピな射に写しながら、試験対象からの射は本数無制限ですべて区別できる。

**枝の選び方に対する限界。** 前稿の悪い鎖を作り直せば、その全非自明遷移射も非エピにできる。その選択に対しては上の \(G_R\) 方式がすべて失敗する。以下は任意に指定した前稿の枝がこの性質を持つという主張ではない。

前稿の型の木 \(U\) を、ある節点とその全先祖の間の、異なる高さを結ぶ標準射がすべて \(\mathcal K_\mu\) で非エピである節点に制限する。これは下向きに閉じた集合サイズの木 \(U'\) である。任意の枝なし木 \(S\)（高さ \(\le\mu\)）から \(U'\) へ高さを保つ写像を作れることを確認する。あらかじめ基数 \(\Lambda>2^\theta\) を選び、\(S\) の節点 \(s\) を、その先祖から \(s\) 自身までの全位置に \(\Lambda\) のラベルを付けた節点に置き換える。順序はラベル付き先祖への制限とする。この木 \(\widehat S\) に枝があれば \(S\) に射影できるので、やはり長さ \(\mu\) の枝はない。

\(\widehat S\) を含む大きい \(B=H_{\vartheta^+}\) を取る。\(S\) 上で高さ順に、各節点のラベルを選ぶ。節点 \(s\) では先祖のラベルはすでに決まっており、最後のラベルだけを動かした \(\Lambda\) 個の節点 \(t\) を試せる。\(Q_B(\widehat S,t)\) は先祖の閉包をすべて含む。そこで全先祖の閉包の元（計 \(\le\theta\) 個）を個別に指定し、さらに \(\widehat S,t\) を指定した同型型を比較する。二つの異なる \(t\) で同じ型が得られる。片方を採用すると、閉包から \(B\) への相異なる二射がすべての先祖の閉包において一致する。先祖との可換性は両方の \(t\) のラベル付き先祖が同一であることによる。こうして各 \(s\) の印付き閉包の型は \(U'\) の節点となり、写像は先祖を保つ。前稿と同じ \(\sigma_{<\mu}U'\) の対角化で \(U'\) に長さ \(\mu\) の枝が得られる。崩壊による鎖の復元と余錐の非存在は前稿と同じであり、非エピ性が全区間で追加される。

従って、平行射を保つために単に「非エピな遷移射に写す」という条件だけを見ても、余錐の可否は判定できない。上の肯定例と悪い鎖では、両者とも全区間が非エピである。未決なのは、元の \(\mathcal C\) 上の**全**合成関係を保つ一つの忠実関手 \(H\) により、指定した悪い鎖を有余錐の鎖に写せるかである。
