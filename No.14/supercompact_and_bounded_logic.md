# No.14　強コンパクト性による小さい図式の構成

2026年11月19日。以下は今回の導出で、独立検証は未実施である。大きいとは本質的に小さくないことをいう。

## 部分結果

\(\kappa\) が強コンパクトなら、一つの大きいアクセス可能圏 \(\mathcal T_\kappa\) があり、次のすべての終域に忠実なアクセス可能関手を持つ。対象とする終域は、ある多ソートの basic theory \(c\) のモデルと全準同型の大きい圏で、各公理が \(L_{\kappa,\kappa}\) に属し、署名の各記号の項数が \(\kappa\) 未満のもの、およびそれと同値な圏である。公理数、ソート数、記号数はいずれも任意の集合濃度でよい。特にこれは一つの supercompact から従う。以下で使う論理的コンパクト性は、任意の集合サイズの言語の理論について、\(\kappa\) 個未満の公理からなるすべての部分理論が充足可能なら全体も充足可能という性質である。[Hayut–Magidor, §2](https://doi.org/10.1017/jsl.2022.11)

### 始域を固定する

署名と公理を合わせた構文のサイズが \(\kappa\) 未満の basic theory のうち、任意に大きいモデルを持つものを、記号の改名を除いてすべて取る。集合個の座標なので、[共通始域の構成 §1](common_sources_and_extendibility.md) を適用して \(\mathcal T_\kappa\) を作れる。各座標への射影は忠実で、すべての射を各ソートで単射に送る。この選択は終域から独立である。

以下の観察で、一つの**指定したソート**上で平行射を区別できる。\(d\) は上のサイズの理論で、ソート \(s\) の濃度がモデルにわたって非有界とする。各ソート \(t\) に関数 \(i_t:t\to s\) とその単射性の公理を加えた理論を \(d^+\) とする。これはなお小さく、任意に大きいモデルを持つ。実際、任意の十分大きな無限基数 \(\rho\) を構文サイズより大きく取り、\(\theta=2^\rho\) と置く。\(s\) に少なくとも \(\theta\) 元あるモデルを取り、その \(\theta\) 元を含む部分モデルを、\(d\) の部分式の断片について下方 Löwenheim–Skolem で取る。\(\theta^\rho=\theta\) なので総台の濃度は \(\theta\) 以下、\(s\) はちょうど \(\theta\) である。そこで各 \(i_t\) を解釈できる。\(d^+\) の準同型は \(s\) 成分だけで決まる。実際、他の成分は \(i_t\) との可換性と終域の \(i_t\) の単射性で一意に決まる。従って \(d^+\) 座標へ射影し、追加記号を忘れた関手 \(\mathcal T_\kappa\to\operatorname{Mod}(d)\) は、異なる平行射を \(s\) 上で区別し、すべてのソートで単射を与える。

### 終域に向かう図式を一つの理論で指定する

終域 \(\operatorname{Mod}(c)\) を固定する。あるソート \(s\) の濃度はモデルにわたって非有界である。各ソートに上界があれば、ソートは集合個なので全台に共通上界ができ、同型類も集合個になってしまう。

\(\mathcal T_\kappa\) と終域の共通のアクセス可能ランク \(\mu\) を、終域の \(\mu\)-フィルター余極限がソートごとに計算されるほど大きく取る。\(\mathcal A\) を始域の \(\mu\)-可呈示対象の小さい充満代表部分圏とする。次の \(L_{\kappa,\kappa}\) 理論 \(D\) は集合である。

1. 各 \(a\in\mathcal A\) に \(c\) のコピーを置く。
2. 各 \(h:a\to b\) と各ソート \(t\) に関数 \(H_{h,t}:t_a\to t_b\) を置く。各記号についての準同型の公理、各ソートでの単射性、恒等射および合成の式を課す。
3. 異なる平行射 \(h,k:a\rightrightarrows b\) ごとに \(\exists x\in s_a\ (H_{h,s}(x)\ne H_{k,s}(x))\) を課す。この公理はソート全体を走る選言を含まない。

\(D\) の \(\kappa\) 個未満の文を取る。それらに現れる元の署名の記号・ソート、コピーされた元の公理をすべて集め、指定ソート \(s\) と各記号に必要なソートを加える。各文の構文と各記号の項数が \(\kappa\) 未満であり、\(\kappa\) は正則なので、得られる部分言語と部分理論 \(d\) のサイズは \(\kappa\) 未満である。\(c\) のモデルを制限すれば \(d\) でも \(s\) の濃度は非有界である。先の \(d^+\) 座標への射影を \(\mathcal A\) に制限すれば、選んだ文をすべて満たす。ここで元の公理は文ごとに丸ごと残す。空ソートを許す規約でも、多ソートの理論を一ソートの述語と関数グラフで表し、量化を各ソートに相対化できる。使わなかった記号は部分理論に新しい制約を課さない。

強コンパクト性で \(D\) 全体がモデルを持つ。それを読むと、真正な関手 \(G:\mathcal A\to\operatorname{Mod}(c)\) が得られる。第3群の公理で忠実であり、第2群の公理で各射はソートごとの単射である。[延長補題 §2](common_sources_and_extendibility.md) により、\(G\) は \(\mathcal T_\kappa\) 全体からの忠実な \(\mu\)-フィルター余極限保存関手に延びる。平行射の区別は延長後も保たれる。可呈示対象からの異なる二射を同じ段階で比較でき、その段階から余極限への標準写像がソートごとの単射だからである。

## 一般問題に残ること

同じ仮定の下で No.14 の肯定は、各大きいアクセス可能圏に、ある大きい basic \(L_{\kappa,\kappa}\) モデル圏から忠実なアクセス可能関手が入る、という条件を**十分条件**として持つ。終域自身がこの論理で表示できることより弱く、合成すればよい。逆に、任意の始域候補がこの論理で表示できるとは示していない。

一般の basic theory の表示では、一つの公理が長さ \(\kappa\) 以上の選言や量化列を持ちうる。これを小さい部分文に分割して同じコンパクト性を使う操作は一般には正当化できない。例えば相異なる \(a_i\ (i<\kappa)\) を持つソートに、被覆公理 \(\forall x\,\bigvee_{i<\kappa}x=a_i\) を課す。新しい定数 \(b\) に対する \(b\ne a_i\ (i<\kappa)\) を加えると、\(\kappa\) 個未満の文は同時に満たせるが、全体は満たせない。これはこの証明での制限を検査する例である。No.14 の反例は得られていない。

## 一つの supercompact で一般の論理幅を扱うための十分条件

先の extendible の証明で使った「内部で任意に大きいモデルがある」を、一つのサイズのモデルに置き換えられる。以下の十分条件が通常の supercompactness から従うかは未解決である。

無限基数 \(\tau<\kappa\) に対し、\(h(\tau)<\kappa\) を、サイズ \(\le\tau\) のすべての basic theory に共通する次の閾値に取る。総台濃度 \(\ge h(\tau)\) のモデルが一つあれば、その理論は任意に大きいモデルを持つ。実際、固定した小さい理論のモデルのサイズが \(\kappa\) 未満で非有界なら、ある一つのソートのサイズもそこで非有界である。相異なる元を指定する定数をそのソートに任意個加え、強コンパクト性を適用すれば任意に大きいモデルを得る。従ってモデルのサイズが有界な小さい理論は、それぞれ \(\kappa\) 未満ですでに有界である。構文サイズ \(\le\tau\) の理論は改名を除いて \(\kappa\) 未満個なので、それらに共通の閾値を取れる。さらに \(h(\tau)>\tau\) と \(h(\tau)^\tau=h(\tau)\) を満たす最小のそのような基数とする。強到達不能性によりこれはなお \(\kappa\) 未満である。

ここで \(\kappa\) を supercompact とし、終域の理論を改名してコードの遺伝的濃度に無限基数の上界 \(\tau\) を取る。もしこの \(\tau\) に対して supercompactness 埋め込み \(j:V\to M\) と基数 \(\lambda\ge\max(\kappa,\tau)\) を

\[
 M^\lambda\subseteq M,\qquad j(\kappa)>\lambda,\qquad j(h)(\tau)\le\lambda
\]

となるよう選べれば、この終域には上で固定した \(\mathcal T_\kappa\) から忠実なアクセス可能関手が入る。実際、\(\chi=j(h)(\tau)\) と置く。\(M\) の \(\chi^\tau=\chi\) は列閉性により外部でも成り立つ。外で大きい \(c\)-モデルに下方 Löwenheim–Skolem を適用して総台濃度ちょうど \(\chi\) のものを選ぶ。台を改名すると、各記号の解釈も含むコードの遺伝的濃度は \(\chi\) 以下であり、\(H_{\lambda^+}\subseteq M\) により \(M\) に入る。充足に必要な代入列は \(M\) にあり、\(M\) もこれを \(c\)-モデルと判定する。閾値の定義の初等性から、\(M\) は \(c\) に任意に大きいモデルがあると判定する。

始域の座標は、改名を標準化したサイズ \(<\kappa\) の全コードのうち、外で任意に大きいモデルを持つものとして選んでおく。その \(j\)-像には標準化した \(c\) が入る。そこで小さい可呈示対象の圏の各対象と射に \(j\) を施して \(c\) 座標へ射影する。超コンパクト性の細正規測度から取った超冪は集合上に制限できるので、この図式自体が集合である。その値が外でもモデルであることは、構文に必要な列の長さが \(\tau\le\lambda\) であることから従う。射影の忠実性と単射性、および余極限保存延長は前稿 §2–3 と同じである。この経路では \(j\) は宇宙上で定義されているので、可呈示対象の代表部分圏まで \(H_{\lambda^+}\) に入れる必要はない。

したがって、すべての \(\tau\ge\kappa\) で上の不等式を達成できれば、一つの始域で一般の No.14 が肯定される。supercompactness から任意の指定済み \(\lambda\) で最初の二条件は得られるが、右辺を大きくして埋め込みを選び直すと左辺の \(j(h)(\tau)\) も変わる。外部で選んだ Hanf 数をそのまま内部のこの値の上界にする根拠は得られていない。

別に、終域の理論より上の可測基数を使い、一つの大きいモデルを反復超冪で任意のサイズまで拡大する案も検討した。極限段階で外部の短い列が反復先に属することが保証されず、内部の無限論理の充足を外でそのまま使えない。例えば正規測度の \(\omega\) 回反復の臨界列は外部で \(j_{0,\omega}(\eta)\) に共終だが、反復先ではこの基数は可測で正則である。従ってその可算列は反復先にはない。この案から可測基数を追加した一般十分条件も結論していない。[反復超冪の背景、Kunen](https://www.math.cmu.edu/~laiken/papers/IteratedUP.pdf)
