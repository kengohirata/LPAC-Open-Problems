# No.11　アクセス可能圏で、一つの対象の商は何個あるか

Adámek–Rosický の No.11 は二問からなる。以下では便宜上 (a), (b) と呼ぶ。固定した対象 \(A\) からのエピ射 \(e:A\to B\) を商と呼び、\(e'=i e\) となる同型 \(i:B\to B'\) があれば同じ商と数える。[原著 *Open Problems*, p.297](https://doi.org/10.1017/CBO9780511600579.011)

| 問い | 2026年11月19日の確認結果 |
| --- | --- |
| (a) どのアクセス可能圏でも、各対象の強エピ商は同型を除き集合個か。 | ZFC で肯定。原著の命題 2.29 と定理 2.33 直後の注意から従う。極端エピ商（extremal epi quotient）にも同じ証明が通る。 |
| (b) 「どのアクセス可能圏でも、各対象のエピ商は同型を除き集合個である」という命題の正確な集合論的強さは何か。 | 公刊された強コンパクト基数による上界に加え、今回の導出では almost strongly compact 基数が任意に大きく存在すれば成立する。必要条件は可測基数の真クラスで、正確な強さは未確定。[証明と先行研究](epimorphisms_and_almost_strong_compactness.md) |

## (a) 固定した始域が商の可呈示ランクを抑える

\(\mathcal K\) を \(\lambda\)-アクセス可能、\(A\in\mathcal K\) とする。定理 2.33 の注意によると、任意に大きい適切な正則基数 \(\gamma\) で次が成立する。\(A\) が \(\gamma\)-可呈示なら、**始域が \(A\) の任意の射** \(e:A\to B\) は

\[
A\xrightarrow{u} C\xrightarrow{m}B
\]

と因子化し、\(C\) は \(\gamma\)-可呈示、\(m\) は \(\lambda\)-pure である。命題 2.29 により \(m\) はモノ射である。アクセス可能圏の各対象はあるランクで可呈示なので、\(A\) を固定した時点でこの \(\gamma\) を選べる。終域 \(B\) が変わっても同じ \(\gamma\) が使える。[原著第2章、命題 2.29、定理 2.33 とその注意、pp.86, 90–92](https://doi.org/10.1017/CBO9780511600579.005)

ここで \(e\) が強エピ射なら、\(m u=1_B e\) という正方形で \(e\) の \(m\) に対する持ち上げ性を使うと、\(m d=1_B\) となる \(d:B\to C\) が得られる。\(m\) はモノ射なので同型である。極端エピ射についても、モノ射を通じた因子化でそのモノ射が同型になることが定義である。従って、いずれの場合も \(B\) は \(\gamma\)-可呈示になる。固定ランクの可呈示対象には同型を除き集合個の代表しかなく、代表ごとの \(\mathcal K(A,B)\) も集合である。これで商の**射**まで数えられる。

## (b) 通常のエピ商に残る問題

**上界の更新。** エピ射の終域の各元について、始域の元をパラメータとして値を一意に決める短い原子図式を取り出す。固定したモデル表示で必要な論理のコンパクト性だけで図式の長さを抑えられるため、almost strongly compact 基数の真クラスが十分である。初出および独立検証は未確認。[エピ商の濃度評価と証明](epimorphisms_and_almost_strong_compactness.md)

上の因子化で \(e\) がエピなら \(m\) もエピになる。従って \(m\) は pure モノ射かつエピ射であるが、この二条件を満たす射には非同型もある。この観察から次の還元が得られる。固定した \(\lambda\)-アクセス可能圏で、各対象を始域とする **\(\lambda\)-pure かつエピな射** が同型を除き集合個なら、その圏は co-wellpowered である。実際、上の \(C\) を集合個の代表から、\(u:A\to C\) を各 Hom 集合から選び、各 \(C\) を始域とするそのような \(m\) の代表と合成すれば全エピ商を覆う。逆は定義から従う。

- **上界。** Makkai–Paré の定理 6.3.8(i) による余極限の検出可能性を押し出しに適用すると、強コンパクト基数の真クラスから (b) の全称命題が従う。ZFC でも、母圏が押し出しを持てば原著の定理 2.49 が適用できる。エピ射 \(e:A\to B\) は、二本の \(e\) からなるスパンの押し出しが二本の \(1_B\) で与えられる射として検出できる。[原著第2章、定理 2.49](https://doi.org/10.1017/CBO9780511600579.005)・[Bagaria–Casacuberta–Mathias–Rosický、系 7.6 直後、pp.574–575](https://www.ub.edu/topologia/casacuberta/articles/bcmr.pdf)
- **下界。** 可測基数がある基数 \(\lambda\) 以上には存在しないとする。原著の例 A.19 は、ZC（置換公理図式を除いた ZFC）の推移的モデルと \(\lambda\)-初等埋め込みの圏に形式的始対象 \(I\) を加える。こうして得るアクセス可能圏では、極限基数 \(\eta\) にわたる \(I\to V_\eta\) が相異なるエピ商になる。どの対象へも \(V_\eta\) からの射が高々一本だからである。一方、\(I\) に入る射は恒等射だけなので、\(I\to V_\eta\) はモノ射でもあり、同型ではない。従ってこれは通常のエピ商だけを真クラス個与える例である。[原著付録、例 A.19、pp.293–294](https://doi.org/10.1017/CBO9780511600579.010)

原著の系 6.8 とその注意 (2) は、Vopěnka 原理による十分条件、強コンパクト基数による上界、可測基数による下界を区別している。Bagaria ほかは、固定した \(A\) の下の圏 \((A\downarrow\mathcal K)\) のうちエピ射が作る充満部分圏を調べる別証明を与えた。この部分圏では比較射は高々一本なので、小さい稠密部分圏を与えられれば本質的に小さい。後続文献も強コンパクト基数による上界を用いている。[原著第6章、系 6.8 と注意 (2)](https://doi.org/10.1017/CBO9780511600579.009)・[Bagaria ほか、系 7.6](https://www.ub.edu/topologia/casacuberta/articles/bcmr.pdf)・[Kamsma–Rosický, *Unstable independence from the categorical point of view*](https://doi.org/10.1016/j.apal.2025.103629)
