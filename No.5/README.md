# No.5　アーベル群の反射と弱反射

2026-11-19。Adámek–Rosický の No.5 の二問は、それぞれ弱 Vopěnka 原理（WVP）と同値である。前半は Isbell の問題に対する Przeździecki の結果。後半の同値は、以下の既知の定理と解集合条件を組み合わせて得られる。原著 p.297 の No.9 は No.5 の重複であることも著者の正誤表で確認できる。[問題の原典、p.296](https://doi.org/10.1017/CBO9780511600579.011)・[正誤表、最終行](https://math.fel.cvut.cz/en/people/adamekj/corrections.pdf)

## 二問とその関係

以下、部分圏は充満で同型で閉じているものとし、極限と積は母圏 Ab で計算する。

- **(a)** 任意の小極限で閉じる部分圏は反射的か。
- **(b)** 任意の小積と直和因子で閉じる部分圏は弱反射的か。原著の split subobject は Ab では直和因子にあたる。

対象 X の弱反射とは、部分圏の対象 W への射 w があり、部分圏への任意の射 f が w を通じて因子化すること。反射ではこの因子化が一意になる。加群論で w は preenvelope と呼ばれる。

1. **WVP ⇒ (b)**。原著の Theorem 6.26 と Remark 6.27(2) は、そこでの原理 (*) の下で弱反射の存在を与える。(*) は semi-weak Vopěnka principle であり、Wilson により WVP と同値。加群については直積と直和因子による同じ十分条件を Lemma 3 で直接参照できる。[Wilson, Theorem 1.4](https://arxiv.org/abs/1909.09333)・[Dualizations of Approximations, Lemma 3](https://doi.org/10.1007/s10485-024-09791-y)
2. **(b) ⇒ (a)**。小極限で閉じる部分圏 A は積で閉じ、冪等自己射と恒等射の等化子を取れば直和因子でも閉じる。(b) を適用すると、各 X に対する一つの弱反射がコンマ圏 (X ↓ A) の弱始対象となり、包含関手の解集合条件を満たす。A は完備で包含は極限を保存するので、Freyd の随伴関手定理により包含は左随伴を持つ。この段階は ZFC で成り立つ。
3. **(a) ⇒ WVP**。Przeździecki の Proposition 6.8 は、¬WVP の下で Ab に非反射的な直交類が存在することを示す。射のクラスに対する右直交類は、各 Hom 関手が第2変数の極限を保存するため、小極限で閉じる。従ってこの直交類は (a) の反例になる。(a) の肯定方向は原著の Theorem 6.22 にも直接従う。[Przeździecki, §6, Proposition 6.8](https://arxiv.org/pdf/1104.5689)

後半には具体的な既知の反例もある。非可算可測基数が存在しないと仮定し、整数の積 ℤ^κ を台の大きさが κ 未満の列の部分群で割った群を考える。無限基数 κ を動かし、これらの群を積と直和因子で閉じて得られる部分圏に対して、ℤ が弱反射を持たない。これは (b) の閉性を直接実現する例である。[Casacuberta–Gutiérrez–Rosický, Proposition 2.6](https://www.ub.edu/topologia/casacuberta/articles/cgr.pdf)

## No.1〜4 との接点

- **No.4** は任意の局所可呈示圏を母圏とし、極限閉性に加えて有向合併による閉性を仮定する。No.5(a) は母圏を Ab に固定し、合併について仮定しない。No.4 のプロジェクト内の証明は、Ab では可算増大列の合併で閉じるだけで ZFC における反射性を導く。具体的には、非零の捩れなし群 K から (1/n!)K の合併を経て ℚ を直和因子として得る箇所と、巡回 p 群の増大列から Prüfer 群を得る箇所でこの仮定を使う。この証明を採用すると、¬WVP の下での No.5(a) の反例は、必ずどこかの可算増大列の合併で閉性を失う。これは両結果からの帰結で、具体的にその列を特定したものではない。[No.4 の Ab に対する定理](../No.4/abelian_groups_limit_countable_union_reflection_theorem_2026-11-18.md)・[プロジェクト内の独立検算](../No.4/independent_audit_abelian_group_reflection_theorem_2026-11-18.md)
- **No.1・2** は局所可呈示圏 K の双対で直交性を取る。K の言葉では、集合個（No.1）またはクラス個（No.2）の射に対する左直交類の余反射性、さらに No.2(b) では二つの余反射的部分圏の交わりによる表示を問う。Przeździecki の反例は Ab 自身における右直交類である。局所可呈示圏では集合個の射に対する右直交類は既に反射的なので、ここで反射性を失う直交類は集合個の射では定義できない。No.1・2 の研究記録では WVP からの肯定方向が扱われており、No.5 ではこれに加えて逆向きも公刊結果から得られる。[No.1・2 の命題と条件付き結果](../No.2/p1_p2_measurable_wvp_almost_compact_2026-11-17.md)・[Przeździecki, §6](https://arxiv.org/pdf/1104.5689)
- **No.3** の原問題は、余完備圏に generated objects からなる強生成集合があるとき、その圏自身が局所可呈示かを問う。No.5 の (b) ⇒ (a) で必要なのは、各 X について X から部分圏への射をまとめる解集合である。これは各 X ごとの条件であり、部分圏全体の生成集合や局所可呈示性を要求しない。No.3 で再検討中の generated strong generator から稠密部分圏への還元も、上の同値には使わない。[No.3 の定式化と還元の検討](../No.3/README.md)
